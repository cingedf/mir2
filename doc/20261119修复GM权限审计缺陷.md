# 20261119修复GM权限审计缺陷

## 现象

新维度审计（GM 命令/聊天/权限系统路线）回报 1 P1 + 3 P2。P1 是**现网可达的任意玩家提权漏洞**，可导致普通玩家获得全部 GM 权限（刷物/刷钱/踢人）：

1. **P1 明文 GM 口令随配置发布 + @LOGIN 无鉴权提权**：任意玩家发 `@LOGIN` 进入口令输入，输入泄露的口令 `GMPassword=@9396399`（随部署配置公开）即 `IsGM=true`，解锁全部 GM 命令。
2. **P2 @SETTIMER 无权限校验**：普通玩家可伪造 NPC 计时器，绕过脚本冷却/门禁。
3. **P2 @CHANGEGENDER/@CHANGECLASS 离线目标 NRE**：对离线角色执行改名/改职业时，日志参数在判空前解引用 `data.Player.Name`（为 null）→ NRE。
4. **P2/配置 TestServer=True 全开命令**：测试服开关误配公网时一次性开放 30+ 刷物刷钱命令。

## 排查过程

1. **P1 提权链逐段核实**：
   - `@LOGIN` 入口（PlayerObject.cs:2326-2329）：`case "LOGIN": GMLogin = true; ReceiveChat(EnterGmPassword); return;`——无任何权限/IP/来源校验，对比紧邻的 `case "KILL": if (!IsGM) return;` 守卫，明显遗漏。
   - Chat 口令分支（:2034-2051）：`if(GMLogin){ if(message==GMPassword){ IsGM=true; UpdateGMBuff(); ...Envir.RemoveRank(Info);} ... GMLogin=false; return; }`——口令正确即置 IsGM，且在禁言(:2053)/限速校验之前。
   - 正规 GM 来源（:242-245）：`if (Account.AdminAccount) { IsGM = true; }`——GM 身份完全可由账号标记决定，聊天口令提权非必需。
   - GMPassword 默认值（Settings.cs:45-47）：源码默认为 `string.Empty`，注释明确「缺省置空=禁用聊天提权，杜绝任何知道源码的人提权」；但部署区 `Build\Server\Release\Configs\Setup.ini:5` 与 `mir2-deploy\Server\Configs\Setup.ini:5` 仍配 `GMPassword=@9396399`，使提权生效。
   - grep GMLogin 全仓仅 4 处（:35 字段声明 `//TODO-Remove`、:2034、:2049、:2327），改动面极小。
2. **P2 SETTIMER**（:4446-4456）：整个 switch 中唯一缺 `if(!IsGM...)` 守卫的危险命令，对比下一行 `case "SETLIGHT": if((!IsGM)||...)`。
3. **P2 CHANGEGENDER/CLASS**（:2494/:3739）：`data=Envir.GetCharacterInfo(parts[1])` 可返回离线角色（Player 字段 null），`Helpers.ChatSystem.SystemMessage(...data.Player.Name...)` 在 :2496/:3741 的判空前求值必抛 NRE。

## 修复内容

**均在 Server\MirObjects\PlayerObject.cs，附 20261119 注释：**

1. **@LOGIN 入口**（:2326-2329）：移除 `GMLogin = true;`，改为 `ReceiveChat("GM 提权命令已禁用，GM 身份由账号标记决定", ChatType.Hint); return;`——GMLogin 永不置 true，口令分支成死代码。
2. **口令分支双保险**（:2037-2039）：删除 `IsGM = true;` 提权行（保留 UpdateGMBuff 等），即使异常路径进入也不再提权。GM 身份只由 :242-245 Account.AdminAccount 决定。
3. **SETTIMER**（:4446-4456）：`if (parts.Length < 4) return;` 后补 `if (!IsGM && !Settings.TestServer) return;`；seconds 解析后补 `if (seconds < 0 || seconds > 86400 * 30) return;`（防 `seconds*Settings.Second` 整型溢出为负）。
4. **CHANGEGENDER**（:2494）：日志参数 `data.Player.Name` → `data.Name`（CharacterInfo 自带名字字段，离线角色也可用）。
5. **CHANGECLASS**（:3739）：同上 `data.Player.Name` → `data.Name`。

**不修（记录在案）：**
- P2/配置 TestServer=True 全开：改动面 30+ 处，当前生产配置 TestServer=False 不触发；误配公网属运维问题，启动警告更佳但非本次代码缺陷范围。
- 部署区 Setup.ini：属数据资产（不进 git），且 @LOGIN 提权路径已在源码侧禁用，即使口令仍在配置中也无法提权，无需改动配置文件。

**子代理确认非缺陷**：GM 命令权限覆盖完整（除 SETTIMER）、无玩家可达封号踢人命令、无法冒充发言、聊天长度/频率限制到位、正则注入已修、Observe 双路径有权限、CLEARBUFFS 仅作用自身属自助。
