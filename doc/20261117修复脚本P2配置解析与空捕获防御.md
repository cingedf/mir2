# 20261117修复脚本P2配置解析与空捕获防御

## 现象

第五轮深度审计脚本引擎维度登记的 7 项 P2 遗留缺陷，均可由畸形配置或异常脚本内容触发启动中断/任务链崩溃：

1. **IniReader ReadPoint/ReadSize 越界**（Shared\Functions\IniReader.cs:281/299）：配置值缺逗号/空段时 `Split(',')[1]` 越界抛异常，中断服务器启动。
2. **ParseSegment 未知指令抛异常**（NPCScript.cs:574-576）：脚本含未知 `#指令` 时 `throw new NotImplementedException()` 中断整页脚本解析。
3. **ParseGoods/ParseCrafting 空格行越界**（NPCScript.cs:676/775）：空白行 `Split(' ')` 后 `data[0]` 越界。
4. **%ARG(n) 溢出**（NPCSegment.cs:50-67）：`Convert.ToInt32` 对超大参数序号抛 OverflowException，负索引/越界访问 Page.Args。
5. **ReplaceValue Captures[0] 无保护**（NPCSegment.cs 15 处）：正则未匹配成功时访问 `Groups[n].Captures[0]` 抛 ArgumentOutOfRangeException 中断脚本执行。
6. **ACTION CALL 无效 ID**（PlayerObject.cs:4727）：无效脚本 ID 触发 NPCScript.Get 内部索引器 KeyNotFoundException 中断任务链。
7. **FishingDelay 负值**（Settings.cs:1575）：负延迟致钓鱼提前到期。

## 排查过程

- 逐项读取现场代码并按引用链确认触发条件与影响面；
- ReadPoint/ReadSize 为 Shared 层（服务端+客户端共用），畸形配置两端均受影响；
- ParseSegment/ParseGoods/ParseCrafting 为启动期脚本解析，异常直接中断整页；
- %ARG/Captures[0] 为运行期脚本执行，异常经 DelayedAction 队列可中断任务链；
- ACTION CALL 根因在 NPCScript.Get 用索引器 `Envir.Scripts[index]`，方案 B 只在 CompleteNPC 调用点改用 TryGetValue（避免扩散 12 处调用点）；
- FishingDelay 为 long 字段，负值钳制用 0L（注意 PlayerObject.cs:11701 类内 const FishingDelay=200 是另一常量，不动）。

## 修复内容

1. **IniReader.cs**：ReadPoint/ReadSize 改为先 `string[] parts = temp == null ? null : temp.Split(',')`，`parts == null || parts.Length < 2 || !int.TryParse(parts[0]...) || !int.TryParse(parts[1]...)` 任一命中即 `Write(section,key,Default); return Default;`。
2. **NPCScript.cs**：ParseSegment 默认分支改 `MessageQueue.Enqueue(未知指令日志); continue;`；ParseGoods/ParseCrafting 的 `IsNullOrEmpty`→`IsNullOrWhiteSpace` 并在 Split 后加 `if (data.Length == 0) continue;`。
3. **NPCSegment.cs**：ParseArguments 改 `int.TryParse` + 范围校验 `sequence < 0 || sequence >= Page.Args.Count` 直接 continue；新增 `private static string CaptureValue(Match match, int group, int capture = 0)` helper（判 match.Success/Groups 边界/Captures 数量，越界返回空串）；15 处高风险 `Groups[n].Captures[0].Value` 机械替换为 `CaptureValue(match,n)`。
4. **PlayerObject.cs CompleteNPC**：`NPCScript.Get(scriptid)` 改 `Envir.Scripts.TryGetValue(scriptid, out NPCScript script)` + null 判空后 return。
5. **Settings.cs LoadFishing**：读值后加 `FishingDelay = Math.Max(0L, FishingDelay);`。

## 验证证据

- `dotnet build Server.MirForms\Server.csproj -c Release`：**0 警告 0 错误**；
- 行为复核：合法配置/脚本路径不受影响；所有钳制/判空只拦截畸形输入（原会抛异常中断），合法输入行为等价；
- 待实测：服务器正常启动、NPC 脚本正常加载执行、寄售/合成/钓鱼正常。
