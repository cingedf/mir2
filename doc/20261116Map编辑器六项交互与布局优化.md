# 20261116Map编辑器六项交互与布局优化

## 现象

用户实测上一轮布局改造后提出 6 个问题（要求完美执行、自主决策、不遗漏）：

1. 地图标签右侧选 Map 文件夹的控件（文件树），其他标签页也一直显示——不需要就互斥显示，不同时可见。
2. 路径输入框下面的"加载"按钮占了一整行，应放到输入框右侧同一行，省出空间给地图显示区。
3. 地图页要支持：按住鼠标左键拖动平移地图；Ctrl+鼠标滚轮缩放地图（换掉不顺手的快捷键）。
4. 4 个图库标签页右侧的 宽度/高度/偏移X/偏移Y 标签与下面的图片预览布局错位，和中间的数字编号缩略图重叠；预览图太小看不清，应参照图块页预览稍大一点。
5. 物件标签还是没有任何显示。
6. 地图标签与后面的 4 个图库标签、图块标签是什么逻辑关系？打开 mir2 地图会不会传递到那些标签？传递实现是否正确？

## 排查过程

### ① 文件树常驻问题

- splitMain（上一轮加的主分割条）Panel2=TreeViewBox 文件树是主窗体级控件，不随标签页切换隐藏，所以每个标签页右侧都挂着它。
- tabControl1_SelectedIndexChanged (Main.cs) 原是空方法——正好是互斥显隐的挂载点。
- SplitContainer 没有 Panel2Visible 属性（首次实施误用报 CS1061），正确属性是 **Panel2Collapsed**。

### ② TreeViewBox 内部布局

- 原布局：PathTextBox (6,18) 184x27、OpenMapDirectory"加载"按钮 (75,46) 在输入框下一行、TreeBrowser 从 y=75 开始——按钮独占一行，树顶部浪费 45px。

### ③ 平移与缩放

- 缩放体系：zoomMIN=zoomMAX=20（L39-40），ZoomIn/ZoomOut（private 无参，内部 Enlarge/NarrowZoom+SetMapSize）已有；原快捷键只有小键盘 +/-。
- 平移现状：MapPanel_MouseMove 只更新 cellX/cellY+信息面板，无拖动平移。
- **交互冲突分析**：左键在绘制层（背景/中间/前景/笔刷等）上是绘制/框选，不能直接抢给平移。拍板：**编辑层为"无"（Layer.None，默认状态）时左键拖动=平移；选择了绘制图层时左键保持原绘制行为**。这样"想平移先按 Esc 回到无层状态"符合直觉，且不破坏任何既有绘制交互。
- Ctrl 笔刷冲突：Main_KeyDown 里 Ctrl 按住会设 keyDown=true 触发连续绘制，但拖动平移分支在 MouseMove 中先 return，滚轮缩放走 MouseWheel 不经过 KeyDown——两条新路径都防住了冲突。

### ④ 图库页预览错位重叠

- 上一轮把 4 标签+picXxx 移入 splitX.Panel2，但 LibListView Dock=Fill 占满 Panel2，把同为 Panel2 子控件的标签/预览图**完全盖住**（WinForms Dock=Fill 控件与绝对定位控件重叠时后绘制者在上，用户截图证实重叠/错位）。
- 正确做法：给右侧预览区一个独立的 Dock=Right 容器，让 Dock=Fill 的 ListView 自动让位。

### ⑤ 物件页空

- Data\Objects 目录无 .X 文件（前两轮已确认非 bug）。用户仍看不到任何东西—— ListBox 空着没有任何指引，用户体验上等于"坏了"。
- .X 格式已核实（BinaryWriter：count + 每条 X/Y/BackIndex/BackImage/MiddleIndex/MiddleImage/FrontIndex/FrontImage/DoorIndex/DoorOffset/动画帧/Tick/TileAnimation/Light，相对坐标）。生成演示文件需要真实地图数据，程序内空态提示更通用。

### ⑥ 传递链验证（重点排查，全部读码确认）

- **库索引链**：4 个图库页 LibListBox_SelectedIndexChanged → selectListItem.Value = 库索引（WemadeMir2 段 0-29 等）。
- **图编号链**：4 个 LibListView_SelectedIndexChanged（WemadeMir2 L1874-1889 等）→ `selectImageIndex = XxxLibListView.SelectedIndices[0]` + selectLibMImage + picXxx.Image + 宽度/高度/偏移X/偏移Y 标签更新。
- **绘制链**：MapPanel_MouseClick 按 layer 分发：BackImage 层 → `M2CellInfo.BackIndex = selectListItem.Value; M2CellInfo.BackImage = selectImageIndex + 1`（CheckImageSizeIsBigTile 校验 96x64 大图 + CheckPointIsEven 偶数格对齐）；MiddleImage/FrontImage 同理。
- **图块页链**：TileslistView_SelectedIndexChanged → selectTilesIndex = SelectedIndices[0] → RandomAutoMir2Tile 用 `selectTilesIndex * Mir2BigTileBlock(50) + random.Next(5)` 映射回真实图编号刷 3x3 大图块。
- **结论：传递链真实存在且实现正确**——地图页放图块 = 图库页选库（selectListItem.Value）+ 图库页/图块页选编号（selectImageIndex/selectTilesIndex）。无需修改。
- 记录不修（上游缺陷）：GetTilesPreview Mir3 分支 L4576 `Libraries.MapLibs[libIndex].Images[tempIndex] = null` 仍用共享字段 libIndex。

### ③ 左键拖动平移 + Ctrl+滚轮缩放（Main.cs）

新增字段：`mapDragging / mapDragStartMouse / mapDragStartMapPoint`。

- **MapPanel_MouseDown**：Right 分支后新增——`e.Button==Left && layer==Layer.None && M2CellInfo!=null` 时记录拖动起点（鼠标像素 + mapPoint），Cursor=SizeAll，return。
- **MapPanel_MouseMove**：M2CellInfo null check 后新增拖动块——像素差 ÷（CellWidth*zoomMIN/zoomMAX）换算成格数，非 0 时 `Jump(mapDragStartMapPoint.X-dxCells, Y-dyCells)` 平移并更新 cellX/cellY，然后 return（在 keyDown 连点绘制之前，防冲突）。
- **MapPanel_MouseUp**：Left+mapDragging 复位状态与光标。
- **MapPanel_MouseWheel（新增）**：无地图或非 Ctrl 直接 return；steps=Max(1,|Delta|/120)；Delta>0 循环 ZoomIn() 否则 ZoomOut()（支持高分辨率滚轮多步）。Designer 中挂接事件。
- 小键盘 +/- 快捷键保留。Jump 内部 clamp 保证不越界。

### ④ 图库页右侧预览面板重构（Main.Designer.cs，4 页同步）

## 使用说明

- **平移**：编辑层保持"无"（默认），按住左键拖动地图即可；要绘制时再从"编辑层"下拉选图层（选了层左键就是绘制，Esc 回到"无"恢复拖动）。
- **缩放**：Ctrl+滚轮（或小键盘 +/-）。
- **文件树**：只在"地图"页出现；输入 Map 文件夹路径点"加载"（按钮已在输入框右侧），双击树中 .map 直接打开。
- **物件页**：空时显示图文指引，按指引保存第一个 .X 后列表即有内容。
- **图库页**：右侧 260px 预览面板显示 宽度/高度/偏移X/偏移Y + 244x244 大预览，与编号缩略图不再重叠。
