# 20261116 修复低分辨率全屏黑边（D3D 拉伸放大滤镜）

## 现象

用户反馈：1920×1080 选择全屏正常铺满，但在 Config 中选择 1024×768 / 1280×800 / 1366×768 后切全屏，屏幕四周出现**黑边**（画面不铺满物理屏）。用户期望低分辨率全屏时有**放大滤镜**效果（画面被拉伸放大到铺满屏幕，人物怪物显得更大），而不是细腻的 1:1 加黑边。

## 排查过程

1. **黑边根源**：原实现走 D3D9 **独占全屏**（`DXManager.Create`/`ResetDevice` 中 `Windowed = !Settings.FullScreen`）。D3D9 独占全屏模式只在后缓冲尺寸与显示模式完全一致时铺满，任意分辨率（如 1366×768）不被显示模式原生支持时产生黑边，且独占模式从不缩放。
2. **分辨率生效链梳理**：
   - Config 窗（`Client\Forms\Config.cs`）单选钮仅设 `Settings.Resolution`，不即时生效；
   - 进游戏时 `SelectScene.StartGame` case4 调 `CMain.SetResolution(逻辑宽, 逻辑高)`；
   - `CMain.SetResolution` / `ToggleFullScreen` / `CMain_Load` 三处按 `Settings.ScreenWidth/Height`（逻辑分辨率）设置 `Program.Form.ClientSize`；
   - `DXManager.ResetDevice` 原先取 `Program.Form.ClientSize` 当后缓冲尺寸——后缓冲与窗口绑定，无缩放空间。
3. **鼠标坐标体系**：全仓唯一换算点 `CMain.CMain_MouseMove` 的 `MPoint = PointToClient(Cursor.Position)`，所有 UI 命中测试走 `CMain.MPoint`；全仓唯一直用 `e.X/e.Y` 坐标的是 `NPCDialogs.NPCDropPanel_Click`。
4. **引用面排查**：`DXManager.Parameters.Windowed` 共 2 处赋值（Create :68、ResetDevice :293、ToggleFullScreen :579），`BackBufferWidth/Height` 共 2 处；`MouseEventArgs` 为 WinForms 原生类型，鼠标事件全部经 CMain 6 个 handler 透传给场景。
5. **额外发现**：`DXManager.Create` 中 `Device.SetDialogBoxMode(true)` 仅在全屏独占模式下合法，恒窗口化后会抛 `D3DERR_INVALIDCALL` 导致设备创建失败，必须防御。

## 修复内容

方案：**无边框窗口式全屏 + D3D 窗口化拉伸**——窗体铺满物理屏，D3D 恒窗口化，后缓冲固定为逻辑分辨率，由 D3D 自动把后缓冲拉伸铺满窗口（等效放大滤镜）。

1. `Client\Settings.cs`：新增 `NativeWidth/NativeHeight`（物理屏尺寸，默认 0）。
2. `Client\Program.cs`（Main）：`Settings.Load()` 后捕获 `Screen.PrimaryScreen.Bounds` 存入 `NativeWidth/NativeHeight`，捕获失败或零尺寸回退逻辑分辨率。
3. `Client\MirGraphics\DXManager.cs`：
   - `Create`：`Windowed = true` 恒窗口化；`SetDialogBoxMode(true)` 包 try-catch（窗口化下该调用非法，忽略仅影响 Alt+Tab 对话框热键体验）；
   - `ResetDevice`：后缓冲不再取 `ClientSize`，固定 `Settings.ScreenWidth/Height`（与窗口解耦，成为拉伸源）；`Windowed = true`。
4. `Client\Forms\CMain.cs`：
   - `CMain_Load`：全屏启动时 `ClientSize = NativeWidth/NativeHeight`（铺满物理屏），窗口模式=逻辑尺寸；全屏不 CenterToScreen；
   - `ToggleFullScreen`：删 `Parameters.Windowed` 切换（恒 true）；全屏 `ClientSize=物理屏`、窗口 `ClientSize=逻辑尺寸`；仅窗口模式 CenterToScreen；
   - `SetResolution`：同上按 `Settings.FullScreen` 选窗体 ClientSize（全屏=物理屏+新逻辑后缓冲 → 拉伸立即生效）；
   - `CMain_MouseMove`：全屏时鼠标坐标按比例换算回逻辑坐标 `clientX × ScreenWidth / ClientSize.Width`（防零除，窗口模式比例=1 行为不变）。
5. `Client\MirScenes\Dialogs\NPCDialogs.cs`（NPCDropPanel_Click :1583）：唯一直用 `me.X/me.Y` 处改用 `CMain.MPoint`（已换算的逻辑坐标；窗口模式两者等价）。

窗口模式全链路行为不变（ClientSize==逻辑尺寸、比例=1、Windowed 本来就是 true），仅全屏链路变化。
