# 20261112F12设置面板内挂区块占位与稀有度本地化回滚

## 现象

- 用户要求在 F12（客户端设置面板 OptionDialog）中**先摆出内挂功能开关的纯 UI 区块**（勾选暂不实现功能），为二期自动喝药/自动捡物预留界面。
- 上一轮（怪物血条+BOSS 高亮）往 `Client\Localization\Chinese.json` 补的 MonsterType 四键被用户指出是**重复造车**：`MonsterType` 枚举成员本身就是中文（`普通级/勇士级/精英级`，Shared\Enums.cs@92-98），本地化查无键时回落枚举名即正确显示；且所加键名（Normal/Uncommon/Rare/Elite）与枚举成员名错位，属无效配置。

## 排查过程

1. **OptionDialog 结构实读**（MainDialogs.cs@2766-3245）：背景图 Title[411]=260×356；现有 8 组开关 + 2 音量条最低占到 y=313，底部仅剩 43px，放不下「标题+3 勾选框」（约 110px）→ 决定压缩现有布局腾空间。
2. **素材尺寸探针**：尝试写 tools\LibProbe 程序集探针，因 `Settings` 类 internal 不可访问（CS0122）放弃；改用 PowerShell 直接按 MLibrary v3 结构二进制读取 .Lib 文件，实测：Title[411]=260×356、Prguse2[450-467]=36×17（开关组）、Prguse[2086]=16×13/[2087]=16×12（勾选框）——素材全部可用。
3. **布局方案**：音量条组整体上移 12px、Observe/NewMove 两行上移 10px，腾出 y≥315 底部区块放内挂区块。
