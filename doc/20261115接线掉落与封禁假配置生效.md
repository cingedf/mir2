# 20261115接线掉落与封禁假配置生效

> 十问之⑩（server.exe 假配置全面排查）收尾项：Settings.cs 全字段五点核对（声明/Load/Save/GUI/消费）扫描后，发现 3 个「真·假配置」——字段有声明、有消费逻辑，但**无 Load 行**，改 Setup.ini 永远不生效（值恒等于默认值）。本次补 Load+Save，默认值不变=行为零变化，ini 从此生效。

## 现象

- 管理员改 Setup.ini 中 `IPBlockSeconds`（封 IP 时长）/`DropRange`（掉落散布范围）/`DropStackSize`（掉落堆叠上限）任一值，重启后行为不变——三者均无 Load 读取行，运行时恒为默认值 5/4/5。
- 同类半接线项（MaxPacket/GMPassword/PetSave/MonsterRarity 系）ini 手改已生效，仅缺 Save 回写或 GUI，不属本次范围。

## 排查过程

- 子代理对 Settings.cs 全字段五点核对（声明/Load/Save/GUI/消费），扫描全部分组（General/Network/Permission/Optional/Database/Game/Hero/Guild/Archive）+ 14 个子配置文件 Loader/Saver + ConfigForm 之外的 4 个 Settings 写入窗体（SystemInfoForm 42 字段/GuildInfoForm 10/BalanceConfigForm 11/GameShop 1）。
- 三字段消费证据：
  - `IPBlockSeconds`（Settings.cs:74，默认 5）→ Envir.cs:2285（每 IP 连接超限封禁时长）+ MirConnection.cs:228；
  - `DropRange`（:118，默认 4）→ HumanObject.cs:1522/1546/1599/1623、MonsterObject.cs:1293/1300/1320 等 10 处掉落坐标散布；
  - `DropStackSize`（:119，默认 5）→ ItemObject.cs:247/334 掉落堆叠。
- Load/Save 缺口定位：Network 段 Load（:398-403）只有 IPAddress/Port/TimeOut/MaxUser/MaxIP/MaxPacket，无 IPBlockSeconds；Network 段 Save（:693-697）连 MaxPacket 也无；Game 段 Load（:434-441）/Save（:728-735）有 ItemTimeOut/PlayerDiedItemTimeOut/PetSave/MaxBossTames/PKDelay，无 DropRange/DropStackSize。
- 其余排查结论（不改码）：RelogDelay 维持既有登记（5483fd4，仍零消费）；MaxPacket/GMPassword 缺 Save 属增强无必要；PetSave/MonsterRarity 系无 GUI 属 ini 级配置；用户疑似清单中 CheckUpdate/UpdateURL/StoragePath/BackupPath/BackupDelay/AccountExpire/ExpireDelay/DropErrorLog/ChatLog/CheatLog/LogSuffix/DefaultMode/AllowResetPassword/AllowCreateWizard/AllowCreateTaoist/AllowObservation/SummonRace/UseDarkStone/FriendlyName 均不存在于本仓（其他 Crystal 血统版本裁剪差异），无假配置风险。

## 修复内容（`Server\Settings.cs` 四处）

1. **Load（Network 段，:403 后）**：`IPBlockSeconds = Reader.ReadInt32("Network", "IPBlockSeconds", IPBlockSeconds);`
2. **Save（Network 段，MaxIP 后）**：`Reader.Write("Network", "MaxPacket", MaxPacket);` + `Reader.Write("Network", "IPBlockSeconds", IPBlockSeconds);`（顺手补 MaxPacket 回写——它有 Load 却在 Save 缺席，保存时会被 ini 旧值回漂）。
3. **Load（Game 段，PetSave 后）**：`DropRange = Reader.ReadInt32("Game", "DropRange", DropRange);` + `DropStackSize = Reader.ReadInt32("Game", "DropStackSize", DropStackSize);`
4. **Save（Game 段，PetSave 后）**：`Reader.Write("Game", "DropRange", DropRange);` + `Reader.Write("Game", "DropStackSize", DropStackSize);`

默认值全部不变（IPBlockSeconds=5 / DropRange=4 / DropStackSize=5），首次保存后 Setup.ini 会多出这四个键。

## 验证证据

- 行为零变化：默认值与原运行时值一致；消费点逻辑零改动。
- 上线验证：改 Setup.ini `Network/IPBlockSeconds=60`、`Game/DropRange=6`、`Game/DropStackSize=8` → 重启服 → 每 IP 连接超限封禁 60 秒、掉落散布 6 格、堆叠 8；配置窗保存后 ini 键保留不丢。
