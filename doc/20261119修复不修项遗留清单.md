# 20261119修复不修项遗留清单

## 现象

此前各轮审计登记了多项「不修」（多为风险/改动面顾虑）。本轮按新准则——数据为自建测试用户、无需顾虑数据风险，唯一约束是**行为等价、不引新 bug**——重新逐项甄别，把其中可安全收敛的 5 项修复，并明确仍不改的项及误报项。

## 排查过程

逐项读现场核实引用链（历史多次出现子代理误报）：

1. **MessageBox 硬类型转换**（MirMessageBox.cs:248）：Dispose 用 `(TextBox)Program.Form.Controls[i]` 硬转，而 Show 用 `as TextBox`。当前主窗体控件均为 TextBox 挂入的原生 TextBox，不可触发，但属未来防御缺口。
2. **KingPoints 跨战残留**（ConquestObject.cs:77/909）：`Dictionary<GuildObject,int> KingPoints` 是单场战争临时计分，StartWar 未清 → 征服模式下一战沿用上战积分错误判胜（当前「占领皇宫」模式不用该字典）。
3. **EndWar null Guild**（ConquestObject.cs:929-932）：征服模式控制点未被占领时 `item.Key.Guild == null`，作 Dictionary key → `ArgumentNullException`。
4. **GetRandomPoint 极小地图越界**（MapObject.cs:1019）：`Random.Next(map.Width - edgeoffset)`，edgeoffset=20，极小地图 Width≤20 时参数≤0 抛。
5. **ActiveDownloads 无锁**（AMain.cs）：`List<Download>` 由工作线程 Add（:259）与 UI 线程 InterfaceTimer_Tick 遍历/删除（:582/:623-646/:652/:669）并发访问，RemoveAt 与遍历交错可抛 `ArgumentOutOfRangeException`/计数错乱。

**甄别为误报、不改**：
- 灵物/怪物蛋非法 Shape NRE：`UserIntelligentCreature.GetInfo()`（IntelligentCreatureInfo.cs:166-172）自带 `if (Info == null) return null`，Enqueue(null) 被 MirConnection.Enqueue:700 `if (p == null) return` 吞，整链无 NRE；怪物蛋 GetMonsterInfo/GetMonster 已判空。
- GetRandomPoint else 分支 `Random.Next(-distance, distance+1)`：distance>0 时 min<max 恒合法（负值走另一分支），非缺陷。
- KingPoints null key：:809 已有 `MyGuild != null` 守卫，不成立。
- ProcessAuction 摘除 / MapObject 清 Effects：历史误报（待领取资产设计 / 无此字段）。

## 修复内容

1. **MessageBox**（MirMessageBox.cs:248）：`(TextBox)` → `as TextBox`，配合原有 `if (T != null && T.Tag != null)` 判空。
2. **KingPoints.Clear**（ConquestObject.cs StartWar:909）：开战前 `KingPoints.Clear();`。
3. **EndWar null Guild**（ConquestObject.cs:932）：控制点循环内判空前加 `if (item.Key.Guild == null) continue;`。
4. **GetRandomPoint**（MapObject.cs:1019）：`Random.Next(Math.Max(1, map.Width - edgeoffset))` + Height 同款；正常地图参数不变。
5. **ActiveDownloads 无锁**（AMain.cs）：加专用锁对象 `_activeDownloadsLock`，所有 List 结构访问（Add/Count/遍历/RemoveAt/索引读取）均加锁；**锁内只操作 List 与累加局部量 currentBytes/currentFile/concurrentCount，绝无 MessageBox/Launch/Close/Invoke 等 UI 操作**，避免持锁重入死锁；锁外再访问 UI 控件。行为等价：并发快照语义，正常单线程表现不变。

**仍不改（登记利弊）：**
- 任务 Remove(QuestInfo) 运行期清玩家状态：需遍历全服在线玩家+账号任务字典，改动面大；运行期删任务为 GM 低频操作，重启后孤儿判定本就过滤。
- GM TestServer=True 全开（30+ 处）/Setup.ini 残留口令：生产配置 False；源码已禁用口令提权，配置不改不影响安全。
- 攻城战其余 8 个 P2：征服模式/配置驱动，当前「占领皇宫」模式不触发。
- CompleteMapMovement 双轨制：踩传送点绕过 Teleport 管线守卫，但改动面大、行为等价风险高，属设计层改造。
- F5 损坏档容错：涉及启动流程，选错备份风险高；自建用户可人工恢复。
- F1 Saving 并发互斥：加 Saving=true 与 shutdown 等待存在互锁风险。
- 多开配置写回覆盖 / 建图并行二期 / 隔墙 AI / PBKDF2 迁移：需重构 Save 语义 / 风险收益不成比例 / 影响怪物手感 / 改迭代使口令需迁移。
