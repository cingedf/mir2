# 20261119修复HTTP服务安全缺陷

## 现象

新维度审计（HTTP 远程接口安全路线）发现 HTTP 服务存在 1 项 P0 路径穿越、多项 P1 认证/日志/存档缺陷及健壮性问题。该服务默认关闭（`StartHTTPService=false`、仅绑定 `127.0.0.1:5679`），管理员开启后才生效，但缺陷真实存在。

## 排查过程

逐项读 HttpServer.cs / HttpService.cs / Envir.cs 全文与调用链核实（历史多次误报，必须验证引用链）：
- **P0 路径穿越**：`AddNameList`（HttpServer.cs:98-114）`fileName = Path.Combine(Settings.NameListPath, request.QueryString["fileName"])`，`fileName` 直接取查询参数零校验——绝对路径会丢弃 base、`..\` 可逃逸到任意目录，导致任意文件创建/追加写。
- **P1 零认证 fail-open**：HttpService.cs:63-72 `if (RemoteEndPoint != null) { if (clientIp != TrustedIP) deny; }`，对端为 null 时整体跳过校验。
- **P1 明文密码入日志**：HttpService.cs:57 记录 `request.RawUrl`，而 `/newaccount` 通过 GET 传 `psd/question/answer`（HttpServer.cs:50-55）。
- **P1 CreationIP=null**：HttpServer.cs:56 `ip` 取查询参数，Envir.cs:2664 `CreationIP = ip`，缺参为 null，AccountInfo.cs:229 `writer.Write(CreationIP)` 对 null string 抛异常，每次存档被吞 → 账号档永久无法写入。
- **P1 HTTPLogin 明文比对**：Envir.cs:2852 `CompareOrdinal(account.Password, Password)` 用明文，而正常登录是 HashPassword 后比对——但全仓 grep 确认 **HTTPLogin 无任何调用点（死代码）**。
- **P2 各项**：异常堆栈回显、POST 响应不关、监听器生命周期（`new Thread` 非后台 / IsSupported 与 new HttpListener 在 try 外 / Stop 不 Close）、ToLower 在 if 分支内。

## 修复内容

**HttpServer.cs：**
1. P0 路径穿越：`AddNameList` 改为 `Path.GetFileName(fileName)` 取纯文件名 + `Path.GetFullPath` 规范路径校验必须落在 `NameListPath` 根内（`StartsWith(root, OrdinalIgnoreCase)`）+ 玩家名 id 白名单（禁 `/ \ \r \n`、限长 30）。
2. P1 空 msg NRE：`/broadcast` 改 `string.IsNullOrEmpty(msg) || msg.Trim().Length < 5`。
3. P2 异常回显：catch 内固定文案 `"request error"`，异常详情写日志。
4. P2 POST 响应：OnPostRequest 补 `WriteResponse(response, string.Empty)` 关闭输出流。
5. P2 ToLower：`ToLowerInvariant()` 移出 if 分支，统一归一化。
6. P2 生命周期：监听线程 `IsBackground=true`；Stop 用 `_thread.Join(2000)` 替代 `Sleep(1000)`。

**HttpService.cs：**
7. P1 fail-closed：对端 IP 为 null 或不在白名单一律拒绝（`clientIp == null || clientIp != TrustedIP`）。
8. P1 日志脱敏：只记 `request.Url.AbsolutePath`，不再记 RawUrl 明文查询串。
9. P2 监听器：IsSupported 判断与 `new HttpListener()` 纳入 try；Stop 补 `Close()`/`Dispose`（try/catch 包裹）。

**Envir.cs：**
10. P1 CreationIP：`CreationIP = ip ?? string.Empty`。

**不修（登记利弊）：**
- **HTTPLogin 明文比对**：全仓无调用点的死代码，不修不影响任何实际路径。若要修需加 `HashPassword` 收敛或删除方法，改动无收益。鉴权缺陷无暴露面。
- **/broadcast 未授权**：HTTP 服务整体依赖 IP 白名单鉴权，broadcast 与其它端点同级，单独加 GM 鉴权属设计层改造。

## 验证证据

- `dotnet build Server.MirForms\\Server.csproj -c Release`：**0 警告 0 错误**；
- 行为复核：合法 /newaccount /addnamelist /broadcast 请求正常处理；白名单 IP 校验更严格（fail-closed）；日志不再泄露密码；正常账号 CreationIP 为空串时存档不再异常。
- 待实测：开启 HTTP 服务后各端点功能正常；路径穿越尝试被拒绝；缺参请求不再崩溃/回显堆栈。
