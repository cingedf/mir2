# 20261115汉化物品信息窗枚举列头与宝石视图映射

> 汉化清单 H2/H3/H4（用户指令：批量列头汉化逐个落盘不遗漏；@717@ 完全自主不询问）。基础设施（`ToLocalizedServerString` + 服务端 Chinese.json Enum 段 60 键）已在前两个 commit 落地（e408dad/b1b01a3），本窗体直接消费。

## 现象

- server.exe「物品信息」窗体（ItemInfoFormNew）三套动态列头显示英文：Stat 属性列（MinAC/MaxDC/HP…）、BindMode 绑定限制列（DontDrop/BindOnEquip…16 键）、SpecialItemMode 特殊模式列（Paralize/Teleport…12 键）。
- 隐藏耦合：宝石视图（宝玉神珠上下文列头映射 MapHeaderText）按 **HeaderText 英文串**匹配——若仅汉化列头，映射 switch 全部 miss，宝石视图功能静默失效。

## 排查过程

- 三处列头现场：CreateDynamicColumns（161-217）——Stat 列（167-186，SeperateCamelCase→HeaderText=`{strKey} {sign}`，sign=Percent/Multiplier 判断）；BindMode CheckBox 列（188-201，HeaderText=bind.ToString()）；SpecialItemMode CheckBox 列（203-216，同构）。
- 数据链零回归论证：填充（row["Stat"+stat]/["Bind"+bind]/["Special"+special]）、CSV 导入导出、单元格校验全部按 **列名 Name**（"Stat"+枚举名/"Bind"+枚举名/"Special"+枚举名）——HeaderText 仅显示层，改显示不影响任何写盘/回读链。
- MapHeaderText（1128-1188）取证：先存 `_defaultItemHeaderMappings`（列序→HeaderText），再按 HeaderText 字符串 switch 填 `_gemItemHeaderMappings`（12 个 `nameof(SpecialItemMode.X)` → 英文部位名 + 4 个硬编码英文串——即 SeperateCamelCase(暴击伤害)="Critical Damage"、(暴击率)="Critical"、(反弹伤害)="Reflect"、(法力值消耗百分比)="HP Drain %" 的拆分产物）；SwapGemContext（1190-1213）切换显示（切回默认用缓存的原文=汉化后自然显示中文）。
- 触发点：筛选=宝玉神珠或选中行为宝玉神珠时 swap（黄色高亮）。右键批量属性提示（989-1004）读 HeaderText——纯显示自动受益。

## 修复内容（`Server.MirForms\Database\ItemInfoFormNew.cs` 三处）

1. **H2 Stat 列头**（167-168）：`strKey = stat.ToLocalizedServerString()`（原 SeperateCamelCase 链删除；sign 逻辑保留）。
2. **H3 BindMode/SpecialItemMode 列头**（194/209）：`HeaderText = bind/special.ToLocalizedServerString()`（列名保持英文枚举名不动）。
3. **H4 MapHeaderText switch 改造**（1139 起）：匹配键从 `entry.Value.Trim()`（HeaderText 串）改为 **列名 Name**——`switch (itemInfoGridView.Columns[entry.Key].Name)`：12 个特殊模式列 = `"Special" + nameof(...)`；4 个 Stat 列 = `nameof(Stat.暴击伤害)` 等（中文枚举成员 nameof 合法，Name="Stat"+中文名）。**宝石视图目标标签一并汉化**（顺手汉化规则）：Weapon→武器/Armour→衣服/Helmet→头盔/Necklace→项链/Bracelet→手镯/Ring→戒指/Amulet→护身符/Belt→腰带/Boots→鞋子/Stone→宝石/Torch→照明/Max Stats (All)→全属性上限/Base Rate %→基础概率/Success Drop→成功概率/Max Gem Stat→宝石属性上限。

## 验证证据
