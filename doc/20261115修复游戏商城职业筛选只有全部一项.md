# 20261115修复游戏商城职业筛选只有全部一项

## 现象
- 游戏商城窗体职业筛选下拉只显示「全部职业」一项，缺少「战士/刺客/道士/法师/弓箭手」。

## 排查
- 上一轮（aee9e4f）将职业筛选改为「数据驱动」：遍历 GameShopList 去重后列出数据中实际出现的 Class 值。
- 实测商城数据所有条目 Class 均为 "All"（商店物品本就全职业通用）→ 去重后只剩哨兵「全部职业」一项。
- 结论：筛选列表不应依赖数据内容，应固定列出全部六个职业选项。

## 修复
- GameShop.cs LoadGameShopItems：
  - 哨兵「全部职业」(ValueMember=null，全选语义不变) 之后固定追加 战士/刺客/道士/法师/弓箭手 五项（ValueMember=英文原值）；
  - 数据驱动逻辑保留作兜底：seenClasses 预置六个固定值，数据中出现固定集之外的 Class 值仍会追加显示；
  - 显示统一走 ClassDisplay（未知值回退原样），UpdateGameShopList 按 ValueMember 比对的过滤逻辑未动。

## 验证
- dotnet build Server.MirForms\Server.csproj -c Release → 0 警告 0 错误。
- 运行验证点：职业筛选显示 全部职业/战士/刺客/道士/法师/弓箭手 六项；选「战士」只列 Class=Warrior 的条目，
  选「全部职业」恢复全列；分类筛选行为不变。
