# 20261113修复主循环龙系统处理异常隔离

> ⑤容错加固第二步第三段。承接：切片每对象（36b1b84）、每地图（e909487）、ThreadLoop 恢复式容错（aba3b12）。

## 现象

WorkLoop 主循环 `DragonSystem?.Process()`（龙系统：攻沙龙影/龙血等全局系统）抛异常时直接冒泡到内层致命 catch → 全服踢人停机。

## 排查过程

- 现场核查：DragonSystem?.Process() 位于每地图段之后、Envir.Process() 之前，无隔离。
- 引用逻辑链核查：DragonSystem 为 Envir 单例字段（DragonSystem?.Process() 空条件即证明可空），**单实例无逐项维度**，节流键用固定常量 `WorkLoopDragon` 即可。
- `?.` 空条件语义保留：改为 `if (DragonSystem != null)` 包裹，null 时与原实现一样整段跳过。

## 修复内容

**`Server\MirEnvir\Envir.cs`**（WorkLoop 龙系统段，单文件）：

```csharp
if (DragonSystem != null)
{
    try
    {
        DragonSystem.Process();
    }
    catch (Exception ex)
    {
        ErrorThrottle.Notify("WorkLoopDragon", () =>
            MessageQueue.Enqueue($"主循环龙系统处理异常 => {ex}"));
    }
}
```

- 复用 ErrorThrottle 节流器；`Process()`（Envir 全局段）不在本段范围（下一独立段位）。

## 验证证据

- `dotnet build Server\Server.Library.csproj -c Release`：**0 警告 0 错误**。
- 逻辑复核：null 时跳过（与原 `?.` 等价）、异常只影响龙系统段本身，后续主循环段（Envir.Process/存档/公告）不再被其异常波及。
