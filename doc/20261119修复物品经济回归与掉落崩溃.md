# 20261119修复物品经济回归与掉落崩溃

## 现象

子代理对「物品/掉落/经济系统」维度深度审计，回报 1 项 P0（**前批修复引入的回归**）、4 项 P1、2 项 P2：

1. **P0·NPC 商店刷物回归**（前批 02ea817 引入）：前批为「不污染共享商品模板」删掉了 `else goods.Count = count;`，但计价函数 `Price()`（= 单价×Count）仍按共享模板 Count（默认 1）算 → 玩家请求 50 个只付 1 份钱、实发 50 个。普通客户端即可触发，无需伪造包。
2. **P1·掉落表插入文件死循环**：`DropInfo.ParseInsert` 无自引用/循环访问防护（NPCScript 同名方法已修，此处同类遗漏）→ 配置互相插入时启动期死循环。
3. **P1·合成金币 uint 回绕**：`recipe.Gold(uint) × count` 在 uint 域乘法回绕（65536×65535 真值 42.9 亿回绕成 65535）→ 大额合成少扣金币。
4. **P1·金币掉落除零/负数刷钱**：`MaxDropGold` 从 ini 读入配 0 时 `gold / MaxDropGold` 除零中断怪物 Process；金币区间 `(int)(Gold + Gold/2)` uint 回绕转负 → `Random.Next(负,负+1)` 抛异常，或负返回值强转 uint 成巨额金币。
5. **P2·Clone 引用共享/字段遗漏**：`UserItem.Clone()` 浅拷 Slots/Awake、漏拷 RefinedValue/RefineSuccessChance → 拆分后两堆叠共享觉醒对象、精炼属性蒸发。
6. **P2·部分堆叠丢属性**：红名死亡掉落/丢弃/出售/英雄死亡掉落的分堆路径仍用 `CreateFreshItem`（只拷 Info），掉落物丢失强化/觉醒/耐久。

- 逐项读现场核实子代理报告（历史多次出现误报，必须验证引用链）：
  - P0：`Buy()` 计价 `cost=goods.Price()`（:1245）与实发 `item.Count=(ushort)purchaseCount`（:1256）确认分离；goods 来自 `Goods[i]` 共享模板；`Price()`（ItemData.cs:521-547）依赖 Count，确属回归。
  - P1-3：`recipe.Gold` 为 uint（RecipeInfo.cs:29），count 可达 65535（:1423），校验(:1336)与扣款(:1508)均用 uint 乘法，回绕实锤。
  - P1-4A：grep 确认 `Settings.MaxDropGold` 全仓仅 MonsterObject.cs 两处消费（Settings.cs:236 默认 2000、:540 从 ini 读、:819 写），配 0 即除零。
  - P1-4B：MonsterInfo.cs:546-557 uint 回绕 + `(int)` 强转可能负，`Random.Next(lower, upper+1)` 抛异常/负值强转 uint 刷钱，实锤。
  - P2-5：`Clone()`（ItemData.cs:709-737）`Slots=Slots`/`Awake=Awake` 共享引用，RefinedValue(:292)/RefineSuccessChance(:294) 未拷；Awake 类 :904-925 有 `readonly List<byte> listAwake` 需拷贝构造。
  - P2-6：五处分堆现场（PlayerObject.cs:761/7923/8544、HumanObject.cs:1520/1597）均 `CreateFreshItem(原.Info)`，确属属性蒸发同类遗漏。
- 已核查非缺陷（子代理声明）：WinGold 余数、DropGold 0 堆、MergeItem 自合并、Craft 除零前置、SplitItem Clone、NPCScript.ParseInsert 循环防护、ChatItem 正则、CheckAwakening 预检（均前批已修）。

## 修复内容

1. **P0·按实发数量计价**（NPCScript.cs Buy :1245）：增加临时副本 `priceItem`，非买回/二手时 `priceItem = goods.Clone(); priceItem.Count = (ushort)purchaseCount;`，cost/baseCost 均按 priceItem.Price() 计算——不回写共享模板，按玩家实发数量收费。买回/二手路径沿用自身 Count（等价）。
2. **P1·掉落表循环防护**（MonsterInfo.cs ParseInsert :486）：移植 NPCScript 版 `HashSet<string> processed`(OrdinalIgnoreCase) + `Path.GetFullPath` 去重、`File.Exists` 缺失时中文日志提示并跳过。
3. **P1·合成金币 long 化**（NPCScript.cs Craft :1336/:1508）：`ulong totalGold = (ulong)recipe.Gold * (ulong)count` 用于校验与扣款，扣款 `uint goldCost = (uint)totalGold`（已校验不超玩家金币，强转安全）。
4. **P1·掉落除零兜底**（MonsterObject.cs DropGold :1313）：局部 `uint maxDrop = Settings.MaxDropGold == 0 ? 1u : Settings.MaxDropGold;` 替换分母与末堆基数，不改配置写回。
5. **P1·金币区间 long 化**（MonsterInfo.cs AttemptDrop :546）：long 中间量计算 lower/upper，钳制 `[0, int.MaxValue-1]`，lower>upper 时回退 lower=upper，正常小配置等价。
6. **P2·Clone 深拷补漏**（ItemData.cs）：Awake 新增拷贝构造（`Type` + `listAwake.AddRange`）；Clone 改 `Slots=(UserItem[])Slots.Clone()`、`Awake=new Awake(Awake)`，补 `RefinedValue`/`RefineSuccessChance`。
7. **P2·分堆保留属性**（PlayerObject.cs 3 处 / HumanObject.cs 2 处）：`CreateFreshItem(原.Info)` → `原.Clone()` + 重设 `UniqueID = ++Envir.NextUserItemID`（避免与原堆叠撞号）+ `Count = count`。
