# 20261116Map编辑器布局可拖动与图库页布局修复

## 现象

用户实测五项修复后的地图编辑器，提出两点布局问题（附截图）：

1. **各标签页左右区域需要可拖动的分割条**（地图页、图库页等），目前宽度固定无法调整。
2. **4 个图库标签页（WemadeMir2/ShandaMir2/WemadeMir3/ShandaMir3）布局不对**：中间显示数字编号的区域（LibListView 图标区）太靠上、偏小，顶部被标签行压住，高度不足。

## 排查过程

### 布局现状核实（Main.Designer.cs 逐区块）

- **主窗体**：tabControl1 Dock=Left 固定宽 1729；TreeViewBox（地图文件树）绝对定位 (1729,54) 宽 253——两者之间无分割条，宽度比例永远固定。
- **地图页**：tableLayoutPanel1 Dock=Left（MapPanel Percent100 + v/h 滚动条 Absolute20），随 tab 宽度不自动填满。
- **4 个图库页**：控件全部绝对定位——LibListBox Dock=Left（宽 175~224）、LibListView Anchor 四边但 Location y=2~5 贴顶、Size 1331x1010（右侧留白大）；**关键缺陷：右侧 宽度/高度/偏移X/偏移Y 标签 x=1617~1745，超出 tab 实际宽度 1721，Anchor=Top|Right 使其被裁剪到右边缘外不可见**——这是"右边快看不到"的直接根源；picXxx 同样 Anchor=Top|Right 贴边。
- **图块页**：TileslistView Dock=Left 宽 1539（占几乎全宽）+ picTile 绝对定位 (1563,24)——两者重叠，picTile 实际被 ListView 盖住。
- **物件页/图块裁剪页**：已是 SplitContainer（splitContainer1/2/3），可拖，无需改动。
- **帮助页**：中文 RichTextBox Dock=Fill，无需改动。

### 运行时依赖复核（保证改动安全）

grep Main.cs 确认：
- 无任何对 picTile/picXxx/TreeViewBox/tabControl1/LibListView/tableLayoutPanel1 的 Size/Location/Bounds/Dock/Anchor/SizeMode 运行时赋值；只有 `picXxx.Image = selectLibMImage.Image`（L1855/2148/2169/2189/3143/3164/3185/3205）与 `picTile.Image = GetTilesPreview(...)`（L4546）——纯内容赋值，控件换父级/改 Dock 不受影响。
- MapPanel 只读自身 Width/Height 计算渲染偏移（安全）。
- MapPanel_Resize（L572-580）已挂 Resize 事件：Device.Clear + Present + DXManager.ResetDevice()（含 Device null 守护）——拖动主分割条改变 MapPanel 尺寸时会自动重置 DX 设备，渲染面安全。

## 修复内容（全部在 Main.Designer.cs）

### 1. 主窗体加主分割条 splitMain（解决"地图页左右可拖"）

- 新增 `splitMain`（SplitContainer，Orientation=Vertical）：**Panel1=tabControl1（Dock 改 Fill）、Panel2=TreeViewBox（去绝对定位改 Dock=Fill）**。
- splitMain：Dock=Fill、SplitterDistance=1729（保持原比例）、Panel2MinSize=180、SplitterWidth=6。
- Main.Controls.Add 顺序改为 splitMain→toolStrip1→menuStrip1。
- 拖动主分割条 = 调整左侧标签页编辑区与右侧地图文件树的宽度。

### 2. 地图页自适应

- tableLayoutPanel1 Dock 从 Left 改 **Fill**：地图渲染区随 splitMain 宽度变化自动伸缩，v/h 滚动条由 TableLayoutPanel 布局自动贴边。

### 3. 4 个图库页重构（解决编号区贴顶过小 + 右侧被裁 + 可拖）

每页新增一个 SplitContainer（splitWemdeMir2/splitShandaMir2/splitWemdeMir3/splitShandaMir3）：

- `splitX.Dock=Fill`、SplitterWidth=6、Panel2MinSize=200、SplitterDistance=各页原 ListBox 宽（200/175/224/220）。
- **Panel1 = LibListBox**（Dock 改 Fill，加 IntegralHeight=false 防止列表高度取整留缝）。
- **Panel2 = 4 个标签（宽度/高度/偏移X/偏移Y）+ picXxx + LibListView**：
  - 标签坐标从 x=1617~1745（超出 tab 宽被裁）统一改到 Panel2 内 x=1380 / 1265，右移问题彻底消除；
  - picXxx 移入 Panel2 (1270,125~135)；
  - **LibListView 去掉 Anchor 绝对定位，改 Dock=Fill**——自动占满 Panel2 全部空间，不再贴顶偏小。
- 拖动页内分割条 = 调整左侧图库文件列表与右侧编号缩略图区的宽度。

### 4. 图块页重构

- 新增 `splitTiles`：Panel1=TileslistView（Dock=Fill）、Panel2=picTile（Dock=Fill、SizeMode 从 AutoSize 改 **Zoom**，大图预览自动缩放适配）；SplitterDistance=1000、Panel2MinSize=100、SplitterWidth=6。
- 原两控件重叠、picTile 被盖住的问题一并消除。

### 5. 未改动项

- 物件页 splitContainer1/2、裁剪页 splitContainer3 原本就可拖，不动。
- 帮助页 RichTextBox Dock=Fill 不动。
- LibListView 的 ImageList 保持 64x64（预览图由 GetPreview 生成 64x64 居中缩放，改 ImageList 尺寸只会拉伸不会更清晰，避免无收益变量）。
- 6 个新 SplitContainer 均加中文注释说明用途；SuspendLayout/BeginInit、ResumeLayout/EndInit、字段声明区同步补全（Designer 规范成对结构）。

## 使用说明

| 位置 | 分割条 | 拖动效果 |
|---|---|---|
| 整个窗口右侧 | splitMain 主分割条 | 左侧标签页编辑区 ↔ 右侧地图文件树 宽度 |
| 地图页 | （随主分割条） | 地图渲染区随窗口自适应，滚动条自动贴边 |
| 4 个图库页 | splitX 页内分割条 | 左侧图库列表 ↔ 右侧编号缩略图+预览区 宽度 |
| 图块页 | splitTiles 页内分割条 | 左侧图块编号 ↔ 右侧大图预览 宽度 |
| 物件页/图块裁剪页 | 原有分割条 | 原本可拖，未改动 |
