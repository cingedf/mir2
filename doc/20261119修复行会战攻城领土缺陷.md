# 20261119修复行会战攻城领土缺陷

## 现象

子代理对「行会战/攻城/领土系统」维度深度审计，回报 2 P1 + 8 P2。多数为配置/时序/权限缺陷，其中 2 项 P1 可导致定时停机或领地永久锁死。逐项读现场甄别后，7 项属实修复，1 项登记不修。

1. **P1-1 经典模式计分 NRE**（ConquestObject.cs）：攻城经典模式下 PalaceMap 为空或唯一在场玩家无公会时，计分逻辑解引用 null → 异常每 10 秒触发一次 → 熔断停机。
2. **P1-2 解散行会领地永久锁死 + 悬空引用**（Envir.cs DeleteGuild）：只从列表移除行会对象，不释放领地（GTMapList.Owner 永远指向已解散行会，领地无法再购买），且 GuildsAtWar / Conquest 残留对已解散行会的强引用与陈旧状态。
3. **P2-5 EndGT 驱逐漏项**（GuildObject.cs）：正序遍历领地玩家列表并 Teleport（会移除元素）→ 跳过部分玩家未被驱逐。
4. **P2-1 StartConquest 无权限**（NPCSegment.cs）：任何玩家可强制启停攻城。
5. **P2-2 金库/税率越权**（NPCSegment.cs）：TakeConquestGold / SetConquestRate 无会长独占校验。
6. **P2-3 BuyGT 副会长覆盖会长**（NPCSegment.cs）：副会长购买领地时把会长名写进 Leader 字段，覆盖真正的会长。
7. **P2-4 ExtendGT 续租意外挂牌出售**（NPCSegment.cs）：续租时把 Price 设为 10000000，导致领地被意外挂牌出售。
8. **P2-6 CheckConquest PalaceMap 空引用**（PlayerObject.cs）：前置未判空。

## 排查过程

- P1-1：读经典模式计分支，确认 PalaceMap = GetMap(:276) 可能为 null（上面 :386 的判空只保护前段，计分在后段仍解引用）；`takingGuild` 由在场玩家公会推导，唯一玩家无公会时保持 null，原 :897 `.Guildindex` 解引用崩溃。
- P1-2：读 DeleteGuild(:4545) 确认只 `Guilds.Remove` + `GuildList.Remove`。GuildObject.EndGT(:857-889) 会置 Owner=None/Price=BuyGTGold/Leader=None + 驱逐玩家 + 清行会侧 GTIndex/GTRent/GTKey，解散前应调用。战争/攻城引用结构：GuildsAtWar 含 GuildA/GuildB（EndWar 清双方 WarringGuilds）；`Conquests` 是 List<ConquestObject>（含可写 .Guild），而 `ConquestList` 是 List<ConquestGuildInfo>（无 .Guild）——第一次误用 ConquestList 导致编译 CS1061，已改 Conquests。
- P2-5：Teleport 会从 map.Players 移除玩家，正序遍历 Count 动态缩小 → 漏项。
- P2-1/2：对照同文件 OpenGate(:4664) 的会长/GM 校验模板，这两处缺失。
- P2-3：对照 PlayerObject.cs:11056 已修的同类（副会长写 Leader2 而非 Leader）。
- P2-4：续租逻辑只需延长租期，Price 赋值与续租语义无关。
- P2-6：CheckConquest 在 PalaceMap 为空时仍进入判定链。

## 修复内容

1. **P1-1**（ConquestObject.cs）：:878 经典 case 开头 `if (PalaceMap == null) break;`；:895 `if (guildCounter == 1 && takingGuild != null && takingGuild != Guild)`。
2. **P1-2 / P2-7**（Envir.cs DeleteGuild:4545）：开头 `if (guild.GTIndex >= 0) guild.EndGT();`（GTIndex 默认 -1）；倒序遍历 GuildsAtWar 对含 guild 的 war 调 EndWar() + RemoveAt(i)；遍历 `Conquests` 置 `Conquests[i].Guild = null`；`guild.Conquest = null`；再移除行会。
3. **P2-5**（GuildObject.cs EndGT:875）：驱逐循环改倒序 `for (j = map.Players.Count - 1; j >= 0; j--)`。
4. **P2-1**（NPCSegment.cs StartConquest:4603）：case 开头 `if (!player.IsGM) return;`（强制启停仅 GM，正常开战走 ScheduleConquest）。
5. **P2-2**（NPCSegment.cs TakeConquestGold:4576 / SetConquestRate:4590）：各加 `if (!player.IsGM && (player.MyGuild == null || player.MyGuild.Guildindex != conquest.GuildInfo.Owner || player.MyGuildRank != player.MyGuild.Ranks[0])) return;`。
6. **P2-3**（NPCSegment.cs BuyGT:3324）：副会长写 `GTmap.Leader2`（原误写 Leader），else 置空。
7. **P2-4**（NPCSegment.cs ExtendGT:3418）：删除 `GTmap.Price = 10000000;`。
8. **P2-6**（PlayerObject.cs:14630）：`if (checkPalace && CurrentMap.tempConquest.PalaceMap != null && ...)` 加前置判空。

**不修（登记利弊）：**
