# 20261117修复社交存档P2状态一致性与失败重试

## 现象

第五轮深度审计社交系统 + 存档/DB 维度登记的 5 项 P2 遗留缺陷：

1. **F3 婚姻冷却旧求婚绕过**（PlayerObject.cs MarriageReply）：旧求婚在发起时尚未离婚，接受时才判定，仅检查 `Married != 0`，未在接受瞬间校验双方离婚冷却期 → 冷却期内仍可再婚。
2. **F4 行会仓库领取不回包**（PlayerObject.cs GuildStorageItemChange case1）：领取成功（Type=1 全服广播）后未给请求方 `Enqueue(p)`，客户端请求格持续锁定。
3. **F5 领地副会写错字段**（PlayerObject.cs:10996-10998）：把副会长（`Members[1]`）写进 `gt.Leader` 主字段覆盖会长，`Leader2` 副会字段留空。
4. **备份秒级覆盖**（Envir.cs:1164/1534）：存档备份名精确到秒，同一秒内多次存档后一次先删同名备份再 Copy → 前次备份被覆盖，丢失回滚点。
5. **NeedSave 失败不复位**（Envir.cs EndSaveGuildsAsync/EndSaveConquestsAsync）：SaveGuilds/SaveConquests 提前置 `NeedSave = false`，异步写盘失败时 catch 仅记日志，该对象永不重试存盘 → 坏档长期不修复。

## 排查过程

- F3：读 MarriageReply 全流程（:13755-13794），确认 `MarriageCooldownAfterDivorce`/`MarriageCooldownAfterDivorceOther` 两个 key 及中英文文案已在 Shared\Language.cs:1555/1559/2339/2343 存在，`Settings.MarriageCooldown`（默认 7 天，Config 段可配）已接线；
- F4：比对同方法其他失败分支均 `Enqueue(p)`，成功分支独缺；仓库类型 p.Type=3+type=4 failretrieve 仅解锁格不搬物，与 Type=1 广播同型无视觉冲突；
- F5：GTMap.cs:18 `public string Leader2 = string.Empty;` 存在且参与序列化；先例 GuildObject.cs:305-312；
- 备份名：全仓无按 .bak 文件名回读的逻辑，加 GUID 后缀不影响恢复流程；
- NeedSave 复位：guild 侧存盘文件名 `i + ".mgdn"`（i=GuildList 索引）、conquest 侧 `Info.Index + ".mcdn"`，故 catch 内从 `fStream.Name` 解析出的整数分别用于 GuildList 索引 / ConquestList.Info.Index 匹配。

## 修复内容

1. **PlayerObject.cs MarriageReply**：两处已婚检查后、赋值前插入双向冷却校验——自己侧 `Info.MarriedDate.AddDays(Settings.MarriageCooldown) > Envir.Now` 用 `MarriageCooldownAfterDivorce`，对方侧 `MarriageProposal.Info.MarriedDate...` 用 `MarriageCooldownAfterDivorceOther`；命中均 ReceiveChat + `MarriageProposal = null` + return。
2. **PlayerObject.cs GuildStorageItemChange case1**：`MyGuild.NeedSave = true;` 后补 `Enqueue(p);`。
3. **PlayerObject.cs 领地归属**：`if (Members.Count > 1) gt.Leader2 = Members[1].Name; else gt.Leader2 = string.Empty;`（原写 `gt.Leader`，保留 `gt.Leader = Members[0].Name` 主会）。
4. **Envir.cs 备份名**：Database/Accounts 两处文件名末尾加 `-{System.Guid.NewGuid():N}`（全限定 System.Guid）。
5. **Envir.cs EndSaveGuildsAsync/EndSaveConquestsAsync**：catch 内 `MessageQueue.Enqueue(ex)` 后加 try 复位块——guild 侧 `int.Parse(Path.GetFileNameWithoutExtension(fStream.Name))` 索引 GuildList 置 NeedSave=true；conquest 侧按 Info.Index 匹配 ConquestList 置 NeedSave=true；二次 catch 记日志。
