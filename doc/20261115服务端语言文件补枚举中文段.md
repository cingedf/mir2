# 20261115服务端语言文件补枚举中文段

> 顺带汉化线第二步（承接 `e408dad`「20261115服务端枚举本地化基础设施」）：给服务端语言文件 `Server.MirForms\Localization\Chinese.json` 的空 Enum 段填充 60 个中文映射，server.exe 编辑器 UI（经 `ToLocalizedServerString`）即可显示中文。

## 现象

- 基础设施落地后，`ServerTextMap.Enum` 仅有预填充的英文原名（`Stat_MinAC → "MinAC"`），服务端中文 json 的 `"Enum": {}` 为空段——UI 仍显示英文。需补中文映射数据。

## 排查过程

- 目标键集=基础设施预填充的 12 类枚举中「英文成员名」者：Stat 英文键 13（MinAC/MaxAC/MinMAC/MaxMAC/MinDC/MaxDC/MinMC/MaxMC/MinSC/MaxSC/HP/MP/Hero）+ RequiredType 12 + BindMode 17 + SpecialItemMode 13 + LightSetting 5，共 **60 键**（中文枚举成员如 攻击力提升/工艺材料 不需要映射，原生显示中文）。
- 文件解析要点：该 json 存在大小写冲突键（YouDoNotHaveEnoughBaseMac/MAC），PowerShell `ConvertFrom-Json` 会报错——改用 Python `json.loads(object_pairs_hook)` 容忍重复键（保留首现，与 .NET 字典语义一致）后整体重序列化。
- 确认文件为 git 跟踪（`git ls-files` 命中），改动可随 commit 入库；deploy 侧 `Server\Localization\Chinese.json` 为运行区副本需同步。

## 修复内容

1. **`Server.MirForms\Localization\Chinese.json`**：`"Enum": {}` → 60 键中文映射——
   - Stat：MinAC=下限防御、MaxAC=上限防御、MinMAC=下限魔御、MaxMAC=上限魔御、MinDC=下限攻击、MaxDC=上限攻击、MinMC=下限魔法、MaxMC=上限魔法、MinSC=下限道术、MaxSC=上限道术、HP=生命值、MP=魔法值、Hero=英雄；
   - RequiredType：Level=等级、MaxLevel=最高等级、其余 Max/Min 系列=对应上下限攻防魔道；
   - BindMode 17 键：无/死亡不掉落/不可丢弃/不可出售/不可仓存/不可交易/不可修理/不可升级/丢弃即销毁/死亡破碎/拾取绑定/不可特殊修理/不可作婚戒/不可租借/不可拆解/不可邮寄/英雄不可用；
   - SpecialItemMode 13 键：无/麻痹/传送/护身戒指/保护/复活/力量/火焰/治愈/探查/技能/不损耗持久/瞬移；
   - LightSetting 5 键：普通/黎明/白天/黄昏/夜晚。
2. **`C:\1.40\mir2-deploy\Server\Localization\Chinese.json`**：同内容同步（运行区，不进 git）。
