# 20261119修复配置加载健壮性

## 现象

配置加载健壮性维度审计回报 14 项缺陷（3 P1 + 11 P2）。这些配置均为 GM 可控（ini / txt / DB 编辑器），玩家无法直接构造，但一个错别字/空行即可导致启动期崩溃、掉落经济破坏或玩家侧崩服：

1. **P1-1 配方文件裸 Parse**：非数字 amount/chance/gold → `FormatException` 启动期崩溃。
2. **P1-2 配方纯空格行越界**：Split(RemoveEmptyEntries) 返零长数组 → `data[0]` 越界。
3. **P1-3 BaseStats.ini 公式枚举裸 Parse**：非法枚举名 → `ArgumentException` 启动失败。
4. **P2-1 配方节头 Substring 负长度**、**P2-8~11 编辑器 FromText 守卫长度不足**：短行访问越界索引 → 编辑器崩。
5. **P2-2 配方 flag 越界**：flag > Flags.Length → 玩家合成时 `Flags[flag]` 索引越界崩。
6. **P2-3/P2-4 掉落表短 token Substring(2)** 负长度 → 加载崩。
7. **P2-5 DropRate=0/负致全掉落必中**（经济影响最大）：除零 → `int.MinValue` → 钳 1 → 所有怪物必掉物。
8. **P2-6 ThreadLimit 无上限**：配超大值 → `new MobThread[超大]` OOM。
9. **P2-7 非法 IP**：`IPAddress.Parse` 抛异常 → 启动失败。

## 排查过程

逐项读现场核实子代理报告（历史多次误报，必须验证引用链）：
- P1-1/P1-2/P2-1/P2-2：读 RecipeInfo.cs recipe 段 `:75 ushort.Parse`/`:78 byte.Parse`/`:86 uint.Parse` 全裸调用，criteria 段子代理确认已在 try 内（未动）；`:56 IsNullOrEmpty` 不跳纯空格，`:95/112 Split(RemoveEmptyEntries)` 返零长数组后 `:97/114 data[0]` 越界；`:60 Substring` 无长度守卫；CanCraft `:208 player.Info.Flags[flag]` 无范围校验。
- P1-3：Settings.cs:978/:1018 `(StatFormula)Enum.Parse(...)` 无 TryParse。
- P2-3/P2-4：DragonInfo.cs:158 / MonsterInfo.cs:341 `parts[0].Substring(2)` 无长度校验。
- P2-5：Settings.cs:443 DropRate 读入无钳制，MonsterInfo.cs:527 `rate=(int)(Chance/DropRate)` 除零得 `int.MinValue`，下一行 `if(rate<1)rate=1` → 必掉（Boss 装备全变必掉，经济崩坏）。
- P2-6：Settings.cs:394 批 B 已改 `Math.Max(1,...)` 只有下限，Envir.cs:230-231 `new MobThread[ThreadLimit]` 无上限。
- P2-7：Envir.cs:2336/:2342 `IPAddress.Parse(Settings.IPAddress)` 无保护。
- P2-8~11：RespawnInfo/NPCInfo/QuestInfo/MapInfo 的 FromText 守卫长度小于下方实际访问的最大索引（编辑器路径）。
- **特别甄别**：MapInfo stride 校验曾误写 `ri*10` 会误拒合法配置，改为按各段实际 stride（安全区4/移动5/刷怪7+段内偏移9/NPC6）精确计算 head/respawnEnd/npcEnd，取最大值校验总长。

## 修复内容

1. **P1-1**（RecipeInfo.cs）：`ushort.TryParse`/`byte.TryParse`（Chance>100 钳 100）/`uint.TryParse`，失败记日志并 `continue`。
2. **P1-2**（RecipeInfo.cs:56）：`IsNullOrEmpty` → `IsNullOrWhiteSpace`。
3. **P1-3**（Settings.cs:978/:1018）：`Enum.TryParse<StatFormula>(formula, true, out var f)`，失败记日志 `continue`。
4. **P2-1**（RecipeInfo.cs:60）：`if (lines[i].Length < 3) continue;`。
5. **P2-2**（RecipeInfo.cs CanCraft:208）：`if (flag < 0 || flag >= Flags.Length || !Flags[flag]) return false;`。
6. **P2-3**（DragonInfo.cs:158）：`if (parts.Length < 2 || parts[0].Length < 2) return null;`。
7. **P2-4**（MonsterInfo.cs:341）：`if (parts[0].Length < 2) return null;`。
8. **P2-5**（Settings.cs:443）：`DropRate = Math.Max(0.01F, Reader.ReadSingle(...))`，杜绝除零/负值。
9. **P2-6**（Settings.cs:394）：批 B 的 `Math.Max(1,...)` 叠加改为 `Math.Clamp(..., 1, 64)`。
10. **P2-7**（Envir.cs:2336/:2342）：`IPAddress bindAddress = IPAddress.TryParse(Settings.IPAddress, out var parsed) ? parsed : IPAddress.Loopback;`（选 Loopback 最小暴露，非 Any），两处 listener 共用 bindAddress。
11. **P2-8**（RespawnInfo.cs:58）：守卫 `<7` → `<11`。
12. **P2-9**（NPCInfo.cs:147/:162）：守卫 `<6` → `<19`；`FirstOrDefault()` 结果判空后取 `.Index`。
13. **P2-10**（QuestInfo.cs:441）：守卫 `<10` → `<13`。
14. **P2-11**（MapInfo.cs:246 后）：按各段 stride 精确计算所需最小长度，不足则 return（编辑器路径，防越界）。

## 验证证据

- `dotnet build Server.MirForms\\Server.csproj -c Release`：**0 警告 0 错误**；
- 行为复核：合法配置路径字节级不变（仅非法/边界配置被跳过或钳制）；DropRate 默认合法值不受 Math.Max 影响；ThreadLimit 默认 2 在 [1,64] 内不变；合法 IP 解析路径不变；
- 待实测：畸形配方/txt 不再启动崩；非法 IP 不再启动失败；DropRate 配 0 不再全掉落。
