# 20261116修复审计批2客户端渲染资源泄漏

## 现象

第十二轮四路审计之「客户端渲染」报告：P1×8 + P2×6。核心问题为资源生命周期缺陷——循环音效句柄泄漏、补丁器失败锁死、纹理裸指针 use-after-unlock、对话控件泄漏、批量图标索引错位、截图/GDI 资源未释放、ini 读写越界等。单项均非崩溃级，但长期运行内存/句柄持续增长（挂机数小时后卡顿掉帧的典型来源）。

## 排查过程

各缺陷均经逐行代码核查定位（行号为审计时点，部分修复后行号有偏移）：

1. **SoundManager.cs:237-246**：CleanDelay 定期清理过期循环音只 `Remove(key)` 不 Stop/Dispose；LoopProvider.PlaybackStopped 里 `if(_loop&&!_isDisposing) Play()` 无限重播 → 声音停了但设备句柄永不释放。
2. **AMain.cs:312-325**：补丁器下载失败两个 catch 均未置 `dl.Completed` → dl 永滞 ActiveDownloads → InterfaceTimer 完成条件永不成立 → Launch 按钮永久禁用。
3. **NPCDialogs.cs:398-418**：NewText 每页 new MirLabel 覆盖 TextLabel[i] 旧引用不 Dispose（对照 :395 TextButtons 有 Dispose 模式）→ 每次对话/翻页泄漏 8+ 控件。
4. **GameScene.cs:13146**：UpdateWeather 清理循环 `i>0` 漏索引 0 → 每次换图泄漏一个 ParticleEngine。
5. **ItemObject.cs:127-147**：CreateLabel 把 NameLabel 加入静态 LabelList 但缺 Disposing 反注册钩子（MapObject.cs:519 等全仓 6 处同模式先例都有）→ 掉落物标签+GDI Font 永久滞留。
6. **BuffDialog.cs:110/:911 + GameScene.cs:5592/:5614**：Buffs（顺序 Add）vs _buffList（`Insert(0,..)` 逆序）平行索引错位 → RemoveBuff(i) Dispose 错误图标、正确图标滞留；RemoveBuff 循环无 break → 删后继续旧 Count 迭代可跳元素。
7. **CMain.cs:631-658**：CreateScreenShot backbuffer Surface 不 Dispose、Bitmap 不 using、每次 new 5 个 Font。
8. **MLibrary.cs:962-1038**：CreateTexture Lock 后 `Data=(byte*)stream.DataPointer`，Unlock 后裸指针仍被 VisiblePixel 解引用（PlayerObject/MonsterObject/NPCObject 每帧鼠标拾取）= use-after-unlock 未定义行为。
9. **IniReader.cs:38/:74**：FindValue 无 '=' 行 Split[1] 越界；Save 非原子（进程崩溃写半截损坏配置）。
10. **DXManager.cs:307**：ResetDevice 的 Device.Reset 未捕获异常（设备丢失竞态时直接炸出主循环）。

## 修复内容

**P1×8：**
1. SoundManager 过期循环音：Remove 前先 `Stop()`（=Dispose，内部置 _isDisposing 阻断重播链）。
2. AMain 下载：finally 补 `dl.Completed = true`（成功路径幂等无害）。
3. NPCDialogs NewText：TextLabel[i] 覆盖前 `Dispose()+null`（:411 无条件 new 覆盖槽位，无悬挂风险）。
4. GameScene UpdateWeather：`i>0` → `i>=0`。
5. ItemObject CreateLabel：补 `NameLabel.Disposing += (o,e)=>LabelList.Remove(NameLabel);`（对齐全仓先例）。
6. BuffDialog 两处 `Insert(0,image)` → `Add(image)`（平行列表同序）；GameScene 两处 RemoveBuff 循环补 `break`（仅删首个匹配，与 AddBuff 对称）。
7. CreateScreenShot：backbuffer/Bitmap/StringFormat/Font 全部 using + 单 Font 复用 5 次 DrawString。
8. MLibrary：CreateTexture 在 Unlock 前预热调 `GetTrueSize()`（Data 指针有效窗口内完成 TrueSize 缓存）→ Unlock 后 `Data=null`；VisiblePixel 在 Data=null 后安全回退 false（拾取退化整图可见，无崩溃）。

**P2×5：**
9. IniReader：FindValue parts.Length 判别防越界；Save 改 .tmp + File.Replace/Move 原子替换。
10. DXManager ResetDevice：Device.Reset 包 try-catch(Direct3D9Exception)，失败保持 DeviceLost=true 交 AttemptReset 重试。
11. GameScene RemoveObject：入口加地图边界判别（换图后残留引用防 OOB）。
12. SoundManager _delayList：入队加上限保护（超限丢弃最老）。
13. BuffDialog PoisonBuffDialog 死代码删除（字段+Initialize+引用全清）。

**暂缓不改（记录在案）**：MainDialogs MiniMap QuestIcons 每帧重建——逻辑上先 Dispose 再重建无泄漏，属性能 churn；差量更新复杂度/风险与收益不成比例，暂不处理。

## 验证证据

- `dotnet build Client\Client.csproj -c Release`：0 错误（1 个 MSB3277 存量警告与本批无关）；
- 资源链复核：LoopProvider.Stop→_isDisposing→阻断重播链；MLibrary TrueSize 缓存后 VisiblePixel 不再走裸指针路径；
- 待实测：长时间挂机（循环 BGM 场景）不再逐渐卡顿；截图功能正常；NPC 对话/翻页/换图反复操作内存平稳；小地图图标/血条 buff 图标显示正常。
