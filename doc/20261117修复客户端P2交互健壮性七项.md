# 20261117修复客户端P2交互健壮性七项

## 现象

第五轮深度审计客户端非渲染维度登记的 P2 遗留缺陷，集中在「异常输入导致卡顿/崩溃/设置丢失/线程安全」：

1. **Tab 双绑定**（GameScene.cs:538-923）：Tab 同时绑定 Pickup（拾取）与 DropView（掉落显示），一次按键触发两个动作。
2. **英雄背包窗口设置无法持久化**（Client\Settings.cs:375）：`Reader.Write("Game", "ExpandedHeroBuffWindow", ExpandedBuffWindow)` 第三参写错变量，保存的是另一个字段值。
3. **IniReader 值含 '=' 被截断**（Shared\Functions\IniReader.cs:40/55）：`Split('=')` 按所有等号拆分只取 parts[1]，密码/URL 等含 '=' 的配置值被截断。
4. **补丁器异常中断 + CPU 忙等**（Client\Program.cs UpdatePatcher）：枚举进程 `MainModule.FileName` 抛异常（进程已退出）直接中断；3 秒等待循环无 Sleep 空转占 CPU。
5. **LoginScene 版本流程卡死**（LoginScene.cs:148/162）：SendVersion 异常只记日志不提示不重试；ClientVersion switch 无 default，未知版本结果卡在连接界面。
6. **多个 handler 解引用空控件**（LoginScene.cs 5 处 / SelectScene.cs 2 处 / GameScene.cs 3 处）：UI 控件已 Dispose 或 User 未赋值时解引用 → NRE。
7. **Network.Process 逐包无 try**（Client\MirNetwork\Network.cs:1099）：单包 ProcessPacket 抛异常中断整帧所有包处理。

## 排查过程

- Tab：Client\KeyBindSettings.cs:337(Pickup→Tab)/:380(DropView→Tab) 源头确认；消费端 GameScene.cs:538-923 是同一 foreach（:920 switch 闭合），keylist 中 Pickup 排在 DropView 前；其余 3 处 keylist foreach 不处理这俩绑定，无需改。
- 设置写错参：Client\Settings.cs:375 与同区块其他 `Reader.Write(...)` 调用对比，确认第三参应为 `ExpandedHeroBuffWindow`。
- IniReader：FindValue/FindIndex 两处 `Split('=')`，与脚本组 ReadPoint 同一文件不同位置（脚本组已改 :281-315），互不冲突；改 `Split(new[]{'='},2)` 保持 parts[0]/parts[1] 用法不变。
- 补丁器：UpdatePatcher:81-129 读全，确认外层 try/catch 存在但 `MainModule.FileName` 局部异常会跳过整个 kill/等待流程；忙等 `while(wait)` 内无 Sleep。
- LoginScene：SendVersion catch 与 ClientVersion switch 现场确认；文案 key ErrorConnectingToServer/SendingClientVersion/WrongVersionPleaseUpdateGame 与 MirMessageBoxButtons.YesNo/YesButton/NoButton 均存在，弹窗在 UI 线程安全。
- handler 判空：各 handler 入口首行均为控件/User 解引用，IsDisposed 是控件基类属性（项目多处先例），User 判空先例 GameScene.cs:1239。
- Network.Process：UI 线程由 CMain.UpdateEnviroment():408 调用，逐包 try 不影响外层断线通知/错误弹窗逻辑。

## 修复内容

1. **GameScene.cs**：Tab 绑定 foreach 的 switch 闭合后加 `break;`，一次按键只执行首个通过过滤的绑定。
2. **Client\Settings.cs:375**：第三参改 `ExpandedHeroBuffWindow`。
3. **Shared\Functions\IniReader.cs**：FindValue:40 与 FindIndex:55 的 `Split('=')` → `Split(new[] { '=' }, 2)`（值含 '=' 不再被截断，parts[0]/parts[1] 语义不变）。
4. **Client\Program.cs**：`using System.Threading;`；Kill 循环逐进程包 try/catch 忽略异常；忙等 for 块包 try/catch（catch 置 wait=true），`if (stopwatch.ElapsedMilliseconds <= 3000) { Thread.Sleep(50); continue; }`（3 秒上限+MessageBox+return true 保留）。
5. **LoginScene.cs**：SendVersion catch 加 YesNo 弹窗（ErrorConnectingToServer，Label=SendingClientVersion+"\n"+ex.Message，Yes=SendVersion 重试，No=Network.Disconnect）；ClientVersion switch case1 后加 `default:` 同款弹窗（WrongVersionPleaseUpdateGame）。
6. **handler 判空 10 处**：LoginScene.cs（NewAccount→_account / ChangePassword×2→_password / Login×2→_login）、SelectScene.cs（NewCharacter×2→_character）入口加 `if (X == null || X.IsDisposed) return;`；GameScene.cs（InTrapRock/CancelReincarnation `if (User == null) break;`、RequestReincarnation `if (User == null || User.Dead) return;`）。
7. **Network.cs Process**：`MirScene.ActiveScene.ProcessPacket(p)` 改 try 包裹 + ActiveScene 判空 + `catch (Exception ex) { if (Settings.LogErrors) CMain.SaveError(ex.ToString()); }`（单包异常不中断整帧）。
