# 20261113修复主循环地图处理异常隔离

> ⑤容错加固第二步第二段。承接：切片每对象隔离（36b1b84）、ThreadLoop 恢复式容错（aba3b12）。

## 现象

WorkLoop 主循环对 `MapList` 逐张调用 `MapList[i].Process()`——任何一张地图的 Process 抛异常（如地图内对象/施法/门/雷电火焰段异常冒泡），直接冒泡到内层致命 catch → 全服踢人停机。地图数量大（含实例图），单图毒对象可致全服「一炸全停」。

## 排查过程

- 现场核查：切片段（已隔离）之后紧跟 `for (var i = 0; i < MapList.Count; i++) MapList[i].Process();`，无任何隔离。
- 引用逻辑链核查：`MapList` 仅在加载期（LoadDB 的 Clear+重建）增删，**运行期不增删** ⇒ for 索引推进无需回退/补偿，catch 后 `i` 自然推进到下一张即可。
- 防解引用窗口：与切片段同理由，先 `var map = MapList[i];` 捕获引用再 try，catch 内不二次解引用 `MapList[i]`。
- 日志标识：key 用索引 `i`（运行期稳定唯一）；日志内容带 `map.Info.FileName` 便于定位。

## 修复内容

**`Server\MirEnvir\Envir.cs`**（WorkLoop 每地图段，单文件）：

```csharp
for (var i = 0; i < MapList.Count; i++)
{
    var map = MapList[i];
    try
    {
        map.Process();
    }
    catch (Exception ex)
    {
        ErrorThrottle.Notify("WorkLoopMap:" + i, () =>
            MessageQueue.Enqueue($"主循环地图处理异常 [{i}:{map.Info.FileName}] => {ex}"));
    }
}
```

- 复用 ErrorThrottle 节流器（同 key 默认 10 秒窗口只输出一条），毒地图不刷屏；
- `MapList[i].Process()` 原语义逐字保留（catch 不改变 i 推进，仍逐张处理）；
- 存档段与 DragonSystem/Envir.Process 段不在本段范围（各自独立段位，另行隔离）。

## 验证证据

- `dotnet build Server\Server.Library.csproj -c Release`：**0 警告 0 错误**。
- 逻辑复核：遍历顺序、逐张处理语义、异常隔离后继续下一张，与原实现唯一差异=异常不再冒泡致命 catch。
