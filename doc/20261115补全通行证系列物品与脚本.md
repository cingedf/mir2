# 20261115补全通行证系列物品与脚本

> 素材③模式延续（用户 @521@ 拍板「PremiumPass 530/536/542 占位段补全」，授权自主决策）：把 HeroUseItems.txt 三个占位段实装为青铜/白银/黄金通行证，形成 500（高级）+530/536/542 四档付费通行证系列。过程中发现并顺手根除素材③遗留的「主人侧双倍经验拒授」bug。

## 现象

1. `HeroUseItems.txt` 530/536/542 三段均为 `#SAY 尚未添加/Not added yet. PremiumPass.` 占位——通行证系列半成品，无对应物品、无实际效果。
2. **独立发现（素材③遗留 bug）**：500 页高级通行证原脚本 `GIVEBUFF 双倍经验 86400 TRUE FALSE FALSE 经验收益=200` 在**主人侧从未生效**——GIVEBUFF 执行端（NPCSegment.cs:4174-4184）要求命令属性对的键必须在 SetBuffs.txt 预设行中且**预设值为 0** 才放行；而 `双倍经验;经验收益=200;;` 预设值非 0 → `canAddBuff=false` 静默拒授。英雄侧 GIVEHEROBUFF 无此检查不受影响（4197-4256 直填）。

## 排查过程

- Shape 占用取证：旧导出快照（baseline 2_物品数据.csv）显示 530=软玉/542=破碎戒指，但 deploy 无 Exports 目录且现网库持续演进——**占用判定以现网 MirDB 为准**，由工具自检（Shape 被异物占用即报警跳过）；实际 apply 三 Shape 全部空闲。
- 拒授规则取证：NPCSegment.cs 玩家侧 GIVEBUFF 执行端（4110-4195）与英雄侧 GIVEHEROBUFF（4197-4256）对照阅读，确认 4174-4184 的 initialStats 校验即拒授根因。
- 引用面全景核查（零现网风险确认）：全库 GIVEBUFF 脚本逐条核对——特殊消耗品 14 件（摩鲁三色/破天的核心/天灵水/玉清水/内尔族/经验卷 10/20/30%/100%爆率卷/古代宗师/黄金宗师/真视卷轴，全部纯预设或预设 0 值+覆盖，兼容）、命令物品开启×3（纯预设）、地图触发 InDun4×2（暗影侵袭纯预设）、雕刻师德勋 7 处（龙之特效预设 0 值+单键覆盖）、荣誉战场红蓝方（10 键全 0 预设+覆盖）、监禁（纯预设）——**全部兼容**；本轮改动的 SetBuffs 两行（攻击力/防御提升）无任何既有脚本引用。

## 修复内容

1. **工具多目标化**（`tools\ItemSpawnSeed\Program.cs`）：单目标→批量 `plan|apply '名称:Shape'...`——逐目标幂等（同名已存在跳过/Shape 异物占用报警跳过）、计数器自愈沿用、构建循环、apply 后回读逐件验证。
2. **三件物品播种**（deploy Server.MirDB，备份 `Server.MirDB.pre-premiumpass.bak` 940276B；沙盒 iss-sandbox apply 全绿后落库，ItemIndex 计数器 4321→4324）：
   - 青铜通行证 Index=4322 Shape=530 / 白银通行证 Index=4323 Shape=536 / 黄金通行证 Index=4324 Shape=542（均 Type=特殊消耗品 StackSize=20 Price=1000 Image=4570 Effect=0）
3. **HeroUseItems.txt 三段实装**（deploy 区，UTF-8；梯度自主拍板：青铜纯攻击/白银攻击+双倍经验/黄金攻击+防御+双倍经验，全部 86400 秒=24h）：
   - 530 青铜：`GIVEBUFF 攻击力提升 86400 TRUE FALSE FALSE MinDC=15 MaxDC=15` + `GIVEHEROBUFF` 同款
   - 536 白银：攻击力提升 + 双倍经验（两组双命令）
   - 542 黄金：攻击力提升 + 防御提升（MinAC=15 MaxAC=15）+ 双倍经验（三组双命令）
   - 各带 `LocalMessage "主人与英雄XX加成 持续一天" Hint` 中文提示（顺手汉化规则）
4. **500 页同步修正**：`GIVEBUFF 双倍经验 86400 TRUE FALSE FALSE`（去 `经验收益=200` 属性对）——预设行 `双倍经验;经验收益=200;;` 自带 +200%，主人侧拒授根除。
5. **SetBuffs.txt 两行补 0 值键**（满足 4174 校验「键须在预设行且值为 0」）：`攻击力提升;MinDC=0;MaxDC=0;;`、`防御提升;MinAC=0;MaxAC=0;;`。
