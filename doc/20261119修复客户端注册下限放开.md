# 20261119 修复客户端注册下限放开

## 现象
客户端注册时账户 id 限 3-15 字符、密码限 5-20 字符；服务器侧账号名仅上限 20 无下限（Envir.cs:2624/2679）、密码无任何位数/组合限制。用户希望客户端也不再限制（下限 3→1、5→1）。

## 排查
- 限制不在 LoginScene.cs 硬编码，而来自常量 `Globals.MinAccountIDLength / MaxAccountIDLength / MinPasswordLength / MaxPasswordLength`（`Shared\Globals.cs`）。
- 引用点：Client\MirScenes\LoginScene.cs（:473/:491/:951/:967/:983/:1099/:1104/:1295/:1311/:1327）、NPCDialogs.cs:3299 —— 全链引用同一常量，改 Globals 即全链生效。
- 服务器侧已验证：账号名仅上限 20（Envir.cs:2624/2679 `p.UserName.Length > 20`），密码无最小长度/纯数字/纯字符/与账号名相同限制；账户 1/密码 1 服务器可注册，无需改动。

## 修复
`Shared\Globals.cs`：
- `MinAccountIDLength` 3 → **1**
- `MinPasswordLength` 5 → **1**
- 上限保留：`MaxAccountIDLength = 15`、`MaxPasswordLength = 15`；`MinCharacterNameLength = 3` 等其他常量不动。
