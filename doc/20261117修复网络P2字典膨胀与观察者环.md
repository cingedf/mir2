# 20261117修复网络P2字典膨胀与观察者环

## 现象

第五轮深度审计网络维度登记 4 项 P2 遗留缺陷（低风险但长期运行会累积恶化）：

1. **IPBlocks / ConnectionLogs 字典只增不减**：IP 封禁表、连接日志表只有写入没有过期清理，服务器长时间运行后随封禁/连接数无限膨胀。
2. **状态端口排空 while 未查 Running**：关服时状态端口的 finally 块 `while (StatusConnections.Count >= 5) Thread.Sleep(1)` 不检查停机标志，关服线程可能永久滞留。
3. **SendDisconnect 绕过发送队列计数**：断线包直入 `_sendList` 却不 `_sendQueueCount++`，而出队时无条件 `--`，计数被减成负数使队列上限保护失效。
4. **观察者扇出递归无环检测**：管理员令 A 观察 B、B 观察 A（或更长环）后，Observable 包扇出无限递归，栈溢出崩进程。

## 排查过程

- Envir.cs:812-820 WorkLoop 的 5 分钟周期块只广播在线人数，无清理逻辑；IPBlocks(:138)/ConnectionLogs(:140) 声明处及 UpdateIPBlock(:2006) 等写入点均无移除路径；
- Envir.cs:2405 状态端口 finally 对比游戏端口 :2381 已加 `Running &&` 的先例，确认状态端口遗漏；
- MirConnection.cs:1656-1676 SendDisconnect 与 Enqueue(:691) 对比，确认断线包绕过计数；出队 TryBeginSend(:657) 无条件递减；
- MirConnection.cs:281-293 AddObserver 仅查 `c == this`，未查双向关系；Enqueue 扇出 :714-720 无访问集，A↔B 互观察时 `c.Enqueue(p)` 无限递归。

## 修复内容

**Envir.cs（2 处）**
1. WorkLoop 5 分钟块广播后加过期清理：`IPBlocks` 用 `((ICollection<KeyValuePair<string,DateTime>>)IPBlocks).Remove(new KeyValuePair<>(pair.Key,pair.Value))` 做**键+值原子匹配删**（不可用 TryRemove 仅按键删——会误删其它线程刚刷新的新封禁）；`ConnectionLogs` 取两日志 List 末尾最大时间戳 last，`last==0 || last+24h < Time` 时同款原子删。
2. 状态端口 finally 的 while 改 `while (Running && StatusConnections.Count >= 5)`。

**MirConnection.cs（3 处）**
3. SendDisconnect 断线包入队改 `if (_sendQueueCount < MaxSendQueue) { _sendList.Enqueue(...); _sendQueueCount++; }`（不改调 Enqueue()——此时 state 已 Disconnecting 会被入口拦截）。
4. Enqueue 拆重载：`public void Enqueue(Packet p) => Enqueue(p, null);` + `private void Enqueue(Packet p, HashSet<MirConnection> visited)`——入口 `if (visited != null && !visited.Add(this)) return;` 拦截重复访问；非 Observable 包零集合分配；扇出前 `if (visited == null) visited = new HashSet<MirConnection>{this};`，递归调用改 `c.Enqueue(p, visited)`。
5. AddObserver 守卫改 `if (c == null || c == this || Observing == c || c.Observing == this) return;`（`Observing == c` 真正拦 2 节点环；更长环由访问集兜底）。

## 验证证据

- `dotnet build Server.MirForms\\Server.csproj -c Release`：**0 警告 0 错误**；
- 逻辑复核：键+值原子删避免误删刷新项；停机 while 加 Running 后可正常退出；断线包计数自洽不再变负；正常观察者链 visited 每节点仅入一次不影响分发，环被截断；
- 待实测：长时间运行内存曲线平稳；关服无滞留；管理员互观察配置被拒。
