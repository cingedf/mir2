# 20261110修复物品悬浮窗被鼠标遮挡

## 现象

- 背包物品悬浮窗（鼠标悬停物品弹出的提示框）顶部与鼠标光标同高，**文字被鼠标指针挡住**，看不清物品名称/属性首行。
- 同屏其他 UI 按钮悬浮窗（如邮件按钮提示）位置正常，在鼠标左下方，两者观感不一致。

## 排查过程

1. 定位渲染代码：`Client\MirScenes\GameScene.cs`（angelk727）@1264-1314——物品（ItemLabel）/邮件（MailLabel）/备忘（MemoLabel）/公会 buff（GuildBuffLabel）四类悬浮窗共用同一套定位：`int x = CMain.MPoint.X + 15, y = CMain.MPoint.Y;`（浮窗顶边与鼠标同高，右侧偏 15px）。
2. UI 按钮悬浮窗的定位在 `Client\Forms\CMain.cs@556`（CreateHintLabel）：`Point point = MPoint.Add(-HintTextLabel.Size.Width, 20);`——浮窗**右缘贴鼠标左侧、顶边在鼠标下方 20px**（即"左下"位置），仅做右/下边界防溢出。
3. 旧版 crystal 对照（`C:\1.40\mir2\src\crystal\Client\MirScenes\GameScene.cs@1221`）：`+28, +28`（鼠标右下）。当前版本改为 `+15, 同高` 属于改坏了——无论右下还是左下，**原版都没有"浮窗压住鼠标"的问题**。
4. 结论：不是数据/服务端问题，是客户端一行定位回归。修复方向按用户要求：**与 UI 按钮悬浮窗（左下）保持一致**。

## 修复内容

`Client\MirScenes\GameScene.cs` 四处定位（物品/邮件/备忘/公会 buff 悬浮窗）统一改为与 `CMain.CreateHintLabel` 相同的算法（鼠标左下、含左边界防溢出）：

```csharp
int x = CMain.MPoint.X - ItemLabel.Size.Width, y = CMain.MPoint.Y + 20;
if (x < 0) x = 0;
if (x + ItemLabel.Size.Width > Settings.ScreenWidth)
    x = Settings.ScreenWidth - ItemLabel.Size.Width;
if (y + ItemLabel.Size.Height > Settings.ScreenHeight)
    y = Settings.ScreenHeight - ItemLabel.Size.Height;
ItemLabel.Location = new Point(x, y);
```

- MailLabel/MemoLabel/GuildBuffLabel 三处同款修改（它们存在同样的遮挡问题）。
- 仅改客户端 `GameScene.cs` 一个文件、4 处定位；服务端零改动。
- 重编译 `Client.csproj`（0 错误 11 旧警告），产物 Client.exe/Client.dll/Shared.dll 等 7 件已换到 `C:\1.40\mir2-deploy\Client`。

## 验证证据

- 编译：`dotnet build Client.csproj -c Release` → 0 错误。
- 换件：部署区 `Client\` 目录 7 件时间戳 2026-11-10 22:12 全新；客户端运行中无法换件，已由用户关闭后完成。
- 待用户进游戏验收：背包物品悬浮窗出现在鼠标**左下方**、不再被光标遮挡，与 UI 按钮悬浮窗位置观感一致；屏幕边缘时浮窗自动收进不溢出。

## 回滚方法

- 代码：`git revert <本次commit>`，或将 GameScene.cs 四处定位改回 `int x = CMain.MPoint.X + 15, y = CMain.MPoint.Y;`（去掉 `if (x < 0) x = 0;` 行）。
- 部署：回滚后重编译，关闭客户端，将 Build\Client\Release 下 Client.exe/Client.dll/Client.pdb/Client.deps.json/Client.runtimeconfig.json/Shared.dll/Shared.pdb 拷回 `C:\1.40\mir2-deploy\Client`。
