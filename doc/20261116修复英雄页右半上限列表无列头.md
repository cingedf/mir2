# 20261116 修复英雄页右半上限列表无列头

## 现象

用户反馈：Server.exe 配置子菜单「游戏平衡调整」→ 英雄标签页，左半部分列表正常有属性列头，但**右半部分（上限列表）没有列头显示**，要求与左边列表对齐。

## 排查过程

1. 现场：`Server.MirForms\BalanceConfigForm.Designer.cs` 中 `panelHeroRight`（Dock=Right，233×918）内的 `heroCapGridView` 布局为 **`Dock=Bottom + Location(0,-30) + Size 233×948`**——Dock=Bottom 时控件贴面板底边，负 Y 坐标把 **DataGridView 列头（AutoSize 高≈22-30px）顶出面板可视区**，故只见数据行不见列头。
2. heroCapGridView 仅 2 列：HeroCapType（HeaderText「英雄类型」，DataSource=BuildEnumTable&lt;Stat&gt;() 已中文）+ HeroCapValue（「变量」，Fill）。左侧 heroGridView 列头文字为「类型/变量」。
3. .cs 布局引用 grep 实证为零（纯 Designer 布局问题）；该 Designer 文件存在历史遗留的重复实例化块，编辑只动布局属性区。

## 修复内容

`Server.MirForms\BalanceConfigForm.Designer.cs`：

1. `heroCapGridView`：`Dock=Bottom` → **`Dock=Fill`**，`Location (0,-30)` → `(0,0)`，`Size 233×948` → `233×918`（列头回到面板顶部可视区）。
2. `HeroCapType` 列：加 `AutoSizeMode=Fill`，HeaderText「英雄类型」→「**类型**」，与左侧 heroGridView 列头文字对齐（下拉数据源链未动，仍全枚举中文）。

## 验证证据

- `dotnet build Server.MirForms\Server.csproj -c Release`：**0 警告 0 错误**；
- 待用户实测：英雄页右半上限列表顶部应显示「类型/变量」列头，与左半列表视觉对齐。
