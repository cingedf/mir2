# 20261115 Map 编辑器全面汉化

## 现象

Suprcode/Crystal.MapEditor（Map Editor v1.1）下载并放置于 `tools/MapEditor/` 后，编辑器全部界面为英文（工具栏、菜单、右键菜单、图层下拉、标签页、对话框、消息框、图库信息窗体等），中文用户使用困难。

## 排查过程

1. 从 https://github.com/Suprcode/Crystal.MapEditor.git 克隆仓库（浅克隆），确认结构：`Map Editor.sln`（SDK 风格 csproj，**net8.0-windows**，引用 `..\Components\SlimDX.dll`，WinForms + SlimDX 渲染）。
2. 放置到 `C:\1.40\mir2-angelk727\tools\MapEditor\`，补齐被遗漏的 `Components/`（SlimDX.dll/pdb/xml），否则 csproj 引用路径 `..\Components\SlimDX.dll` 断链无法编译。
3. 全量 grep 定位 UI 字符串：`\.Text = `、`\.ToolTipText = `、`MessageBox.Show`、`\.Filter = `、`HeaderText = `、`\.Description = `，共 245+ 处；逐条核对行为耦合点后确认可安全汉化（见下）。
4. 逐文件精确替换（edit 工具，UTF-8 BOM 保持不变），未改动任何逻辑代码。

## 修复内容（改动文件均在 `tools/MapEditor/Map Editor/`）

### 纯文案替换（显示层，无逻辑改动）

- **Main.Designer.cs**（~80 处）：工具栏按钮（新建/打开/保存/跳转/释放内存/视图）、14 个显示开关复选框、`编辑层` 下拉 20 项（含快捷键标注，仅改文案，Main.cs 全部按 `SelectedIndex` 数字索引切换，不比较文本，安全）、撤销/重做/缩放/小地图/关于/翻转 Mir3 图层/另存为 Object.X、7 个标签页（Map→地图、Objects→物件、Tiles→图块、TileCutter→图块裁剪、Help→帮助；WemadeMir2/ShandaMir2/WemadeMir3/ShandaMir3 为版本专有名词保留英文）、右键菜单（撤销/重做/另存选区为物件/设置门/动画/亮度属性/删除所选单元格数据）、全选/全不选、隐藏菜单栏（文件/编辑/工具/视图/帮助及全部菜单项）、4 个图库页的 偏移X/偏移Y/宽度/高度 标签、图块裁剪区（保存图库/载入图片/图块尺寸）、主窗体标题 `地图编辑器`、`GO`→`加载`、SaveLibraryDialog.Filter `Lib|*.lib`→`图库|*.lib`（扩展名部分不变）。
- **Main.cs**（~35 处）：`地图信息` 工具栏按钮及其提示、`请先打开或新建一张地图。`、`未命名地图`、`地图已保存`×2、`物件超出地图边界!`、清空地图/删除单元格确认框及标题、`目录不存在`、`路径必须是 Map 文件夹。`、`文件必须是 '.Map' 格式。`、小地图保存提示 `已保存... `、FolderBrowserDialog.Description `请选择客户端的 Map 地图文件夹。`、3 个 SaveFileDialog.Filter（`自定义地图 (*.Map)|*.Map` / `自定义地图 (*.Mir3)|*.Mir3` / `物件文件 (*.X)|*.X`，管道后扩展名部分一律未动）、16 处动态信息标签前缀（宽度/高度/偏移X/偏移Y）。
- **CellInfoControl.Designer.cs**（~28 处）：单元格信息面板表头（背景图/中间层图/前景图/版本/图库名/图库索引/限制/背面/正面/动画/前帧数/前帧速/前混合/中帧数/中帧速/中混合/门/偏移/索引/实体门/亮度/钓鱼）。
- **CellInfoControl.cs**：移动限制显示 `True/False`→`是/否`（纯显示；WemadeMir2 等版本名按库索引判断后显示，为专有名词保留）。
- **FrmAbout/FrmJump/FrmSetAnimation/FrmSetDoor/FrmSetLight/NewFileFrm** 各 Designer + NewFileFrm.cs：关闭/跳转/确定/关于/坐标跳转/设置动画/设置门属性/设置亮度/新建地图标题及标签；`地图尺寸最大 1000*1000`。原中英混排文案（`动画间隔 Animation interval` 等）改为纯中文。
- **MLibrary.cs**：图库版本错误提示 `库版本错误，期望版本: … 实际版本: …`，标题 `打开失败`。
- **字体兼容**：`Comic Sans MS` 无中文字形（WinForms 会 fallback 但渲染不统一），全部替换为 `Microsoft YaHei`（纯字体名替换：Main.Designer 22 处、CellInfoControl.Designer 52 处、FrmAbout 4 处、Main.cs 4 处；其余小窗体本就未用该字体）。

### 行为耦合点（重点，均已安全处理）

- **MapInformationForm.cs**（图库引用/重映射窗体，纯代码构建 UI）：
  - 筛选下拉原为英文枚举名，与 `reference.Kind.ToString()` 字符串比较。汉化为 `全部/图块/小图块/物件/未知` 后，新增 `FilterName(MapReferenceKind)` 显示映射方法，比较逻辑改为 `FilterName(reference.Kind) != selectedFilter`，保持筛选行为等价（原比较字面量不再使用，`GetReferenceKind` 的 `smtile`/`tile` 文件名分类逻辑未动）。
  - 网格列 HeaderText 汉化（类型/图层/图库 #/图库/图库文件/单元格/图片数/图片范围/起始单元格/状态），列 `Name`（程序化 ID）保持英文不动。
  - 新增 `KindName()`/`LayerName()` 显示映射方法，枚举值在网格、选中标签、重映射确认框中显示为中文；`MapReferenceKind`/`MapReferenceLayer` 枚举本体及所有比较逻辑不动。
  - 状态字符串（无效索引/可用/文件缺失/已配置/未知）、占位名 `（未加载）`/`（无效索引）`（保留半角 `(` 前缀——`GetReferenceKind` 用 `libraryName.StartsWith("(")` 识别占位名，全角括号会破坏该判断）。
  - 摘要统计行、确认框、`已更新 N 个单元格引用`、`没有符合筛选条件的引用。`、标题 `地图信息 - xxx` 等全部汉化。
- 保留项（合理不译）：X/Y 坐标标签、设计器内部名（`toolStrip1`/`menuStrip1`）、运行时会被 `SetText()` 覆盖的占位值、注释中的英文、`48 x 32`/`96 x 64` 尺寸项、`btn_grid` 的 `#`。

## 验证证据

1. `dotnet build -c Release -p:Platform=x64`：**0 错误**，仅 2 个原有警告（CS0219 未使用变量，与汉化无关），输出 `Map Editor.exe`（168,960 字节，net8.0-windows/x64）。
2. 启动冒烟测试：`Start-Process` 启动 exe，6 秒后进程仍存活（RUNNING OK），无启动崩溃，随后正常结束进程。
3. 全量 grep 复扫 `.Text`/`ToolTipText`/`MessageBox`/`HeaderText` 无遗留英文（除专有名词/内部名/占位值/注释等合理保留项）。
