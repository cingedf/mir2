# 20261115修复账户窗创建日期时区与按钮遮挡

> 用户十问（server.exe 实机体验）第 1、2 问：玩家账户窗「账户创建日期」显示比实际早 8 小时（UTC 显示未转本地时区）；右下方「清除存储密码」按钮被上方角色列表遮挡 14px。一处 commit 双修。

## 现象

- ① 账户管理窗选中账户后「账户创建日期」比真实创建时刻早 8 小时（北京 UTC+8）；「最后登录日期」同款问题。
- ② 窗体右下方「清除存储密码」按钮上半截被上方「角色列表」框盖住，点击区域受损。

## 排查过程

- **日期根因链**：写入端 `AccountInfo.cs:96` 构造函数 `CreationDate = Envir.Now`——`Envir.Now`（Envir.cs:142-143）= `DateTime.UtcNow + 游戏时钟毫秒`，是 **UTC 时间**；显示端 `AccountInfoForm.cs:171` 直接 `info.CreationDate.ToString()` 无时区转换 → 北京环境显示早 8 小时。LastDate（:174）同款。
- **为何只改显示端**：写入端 :96 与归档判断（AccountInfo.cs:150 同用 Envir.Now 比较）体系内自洽；动写入端会造成归档比较基准不一致（带出新问题）——修复方法论「不带出新问题」优先，显示端 `.ToLocalTime()` 即可闭环。
- **多选比对闭环**：:194/:198 的比对串需与首赋值格式一致（`Text != info.X.ToString()`），首赋值改 ToLocalTime 后比对侧同步改，否则多选不一致时清空逻辑失效。
- **遮挡根因**：`ClearStoragePasswordButton` (701,170) 160x27 与 `CharactersListView` (701,0) **546x184** 在 y=170-184 重叠 14px，且列表后加入 z 序在上压住按钮；周边无冲突空间验证：下移至 (701,188) 后 188+27=215，与 ExpiryDateTextBox(460,202) 右缘 599、BannedCheckBox(610,204) 右缘 661 横向无冲突，右侧到 Panel 右缘 1247 空间充足。

## 修复内容

1. **`Server.MirForms\Account\AccountInfoForm.cs` 四处**（注释「20261115 修复（十问①）」）：
   - :171 回显首赋值 `CreationDateTextBox.Text = info.CreationDate.ToLocalTime().ToString();`
   - :174 `LastDateTextBox.Text = info.LastDate.ToLocalTime().ToString();`
   - :194/:198 多选比对串同步 `.ToLocalTime().ToString()`（保持与首赋值格式一致）。
2. **`Server.MirForms\Account\AccountInfoForm.Designer.cs:286`**：`ClearStoragePasswordButton.Location` (701,170) → **(701,188)**（注释「20261115 修复（十问②）」）。
- 写入端 AccountInfo.cs:96 零改动；存盘数据格式不变（仍是 UTC，显示端转换）。

## 验证证据

- `dotnet build Server.MirForms\Server.csproj -c Release`（server.exe 入口全量）：**0 警告 0 错误**（28.92s）。
- 逻辑复核：ToLocalTime 只影响显示层；归档/存盘/比对链全部基于原始 UTC 值不变；比对串与首赋值同格式闭环。
- 上线验证：重启 server.exe → 账户窗创建日期与真实注册时间一致（不再早 8 小时）；清除存储密码按钮完整可见可点。
