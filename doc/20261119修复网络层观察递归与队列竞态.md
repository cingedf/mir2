# 20261119修复网络层观察递归与队列竞态

## 现象

新一轮「未触碰维度」深度审计（网络底层路线）回报 1 个 P0 进程级崩溃 + 3 个 P2 资源/健壮性缺陷，均可由合法或伪造包触发：

1. **P0 观察者递归爆栈崩进程**（MirConnection.cs）：三个 Check* 观察者通知沿 Observer 链递归时无访问集/环检测，≥3 节点环即无限递归→栈溢出→**整个服务端进程终止**。
2. **P2 CleanObservers 悬挂引用**：断开观察者连接时只清正向 Observers，不清反向 Observing→已断连接被强引用无法 GC。
3. **P2 Accept 构造异常句柄泄漏**：TcpClient 构造 MirConnection 抛异常时未 Close→socket 句柄泄漏。
4. **P2 队列计数跨锁竞态**：两个队列计数器由不同锁/线程读写，lost update 漂移可绕过队列长度上限守卫。

## 排查过程

1. **P0 环检测缺失**：Enqueue（:698-735）前序已加 `visited` 访问集先例（:705 `if(visited!=null&&!visited.Add(this))return;`、:726-727 根节点初始化、:734 透传递归）。但三个 Check*：CheckItemInfo（:3754-3783）、CheckMonsterInfo（:3791-3808）、CheckNPCInfo（:3816-3833）递归观察者时无访问集，Sent*.Contains 去重在递归**之后**才生效。AddObserver（:281-294）只拦 2 节点环（`c==this||Observing==c||c.Observing==this`），3 节点环 A→B→C→A 可合法构造（AllowObserve 或 GM 绕过 :2374-2376）→CheckX 在环上无限递归→StackOverflowException（.NET 不可捕获，直接杀进程）。
   - **关键陷阱**：CheckItemInfo 内部另有「类级派生分支」在 this 上递归调用自己（`CheckItemInfo(item,true,...)`，用 dontLoop 参数防环）。若把 this 加进 visited 放**方法入口**会误伤这个合法的同对象递归；访问集必须在**观察者 foreach 内**只对 observer 去重。
2. **P2-1 悬挂**：CleanObservers（:1699-1711）只 `c.Stage=Login; c.Enqueue(ReturnToLogin)` + `Observers.Clear()`，无 `c.Observing=null`。清理先例见 :1620-1623/:2282-2285。
3. **P2-3 句柄泄漏**：Envir.Connection()（:2394-2449）原 tempTcpClient 在 try 内声明，:2423 `new MirConnection(++_sessionID,tempTcpClient)` 构造抛异常时跳过 :2433 的 `if(!connected)tempTcpClient.Close()`，catch(:2436)/finally(:2440) 均未兜底。注意正常连接时 socket 所有权已转移给 MirConnection，**不能 finally 无条件 Close**（会关掉正常连接）。
4. **P2-2 竞态**：`_sendQueueCount` 的 ++ 在 Enqueue（lock _connectionLock）与 -- 在 TryBeginSend（lock _sendPumpLock），**两把锁保护同一字段**；`_receiveQueueCount` 的 ++ 在 ReceiveData（IO 线程）/ -- 在 Process（主线程）无同步。lost update 使计数漂移，绕过 MaxSendQueue=10000/MaxReceiveQueue=5000 上限守卫。

## 修复内容

均附 20261119 注释，行为和调用约定不变：

1. **P0 观察者递归环检测**（MirConnection.cs）：三个 Check* 保留原公共签名（外部 ~20 处调用零改动），入口改为调 private 重载（带 `HashSet<MirConnection> visited`）；环检测置于观察者 foreach 内 `if(observer==null||!visited.Add(observer))continue;`（避开同对象类级递归误伤）；重载入口 `if(visited==null)visited=new HashSet<MirConnection>{this};`；类级递归分支透传同一 visited（dontLoop 防环正交保留）；三方法加 `if(info==null)return;` 防御。
2. **P2-1 CleanObservers**（MirConnection.cs:1699-1711）：foreach 内加 `if (c.Observing == this) c.Observing = null;`。
3. **P2-3 Accept 句柄**（Envir.cs:2394-2449）：try 外加 `TcpClient tempTcpClient=null; bool handedOff=false;`；EndAcceptTcpClient 结果赋给 tempTcpClient；connected=true 后 `handedOff=true;`（标记所有权转移）；catch 内 `if (tempTcpClient != null && !handedOff) tempTcpClient.Close();`（仅异常且未转移时关闭）。
4. **P2-2 队列计数原子化**（MirConnection.cs）：头部加 `using System.Threading;`；所有 ++/-- 写点改 `Interlocked.Increment/Decrement(ref ...)`（receive++ :378、retry receive++ :808、send++ :720/:1690、send-- :667/:676、receive-- :777）；getter/比较点/reset 保持直接读（x86 平台原子读足够）。

**已核验不构成缺陷（不修）**：状态机 Stage 守卫完整；SessionID 仅用于日志；收包缓冲固定 65535 无越界；刷包限速生效；MaxUser=500/MaxIP=5 配置守卫有效；KeepAlive 无缺陷。
