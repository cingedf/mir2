## 排查

- 四字段创建代码在上游移植时已被注释掉（保留为参考块，约 38~68 行），
  背景图 Title[670] 列头区（深色带）已烧录「类型/发件人/信息」浅色文字，
  再创建 Label 会重影——像素探针实测确认。
- 此前会话声称 commit 5cd02a1 已删除这四个字段，实测该 commit 不存在、文件仍为旧态，属交接失实。
- 字段声明本身也无保留价值（注释块已足以说明来龙去脉），且用户已授权删除。

## 修复内容

- `Client\MirScenes\Dialogs\MailDialogs.cs`：
  - 删除第 14 行 `MirImageControl TitleLabel = null;`
  - 删除第 16 行 `MirLabel TitleTypeLabel = null, TitleSenderLabel = null, TitleMessageLabel = null;`
  - 同步改写上方注释：删去「保留声明供日后自定义列头参考 / 显式赋 null 消除 CS0169」表述，
    改为说明四死字段已删除（CS0414 清理，20261113），日后自定义列头按注释掉的代码块重建即可。
- 注释掉的创建代码块（Title[670] 列头说明）原样保留，未动其他任何代码。
