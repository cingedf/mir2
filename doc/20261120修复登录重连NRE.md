# 20261120 修复登录重连 NRE（LoginScene.SendVersion）

## 现象
用户报告：客户端无法登录服务器（"限制服务端打开登录界面"）。
`C:\1.40\mir2-deploy\Client\Error.txt` 反复 `NullReferenceException at Client.MirScenes.LoginScene.SendVersion()`（11/20 22:02:18 起，间隔约 73-75s；早期条目带行号 LoginScene.cs:line 136）。

## 排查
- 重连触发：`Network` 自动重连（Network.cs:47 ReconnectDelay / :886 ScheduleReconnect / :953 watchdog）→ 服务器重发 `ServerPacketIds.Connected` → `LoginScene.ProcessPacket`（:103-106）→ `SendVersion()`。
- `SendVersion()` :136 `_connectBox.Label.Text = ...`：`_connectBox` 在 `ClientVersion` 成功分支 case 1（:170-172）已 `_connectBox.Dispose()`，而 `MirMessageBox.Dispose` 会把 `Label` 置 null（MirMessageBox.cs:239）→ 重连时 Label 为 null → NRE。
- NRE 发生在 `Network.Enqueue(p)`（:147）之前 → **ClientVersion 包永不发出** → 服务器停在 Stage=None 等版本 → 客户端卡在"发送版本" → 无法登录。
- 佐证：`Process()`（:96）已有 `if (!Network.Connected && _connectBox.Label != null)` 判空写法，`SendVersion` 未判空（历史遗留）。
- 已排除：Setup.ini `CheckVersion=False`（无版本白名单）；`AllowLogin=True`（未限制登录）；客户端版本哈希=MD5(Client.exe)（:143，未受本次 Client.dll 部署影响）；本批 Globals 下限改动与 9ea97e9 启动健壮性批 diff 已审查，与 SendVersion 无关。

## 修复
`Client\MirScenes\LoginScene.cs` `SendVersion()`：
```csharp
if (_connectBox?.Label != null)
    _connectBox.Label.Text = GameLanguage.ClientTextMap.GetLocalization(ClientTextKeys.SendingClientVersion);
```
标签可写时照常更新；为 null 时跳过标签更新、版本包仍照常 `Network.Enqueue`（行为等价收敛）。
