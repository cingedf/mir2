# 20261118修复性能热点小地图与法术快照

## 现象

性能专项审计发现客户端小地图每帧绘制路径存在 GDI 字体抖动与重复 LINQ 查询，服务端持续法术每次 tick 都新建目标数组，均属高频可量化浪费（拥挤地图每秒数百至上千次分配），长时间运行会加剧 GC 与卡顿。

## 排查过程

1. **小地图任务图标每帧重建**（MainDialogs.cs MiniMap_BeforeDraw :1883-2016，每帧由 MirControl.Draw→BeforeDrawControl 调用）：
   - :1886-1889 每帧 `foreach(icon.Dispose()); QuestIcons.Clear();`
   - :1998 每个有任务 NPC `new MirLabel{ Font = new Font(...) }`→MirLabel.Font setter 走 MirControl.ScaleFont（:999-1005 再 new Font + Dispose 旧字体）——**每图标每帧创建 2 个 GDI Font、销毁 1 个**，3~8 图标→每秒 360~960 次字体创建+纹理重建。
2. **每帧无谓 LINQ 查询**（:1961）：`npc.GetAvailableQuests(true).Any()` 内部 new List + 多条 LINQ 管道 + 委托/闭包/枚举器，仅需布尔值却走完整查询（NPCObject.cs:390-424）。NPCDialogs.cs:1056 同类调用。
3. **每帧临时字符串**（:1943）：`string.Format("({0})", MapObject.User.Name)` 每对象每帧分配，拥挤地图每秒数千临时串。
4. **法术目标数组每 tick 新建**（SpellObject.cs:161-168，上轮批3b 加的防御快照）：`cell.Objects.ToArray()` 每次 tick 每法术新数组。

## 修复内容

**客户端（4 文件）：**

1. **任务图标对象池**（MainDialogs.cs）：移除每帧 Dispose+Clear，改为帧首 `int questIconUsed=0; foreach(icon in QuestIcons) icon.Visible=false;` 统一隐藏；:1998 从池中按 `questIconUsed` 取 label，不足才 `new MirLabel(...)` 并 Add，**Font 仅在新建时设置一次**（避开每帧 ScaleFont），复用时仅更新 Text/ForeColour/Location/Visible。多余图标保持隐藏供下帧复用；父控件 MiniMapDialog Dispose 时连带清理子控件，无累积泄漏。
2. **无分配布尔查询**（Client\MirObjects\NPCObject.cs）：新增 `public bool HasAvailableQuest()`，两个普通 foreach（CurrentQuests 匹配 FinishNPCIndex==ObjectID 或 NPCIndex==ObjectID&&SameFinishNPC；Quests 中 CanAccept && !Completed）首命中即 return true——等价 `GetAvailableQuests(true).Any()` 且零分配。替换 MainDialogs.cs:1961 与 NPCDialogs.cs:1056 两处调用（QuestDialogs.cs 需完整列表，保持不动）。
3. **字符串外提**（MainDialogs.cs:1943）：循环外算一次 `string nameSuffix = "(" + MapObject.User.Name + ")";`，循环内 `ob.Name.EndsWith(nameSuffix, StringComparison.Ordinal)`。

**服务端（1 文件）：**

4. **法术目标缓冲复用**（SpellObject.cs）：字段区新增 `private MapObject[] _spellTargetBuffer = new MapObject[16];`；tick 内按 `cell.Objects.Count` 按需 Array.Resize，用 `CopyTo` 拷入缓冲后遍历（保留上轮快照防集合变动语义，消除每 tick 的 ToArray 分配）。

- 待实测：小地图任务标记正常显示、NPC 头顶任务图标正常、持续法术伤害正常、长时间运行 GC 压力下降。
