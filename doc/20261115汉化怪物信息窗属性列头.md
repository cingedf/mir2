# 20261115汉化怪物信息窗属性列头

> server.exe UI 属性英文显示全盘汉化（H1）：怪物信息（实验）窗体动态 Stat 列头由英文枚举名拆分改为本地化映射中文。

## 现象

- server.exe「怪物（实验）」窗体（MonsterInfoFormNew）的动态属性列头（MinAC/MaxAC/HP/MP 等 13 个英文 Stat 键）显示为英文拆分串（Min AC / Max AC / HP / MP…），其余中文键（准确/敏捷等）显示正常——英文键未经本地化映射。

## 排查过程

- 列头生成链：`CreateDynamicColumns()`（MonsterInfoFormNew.cs:101-128）遍历 `StatEnums`（=Enum.GetValues(typeof(Stat))），列头 `HeaderText = $"{strKey} {sign}"`，其中 `strKey = RegexFunctions.SeperateCamelCase(key.Replace("Rate","")...Replace("Percent",""))`——即枚举名驼峰拆分，无本地化。
- 数据链与显示无关：回写链 ReadCellData 按 `col.Name.Substring(4)` Enum.Parse、填充链按 `"Stat"+stat.ToString()` 写 DataTable（167-172/632-637）、CSV 导入导出按 Column.Name 匹配——**全部走 Name 不走 HeaderText**，改显示零回归。
- 基础设施已就绪（commit e408dad/b1b01a3）：`ToLocalizedServerString(this Enum)`（Shared\Language.cs，查 ServerTextMap.Enum，无映射回退枚举名）+ 服务端 Chinese.json Enum 段 60 键（Stat 13/RequiredType 12/BindMode 17/SpecialItemMode 13/LightSetting 5）。
- 既有 Replace("Rate"/"Multiplier"/"Percent") 逻辑核查：中文 Stat 键与 14 个英文 Stat 键均无这些后缀（Rate/Multiplier/Percent 后缀键不存在于 Stat 枚举），整行替换无信息丢失。
- 全窗体 SeperateCamelCase 引用仅此一处（grep 证实），无共享方法需同步（@b61@ 记载的 PopulateColumnsToListView 实不存在）。

## 修复内容（`Server.MirForms\Database\MonsterInfoFormNew.cs`，CreateDynamicColumns 一处）

```csharp
var key = stat.ToString();
// 20261115 汉化（H1）：动态列头改走本地化映射（Chinese.json Enum 段，MinAC=下限防御 等），无映射回退枚举名
var strKey = stat.ToLocalizedServerString();
```

- 显示效果：MinAC→下限防御、MaxAC→上限防御、MinMAC→下限魔御、MaxMAC→上限魔御、MinDC→下限攻击、MaxDC→上限攻击、MinMC→下限魔法、MaxMC→上限魔法、MinSC→下限道术、MaxSC→上限道术、HP→生命值、MP→魔法值、Hero→英雄；中文键（准确/敏捷/…）无映射回退枚举名显示不变。
- `%`/`x` 符号逻辑（key.Contains("Percent"/"Multiplier")）保留——与 key 变量配合不受影响。
