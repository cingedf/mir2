## 结论与建议

1. **最值得做的三件**：#1 掉落表有效概率+模拟、#3 脚本检查中心、#4 变量管理——三者都是“只读/离线分析 + 可视化”，不触碰运行中服务端，风险低、对杂质脚本治理价值高。**（第1轮已全部实现并验证）**
2. **复用优先**：#7 补丁管理、#16 表格编辑优先接入现成工具（LibraryEditor / 外部表格），不重造轮子（家法）。
3. **暂缓**：#17 多区同步/M2 重载（我方 Crystal 引擎不适用 GOM 的 M2）、#18 AI 辅助——前者风险高，后者待核心稳定后再评估。
4. **第2轮新洞察（均已实现）**：#21 变量引用链追踪、#22 地图爆率可视化、#23 地图关系图、#24 GOTO 死循环检测——全部为现有 P0 能力的自然延伸，只读/离线分析，风险低。第2轮已逐项实现并自检通过。
5. **第3轮（均已实现）**：#25 爆率格式化、#26 自定义命令导入导出、#6 路径导航跳转、#8 按类型动态字段名——4 项全部完成并编译通过。编码实证纠偏：CustomCommands.txt=UTF-8 BOM+LF、NPC命令说明.txt=UTF-8 无 BOM（均非子代理初判的 GBK）；Drops\*.txt 仍为 GBK/CRLF。#8 对齐 Crystal 官方 CreateDynamicColumns 家法（本血统无 StdMode，等价 ItemType:byte）。**第4轮建议**：P1 #9 任务链可视化增强（节点图标区分 Kill/Collect/Deliver/Talk）、#10 UI 编辑器（先调研 Crystal UI 体系）、#11 NeedLevel/伤害字段计算器、#12 装备内观坐标；P2 #19 Loot Table 轮盘、#20 对话节点图增强。
6. 本清单作为 roadmap，后续每完成一项按家法逐块实现→编译验证→文档→提交闭环。本清单随网络深挖每轮更新。
