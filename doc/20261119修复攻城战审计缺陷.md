# 20261119修复攻城战审计缺陷

## 现象

新维度审计（攻城战/行会战/Conquest 路线）在现网配置「占领皇宫」+「申请启动」下回报多项缺陷。逐项读现场甄别后，6 项属实并修复，其余为征服模式/争夺国王模式的潜在扩展条件（当前配置不可触发）或有争议配置驱动项，登记不修。

## 排查过程

逐项读现场核实引用链（历史多次出现子代理误报，必须验证）：

1. **P1-1 宣战无 rank 校验**：NPCSegment.cs:4646 ScheduleConquest 只判 `player.MyGuild != null && Guildindex != Owner && !WarIsOn`，无任何 rank 判断——任意普通行会成员可把本行会提交为攻城方，劫持会长宣战权。对比历史 GuildWarReturn(:10797)/PurchaseGuildTerritory(:10984) 均已限 Ranks[0]。
2. **P1-6 开关城门无归属校验**：NPCSegment.cs:4662 `OpenDoor()`/:4675 `CloseDoor()` 直接执行，action 内无任何行会/rank 判断；配置脚本子页 [@openmaindoor]/[@closemaindoor] 无独立权限门，跳子页即可开关守方城门左右胜负。
3. **P2-4 城墙存档写错字段+NRE**：ConquestGuildInfo.cs:308 `if(Wall!=null) Health=Wall.HP;` 已同步 Health 字段，但 :310 `writer.Write(Wall.Health)` 写的是运行时对象 Wall（Wall==null 时 NRE，且未持久化同步好的 Health）。
4. **P1-4 弓箭手对象泄漏**：ConquestGuildInfo.cs ArcherInfo.Spawn :527 直接覆盖 `ArcherMonster` 引用，旧对象从不 Despawn——重复 Spawn（ConquestObject.Reset）致地图残留幽灵弓箭手。对比 Wall.Spawn:315 先 `Despawn()`。
5. **P1-5 LoadNPCs 复制粘贴越界**：ConquestObject.cs:280-287 第二循环遍历 `PalaceMap.NPCs`，:284 设置 `PalaceMap.NPCs[i].Conq`，但 :285 错写成 `ConquestNPCs.Add(ConquestMap.NPCs[i])`——用 PalaceMap 索引 i 去索引 ConquestMap.NPCs，PalaceMap.NPCs.Count > ConquestMap.NPCs.Count 时越界崩溃，且加错对象。
6. **P1-2/P1-3【不修】**：读 ConquestObject.cs:803 确认 KingPoints 累加整块在 `case ConquestGame.争夺国王:` 分支内，EndWar :929 TryGetValue 在 `case 征服模式` 分支内，当前配置「占领皇宫」均不可达。

## 修复内容

1. **P1-1**（NPCSegment.cs:4646）：条件末尾追加 `&& player.MyGuildRank == player.MyGuild.Ranks[0]`——仅会长可提交宣战。
2. **P1-6**（NPCSegment.cs:4662/:4675）：开关城门前加 `if (!player.IsGM && (player.MyGuild == null || player.MyGuild.Guildindex != Conquest.GuildInfo.Owner || player.MyGuildRank != player.MyGuild.Ranks[0])) return;`——占领方守门会长操作，GM 例外（OpenGate 用大写 `Conquest`、CloseGate 用小写 `conquest`）。
3. **P2-4**（ConquestGuildInfo.cs:310）：`writer.Write(Wall.Health);` → `writer.Write(Health);`（持久化已同步的健康值，Wall==null 不崩）。
4. **P1-4**（ConquestGuildInfo.cs:519 ArcherInfo.Spawn 开头）：加 `if (ArcherMonster != null) { ArcherMonster.Despawn(); ArcherMonster = null; }`。
5. **P1-5**（ConquestObject.cs:285）：`ConquestNPCs.Add(ConquestMap.NPCs[i]);` → `ConquestNPCs.Add(PalaceMap.NPCs[i]);`（带 :284 上下文唯一定位，避开 :272 同文本）。

**不修（登记利弊）：**
- **P1-2 KingPoints 跨战残留 / P1-3 EndWar null Guild**：KingPoints 累加在 `case 争夺国王:` 分支、:929 TryGetValue 在 `case 征服模式:` 分支，当前部署配置「占领皇宫」不可触发。若未来启用争夺国王/征服模式，需补 StartWar 时 `KingPoints.Clear()` 与 EndWar :929 的 `if(item.Key.Guild==null)continue;`。
- **其余 P2-1/2/3/5/6/7/8/9**：多为征服模式/配置驱动（AutoSchedule 时间边界、Bind 正序删除跳元素、控制点堆人刷满、多攻城 tempConquest 覆盖等），当前单攻城「占领皇宫」配置不触发或属低优先健壮性，改动面与收益不成比例，登记不修。
