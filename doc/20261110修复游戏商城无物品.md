# 20261110 修复游戏商城无物品

## 现象

进游戏后市场面板的"游戏商店"标签为空，不显示任何可购物品。

## 排查过程（简述）

1. 用户库（run\Server）商城货架实际有 106 条货（`Exports\GameShop_Export.txt`），deploy 库初始为空铺货后，用无头工具回读却显示 0 条，且 DB 文件体积变大（写入成功）——读写不一致。
2. 定位到引擎读盘逻辑：`Envir.LoadDB()` 读取 GameShopList 时，每条记录经 `BindGameShop(item, …)` 绑定物品，而该方法遍历的是 `Envir.Edit.ItemInfoList`（编辑器数据槽）。
3. Server.MirForms 的正常流程会先跑 `EditEnvir.LoadDB()` 给编辑器槽充数据（SMain.cs 415 行附近），所以游戏服务端和编辑器都无感；**无头工具（没有 Edit 数据）里 BindGameShop 全部失败，读盘时每件货架被静默丢弃**。之前的"全 0"读数全是此 bug 的假象。

## 修复内容

- `tools/GameShopMigrate/Program.cs`：新增 `LoadDbTwoPass()`——第一遍 `LoadDB()` 填充 `Main.ItemInfoList`，随后把物品名表同步进 `Envir.Edit.ItemInfoList`，第二遍 `LoadDB()` 时 `BindGameShop` 可正常绑定；5 处 `Envir.Main.LoadDB()` 全部替换为该方法。
- `tools/GameShopMigrate/` 同时具备 export / import / items / clear / seed 五种模式（seed 支持参考清单+名字映射+分档定价）。

## 验证证据

- deploy 库 export 回读 = **43 条**，名称全部非空；抽查价格合理（加速灵药 30000 金、翡翠/金铃铛 10000 金+40 元宝、经验值20%卷 6000 金、Stock=0 表无限）。
- 修复版工具回读 run\Server 库 = **106 条**，与 `GameShop_Export.txt` 行数一致（此前假 0 推翻）。
- 部署侧 Server.exe 重启冒烟：146 增益 / 205 配方 / 817 地图 / 掉落 / 环境 / 网络全链无错，7000 LISTENING。

## 关联事项（同日铺货）

按参考清单类型对 deploy 库上架 43 件（106 参考项中 64 项在 deploy 物品池无对应未铺）。名字映射与定价档存于 `C:\1.40\mir2-deploy\_seed-map.json`，可幂等重放（seed 模式自动跳过已在架物品）。

## 回滚方法

- 货架清空：`GameShopMigrate clear`（在目标库目录运行）。
- 整库回退：把铺货前备份复制回原位——`C:\1.40\mir2-deploy\_baseline-server-1001\Server.MirDB` → `C:\1.40\mir2-deploy\Server\Server.MirDB`（操作前须停服）。
