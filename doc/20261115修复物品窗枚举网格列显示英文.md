# 20261115修复物品窗枚举网格列显示英文

> 十问③第二轮：deploy 产物加载链验证无问题（Language=Chinese、Enum 306 键、RequiredType_ 12 键齐全、PowerShell 运行时探针合并成功）——真正病根在**物品信息窗网格枚举列绑定的 byte-vs-enum 类型不匹配**，闭合态单元格永不匹配数据行值，回退显示枚举英文名。本轮修复类型 mismatch 本身。

## 现象

- 物品信息列表「需要类型」列（下拉列）显示 `MaxDC/MaxAC/MaxMAC` 等英文枚举名，而非中文（json Enum 段 RequiredType_ 12 键齐全却未生效）。
- 展开下拉后选项倒是中文（Enum2DataTable Display 列=ToLocalizedServerString），闭合态才错——差异指向**单元格值与列表项值的匹配环节**。

## 排查过程

- 加载链排除：deploy\Configs\Setup.ini `Language=Chinese`；`[GameLanguage]::LoadServerLanguage(deploy\Localization\Chinese.json)` 反射调用 → Enum count=306，`RequiredType_MaxDC='上限攻击'` 命中——翻译数据与加载全好。
- 病根定位（ItemInfoFormNew.cs:143-160 Enum2DataTable<T>）：
  ```csharp
  enumTable.Columns.Add(new DataColumn("Value", Enum.GetUnderlyingType(typeof(T))));  // ← byte
  ```
  Value 列建为**枚举底层类型（byte）**，行值 `EnumRow["Value"] = e` 装箱枚举写进 byte 列被转成 byte；网格单元格值=DataColumn PropertyName 绑定来的**装箱枚举**。DataGridViewComboBoxCell 用 Equals 匹配 cell.Value（RequiredType.MaxDC）与列表项 Value（byte 3）→ **永不匹配** → 单元格回退显示原始值 ToString=英文。
- 该缺陷自 H5 血统延续，与构建新旧无关——第二轮「重启即好」结论被推翻，正式修正。
- 运行时探针双铁证（模拟 DataGridViewComboBoxColumn 全流程：BindingContext→DataSource→行→赋值装箱枚举→句柄→FormattedValue）：
  - 旧 dll（deploy 62746FA5...）：ValueColType=System.Byte，CellFormatted=**[MaxDC]** ← 用户症状 1:1 复现；
  - 新 dll（修复后）：ValueColType=RequiredType，CellFormatted=**[上限攻击]** ← 修复生效。
  - （注：DataRow 枚举列底层存储特殊，"行值 Equals 诊断"在新旧 dll 都显示 False，无鉴别力；以 FormattedValue 为准。）

## 修复内容

1. `Server.MirForms\Database\ItemInfoFormNew.cs` Enum2DataTable<T>()：Value 列 `Enum.GetUnderlyingType(typeof(T))` → `typeof(T)`——行值与单元格同为装箱枚举，Equals 匹配成功→显中文。影响面：该窗网格 6 枚举列（ItemType/ItemGrade/ItemRequiredType/ItemRequiredGender/RequiredClass/ItemSet，均 ValueType=typeof(枚举)）+MonsterInfoFormNew——全部安全；写回链枚举 cast 兼容（DataRow 内部按底层类型存储，枚举强转不变）。
2. `Server.MirForms\Database\MonsterInfoFormNew.cs` Enum2DataTable<T>(bool sort=false)（:76-100）：同改 typeof(T)（MonsterImage 下拉 sort=true 重载同样受益）。
3. 顺手汉化：`ItemInfoFormNew.cs` InitializeItemInfoFilters 筛选下拉显示值 `type.ToString()` → `type.ToLocalizedServerString()`（Key 保持字节字符串供 RowFilter；ItemType_ 键暂无 json 映射时回退英文名=与原行为一致，无回归）。
