# 20261115修复平衡设置预览空白与属性行枚举显示

> 十问⑧第二轮：用户反馈平衡设置右侧「1-50级统计预览」实际全空白。排查确认预览文本框几何位置无遮挡、链路存在，但**填充只在点选/编辑属性行时触发**——初次进页只有静态标题「1-50级统计预览」孤立在窗体右缘窄条上，观感=空白。本轮补「进页即填充」链并顺手修三处显示问题。

## 现象

- 平衡设置窗职业页/英雄页右侧只有一行小字标题（用户问「右边是干什么用的」「看着都是空白的」），无预览内容。
- 属性行「属性类/方案/综合属性/类型/英雄类型」列闭合态显示英文枚举名（下拉展开才中文）。

## 排查过程

- 几何排除：lblClassStatExample（x=836）与 lblHeroStatExample（x=838）挂窗体级，tabControl1 右缘 834<836，无重叠遮挡。
- 根因（BalanceConfigForm.cs 填充链）：UpdateClassStatExample 的三个调用点（classGridView_CellValueChanged/SelectionChanged/classCapGridView_CellValueChanged）全部依赖用户**手动点选属性行**，且 Populating 加载期守卫跳过——窗体加载完成到点选之前 Text 从未被赋值（只有 Designer 静态标题）。英雄页镜像同病。
- 换行符缺陷：`"{0} - {1}\r\r"` 中 `\r` 无效、`"Level {0}\t: {1}\n"` 中 `\n` 单符不构成 Windows 换行——即便填充了，Label 也会整段挤成一行加重「空白」观感。英雄版表头还直接用英文枚举名（`{1}`, type 原值未走映射）。
- H6 遗产核查：BuildEnumTable<T> 已用 typeof(T) 建列（无 H5 byte 列 bug），下拉列表中文正常；仅闭合态单元格显示走 ToString=英文。

## 修复内容（`Server.MirForms\BalanceConfigForm.cs`，不动 Designer）

1. **进页即填充**：tabControl1_SelectedIndexChanged 在 tabPage3/tabHero 置 Visible 后调用新增的 `RefreshClassStatExample()`/`RefreshHeroStatExample()`。
2. **切职业即刷新**：ClassComboBox_SelectedIndexChanged/HeroClassComboBox_SelectedIndexChanged 末尾（Populating=false 后）各加一次刷新。
3. **新方法 RefreshClassStatExample/RefreshHeroStatExample**：取选中属性行（无选中取首行）的 Type 值调用原 UpdateXxxClassStatExample——原填充链/守卫零改动，Populating 期仍不填。
4. **格式归一**：`"{0} - {1}\r\r"`→`"{0} - {1}\r\n\r\n"`、`"Level {0}\t: {1}\n"`→`"Level {0}: {1}\r\n"`（职业+英雄两处）；英雄表头 `type`→`type.ToLocalizedServerString()`。
5. **顺手汉化（闭合态枚举）**：ctor 挂 `classGridView/classCapGridView/heroGridView/heroCapGridView` 四网格共用 `LocalizedEnumCellFormatting`——六列（BaseStatType/BaseStatFormula/CapType/HeroBaseStatType/HeroBaseStatFormula/HeroCapType）枚举值经 ToLocalizedServerString 显示（`e.FormattingApplied=true`，底层值不变）。

## 验证证据

- `dotnet build Server.MirForms\Server.csproj -c Release`：0 警告 0 错误（15.97s）。
- 引用复核：Refresh 两方法仅读 Rows[0]/SelectedRows[0] 的 Type 单元格（null 守卫覆盖新增行）；Update 原调用点（点行/编辑/上限编辑）不变——旧行为是超集；CellFormatting 只改显示不改数据链（Cats/Stats 读 Value 端不经过 FormattedValue）。
- 预览内容语义不变：1..50 级逐级 `Math.Min(cap, stat.Calculate(职业, level))`。
