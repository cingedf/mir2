# 20261119修复战斗反弹递归与buff健壮性

## 现象

战斗/技能/buff 深度审计回报 1 P0（全服崩溃）+2 P1（NRE/客户端可触发）+4 P2（状态机/溢出健壮性）：

1. **反弹无限递归爆栈杀进程**（P0，HumanObject.cs Attacked(HumanObject,...)）：A 打 B→B 反弹→A 反弹→…→StackOverflow 不可 catch 终止服务端进程。
2. **DoubleSlash 未学技能 NRE**（P1）：客户端构造 C.Attack.Spell=DoubleSlash 包，未学该技能玩家 GetMagic 返 null 未判→magic.Info NRE。
3. **AddBuff 返回 null 未判 NRE**（P1）：未注册 BuffType（旧存档移除类型 / NPC GIVEBUFF 传数字）base.AddBuff 返 null，两处覆写直接解引用。
4. **待删 buff 误判有效**（P2）：FlagForRemoval 的 buff 被 HasBuff 判有效、重施不清标记→1 秒后仍被删（解隐身重施失效）。
5. **ProcessBuffs 不校验空 buff**（P2）：每 tick 遍历空/无效 Info buff→NRE。
6. **施法校验失败仍占全局冷却**（P2）：时标赋值在冷却/MP 校验之前，失败也锁 1.8s 禁咒+动作锁。
7. **伤害/盾时长整数溢出**（P2）：武器增伤加法 int 回绕负值→判 MISS 伤害归零；(damage-armour)*60 int 溢出→盾时长异常近似永久。

## 排查过程

- P0：逐行读反弹分支，确认反射调用传 `damageWeapon=false` 但反弹判断未使用该参数→同一重载递归；同文件 Attacked(MonsterObject,...) 反射给 Monster 不同重载不递归（不动）。
- P1-2：对照同 switch 的 Thrusting/HalfMoon/TwinDrakeBlade 均有 magic==null 检查，唯 DoubleSlash 遗漏。
- P1-3：读 base.AddBuff（MapObject.cs）确认未注册类型 `return null`；可达路径=NPC GIVEBUFF 数字（Enum.TryParse 数字也 true）+ 旧存档 BuffType 恢复（PlayerObject.cs:1404-1410）。
- P2-4：读 RemoveBuff（设 FlagForRemoval=true/ExpireTime=0）、ProcessBuffs（清标记）、AddBuff else 分支（刷新但不清标记）、HasBuff 两重载（不判标记）确认状态机漏洞。
- P2-6：读 Magic 方法完整顺序，确认时标赋值（:3797-3805）在 CastTime/MagicCost 两处 return 之前。
- P2-7：grep 确认魔法盾/金刚术 duration 计算共 **6 处**（子代理仅报 2 处，同类问题统一修）。

## 修复内容

**改 Server\MirObjects\HumanObject.cs：**
1. P0+P2：`damage += 武器增伤` → long 中间量+clamp；反弹判断加 `damageWeapon &&` 守卫切断递归。
2. P1-2：DoubleSlash case 加 `if (magic == null) { spell = Spell.None; break; }`。
3. P1-3：AddBuff 覆写 `if (b == null) return null;`。
4. P2-5：ProcessBuffs 加 `if (buff == null || buff.Info == null) { Buffs.RemoveAt(i); continue; }`。
5. P2-6：AttackTime/SpellTime/ActionTime/LogTime 时标赋值整体移到 CastTime+MP 校验通过之后（Hidden 移除保持原位）。
6. P2-7：6 处魔法盾/金刚术 duration 改 long 中间量+clamp。

**改 Server\MirObjects\MonsterObject.cs：**
7. P1-3：AddBuff 覆写 `if (b == null) return null;`。
8. P2-5：ProcessBuffs 同款判空清理。
9. P2-7：武器增伤 long+clamp。

**改 Server\MirObjects\MapObject.cs：**
10. P2-4：AddBuff else 分支加 `buff.FlagForRemoval = false;`（重施复活）；HasBuff 两重载加 `if (Buffs[i].FlagForRemoval) continue;`。

## 验证证据

- `dotnet build Server.MirForms\Server.csproj -c Release`：**0 警告 0 错误**；
- 行为复核：正常反弹（damageWeapon=true）不变、反射路径（false）不再递归；未学技能/未注册 buff 构造包不再 NRE；待删 buff 重施可复活；施法失败不再占全局冷却；正常数值下伤害/盾时长与修复前完全一致（clamp 仅对异常大值生效）；
- 待实测：双方高反弹装备互殴不再崩服；解隐身立即重施生效。
