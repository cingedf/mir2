# 20261116修复审计批1服务端健壮性P1P2

## 现象

第十二轮四路全仓审计的「服务器核心」报告（无 P0，P1×12 + P2×5）中，属服务端健壮性/并发安全类的问题集中在：UI 线程与主循环并发访问共享集合、存档异步收尾异常被静默吞掉、热重载与运行线程的集合竞态、管理界面直调玩家操作绕过主循环。

## 排查过程

1. **UI 线程并发点**：SMain 三个 Tab 处理/广播方法直接 foreach `Envir.Players`/`Envir.GuildList`，主循环同时可 Remove 元素 → `InvalidOperationException` 或漏发。
2. **租赁孤儿记录**：`ProcessRentedItems`/`ReturnRentalItem` 用角色名反查 `GetCharacterInfo`，角色被删后返回 null 直接解引用 → NRE 被熔断计数吞掉 → 租赁系统静默失效。
3. **存档异步收尾**：四个 `EndSave*Async` 的 catch 全部空体——磁盘满/权限问题导致坏档时无人知晓。
4. **热重载竞态**：`ReloadDrops` 对正在被怪物线程遍历的 `Drops` 列表 `Clear()`+逐条 Add；`Robot.Clear()` 与主循环 `Robots.Where(...)` 延迟枚举竞态。
5. **管理操作线程**：PlayerInfoForm 的踢人/击杀/回城直调 `Player.Die()`/`Player.Teleport()`——Teleport 落点 `MapObject.Teleport`（RemoveObject→改 CurrentMap→AddObject）与 Die（LastHitter/PKPoints）均无锁，与主循环并发=真实风险；Kick（SendDisconnect→SoftDisconnect→StopGame）全链 `_connectionLock`+`Envir.AccountLock` 双锁保护，确认安全。

## 修复内容

**P1 六项：**

1. SMain.cs 三处快照化（:187/:314/:491）：`Envir.Players.ToArray()` / `Envir.GuildList.ToArray()` 后遍历。
2. Envir.cs 租赁 NRE 两处：ProcessRentedItems(:3670) `rentingPlayer == null` 时 continue；ReturnRentalItem(:3758) `owner == null` 时 return false。
3. Envir.cs 四个 EndSave*Async 空 catch 补日志（:1354/:1417/:1453/:1502）：`MessageQueue.Enqueue(ex)`（全仓既有惯例）。
4. Envir.cs ReloadDrops(:4216) 原子替换：怪物 Drops 与 Fishing/Awakening/Strongbox/Blackstone/LotteryStunt 五个静态列表均改「局部 List 加载完 → 整体重指向」，读侧持旧引用遍历不受影响。
5. PlayerInfoForm 三处投递主循环（Kill/PetsDie/SafeZone）：
   - `DelayedType` 尾部追加 `GMTeleport`（纯内存枚举，不进网络包，对既有 switch 无破坏）；
   - `PlayerObject.Process` 加两 case：`DelayedType.Die → Die()`、`DelayedType.GMTeleport → Teleport(bindMap, bindLocation, true, 0)`；
   - KillButton/KillPetsButton（倒序逐宠）/SafeZoneButton（先 GetMap 判空）改 `ActionList.Add(new DelayedAction(...))` 投递；Kick 保留直调（双锁已确认安全）。
6. Robot.cs:78：`Robots.Where(...)` 加 `.ToArray()` 快照消费。

**P2 三项：**

7. Envir.cs:2318 Accept 满员等待条件加 `&& Running`（关服不滞留）。
8. Map.cs:793 ProcessRespawns：`Success` 移入循环体 + `if (!respawn.Spawn()) Success = false;`（不覆盖已记录失败）。
9. HttpService.cs:82 空 catch 改节流日志（`_lastErrorLogTime` 每分钟最多 1 条，防刷屏）。

**暂不动（风险中，记录在案）：** 存盘 IO 后台化（数据本身无竞态仅卡顿）、ReloadNPCs 脚本重载锁、Valor 战场怪物线程投递。
