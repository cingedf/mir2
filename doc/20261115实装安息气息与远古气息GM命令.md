## 修复内容（`Server\MirObjects\PlayerObject.cs`，@华丽雨光 case 后新增）

```csharp
case "安息之气":
case "远古气息":
    if (!IsGM) return;

    {
        int minutes = 60;
        if (parts.Length >= 2 && (!int.TryParse(parts[1], out minutes) || minutes <= 0))
            minutes = 60;

        // 20261115 实装：上游预留 buff（零授予），GM 光环命令组；纯视觉光环无 Stats，
        // 效果语义=去除身上的负面状态气息（RemoveOnDeath+Visible 已在 BuffInfo 注册）
        var auraType = parts[0].Equals("安息之气") ? BuffType.安息之气 : BuffType.远古气息;
        AddBuff(auraType, this, Settings.Minute * minutes, new Stats(), true);

        ReceiveChat($"{parts[0]}光环已激活，持续 {minutes} 分钟。", ChatType.System);
    }
    return;
```

- 双 case 共享体：IsGM 守卫、分钟缺省 60、非法/非正数回落 60、按 parts[0] 判型、AddBuff（duration=相对毫秒，Settings.Minute*分钟）、ReceiveChat 确认。
- GM命令.md【六、buff增益类】同步补录两条用法（未跟踪文件，随本轮更新）。
