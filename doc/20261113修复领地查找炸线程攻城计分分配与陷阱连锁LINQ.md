# 20261113 修复领地查找炸线程攻城计分分配与陷阱连锁LINQ

> 深度体检第二轮产出三项可选修复，用户拍板「按建议修复」后实施。

## 现象

1. **GuildObject 领地查找健壮性隐患**：`Process()`（每分钟级）、`EndGT()`、`GTForSale()`、`EndGTSale()` 四处均用 `Envir.GTMapList.First(x => x.Index == GTIndex)`——`First` 无匹配即抛 `InvalidOperationException`。行会领地图被删档/租约清理顺序异常时，Process 每分钟到点必炸一次调用链。`EndGT()` 内注释「若地图已不存在则跳过」证明作者已知该场景却误用了 `First`。
2. **ConquestObject.ScorePoints 攻城期每秒分配热点**：征服模式分支内层 `controlFlagPoints.Keys.ToList()`（755 行）每玩家每 tick 新分配一个 List，复杂度 O(旗帜×玩家×行会)/秒，攻城期间是真实 GC 压力（平时零开销）。
3. **SpellObject 爆炸陷阱连锁 LINQ**：`Process(DelayedAction)` 中 `CurrentMap.GetSpellObjects(Spell.ExplosiveTrap, Owner).Where(...)`——`GetSpellObjects`（Map.cs:3071）每次全量 new List 扫 Map.Spells，再 LINQ 延迟枚举，引爆时产生双份临时分配。

## 排查过程

- 深度体检第三/四轮逐文件核查 `SpellObject/GuildObject/ConquestObject` 的 Process 热路径：
  - GuildObject.Process 领地段与 EndGT/GTForSale/EndGTSale 全部 `First` 直取，确认无空判；
  - ConquestObject.ScorePoints 征服模式分支确认 `Keys.ToList()` 位于「每玩家」循环体内（非每旗帜一次）；
  - SpellObject 834 行确认 LINQ 链 + GetSpellObjects 的 List 分配。
- 复核 `Envir.GTMapList` 生命周期（Envir.cs 121/1707/1848/1886/1980）：LoadGT 时 `FirstOrDefault` 建立映射、存档 Clear 后重建，确认运行期确实存在查不到的窗口（删档/加载失败）。
- 复核 293-313 行 `HasGT` 段已是 `foreach + break` 手写查找（健康模式），四处 `First` 与之不一致，属笔误级遗漏。
- 全仓 grep `GTMapList`：PlayerObject 10773 已用 `FirstOrDefault`，进一步确认修法与仓库既有习惯一致。

## 修复内容

1. **`Server\MirObjects\GuildObject.cs`**（四处 First → FirstOrDefault + 空判）：
   - `Process()` 领地段：`FirstOrDefault` 查 gt，`gt == null` 时清零 GTIndex/GTRent/GTKey 后正常返回（不再炸）；非空时保留原有 Begin 倒计时与租约到期 EndGT 逻辑。
   - `EndGT()`：`FirstOrDefault` + 空判——领地图不存在时仅清理行会侧状态（GTIndex=-1、GTRent=MinValue、GTKey=0）即 return，实现原注释意图。
   - `GTForSale()`：空判时提示 TerritoryAlreadyForSale 并返回 false（语义=当前不可挂售）。
   - `EndGTSale()`：空判时提示 TerritoryNotForSale 并返回 false。
2. **`Server\MirObjects\ConquestObject.cs`** ScorePoints 征服模式分支：删除 `List<GuildObject> guilds = controlFlagPoints.Keys.ToList();` 中间分配，改为直接 `foreach (var guild in controlFlagPoints.Keys)`（仅读键不增删字典，枚举安全），逻辑不变。
3. **`Server\MirObjects\SpellObject.cs`** 爆炸陷阱连锁：`GetSpellObjects(...).Where(...)` 收敛为手写 for 直扫 `CurrentMap.Spells`——同 Spell、同 Caster、同 ExplosiveTrapID 即 `DetonateTrapNow()`，零临时分配。行为与原实现一致（原实现 `GetSpellObjects(spell, caster)` 过滤 Caster + Where 过滤 TrapID）。
