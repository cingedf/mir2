# 20261118修复服务端残余bug批

## 现象

本轮「bug + 性能 + 内存 + 启动时间」四路子代理审计的**残余 bug 路**回报 15 项缺陷，其中服务端逻辑/健壮性类 15 项（P1×8、P2×6+次要）。缺陷可被伪造包/异常数据/删档状态触发，导致资产刷取、物品销毁、金币蒸发、线程中断（NRE/除零/参数倒挂）。本批集中修复服务端部分。

## 排查过程（关键现场）

1. **MergeItem 自合并刷物/销毁**（PlayerObject.cs MergeItem :7118 合并核心）：`fromID==toID` 同网格时 tempFrom/tempTo 引用同一对象且无同源校验。X≤StackSize/2 → `tempTo.Count += tempFrom.Count`（=2X）且 `arrayFrom[index]=null` 销毁整叠；X>半 → 凭空补满到 StackSize。两种都刷物/销毁。
2. **多处 NRE（删档/离线/空槽）**：GainExp 配偶/师父（:927/:940）、LevelMagic 师父（HumanObject.cs:7972）、MonsterObject.Attacked 师徒 mentee（:2941）、师徒/情侣私聊（:2176/:2266）、传送 lover（:4937）、红名死亡左戒指槽（:737）、钓鱼 reel（:11654）——均为 GetCharacterInfo/槽位返回 null 后直接取 .Name/.CurrentDura/.UniqueID。
3. **Drop 单件失败中断整批**（MonsterObject.cs:1275）：`if (!DropItem(item)) return;` 提前终止，丢弃后续所有掉落物。
4. **钓鱼掉落取错变量**（:11620）：`CreateDropItem(drop.Item)`（配置基础物品）而非遍历所得 `dropitems`（DropRewardInfo.Items 的 ItemInfo 元素）。
5. **钓鱼 Random.Next 参数倒挂**（:11555/:11557）：装备 stats 可使 nibbleMin>nibbleMax、failedAddSuccessMin>Max → Random.Next(min>max) 抛 ArgumentOutOfRangeException 中断钓鱼。
6. **SplitItem 丢属性**（:6862）：`CreateFreshItem` 只拷 Info/新 ID/耐久，丢强化/觉醒/耐久/宝石/租赁等属性。
7. **组队金币余数丢失**（:8138）：`gold=gold/count` 整商发放，gold%count 凭空消失。
8. **GameshopBuy 除零+截断**（:14342/:14459）：StackSize==0 除零；`ushort quantity=(ushort)(Quantity*Product.Count)` 超 65535 截断少发货。

## 修复内容（全部在 C:\\1.40\\mir2-angelk727\\Server\\MirObjects\\）

**MergeItem（PlayerObject.cs）**：合并核心前插 `if (tempFrom == tempTo) { Enqueue(p); return; }`（引用相等=自合并，合法的不同物品不受影响）。

**8 处 NRE 判空（防御性收敛，行为等价）**：
- GainExp 配偶/师父：`lover == null ? null : Envir.GetPlayer(lover.Name)` / `mentor == null ? null : ...`
- LevelMagic 师父：`player = mentor == null ? null : Envir.GetPlayer(mentor.Name)` + 后续 if 补 `player != null &&` 守卫
- Attacked mentee（MonsterObject.cs）：`player = mentee == null ? null : Envir.GetPlayer(mentee.Name)`（不 return，后续 Master 逻辑照常）
- 师徒/情侣私聊：`player = Mentor/Lover == null ? null : Envir.GetPlayer(...)` + null 时 ReceiveChat 提示
- 传送 lover：`ply = lover == null ? null : Envir.GetPlayer(lover.Name)`
- 红名死亡：`var leftRing = Info.Equipment[左戒指]; if (item.WeddingRing != -1 && leftRing != null && leftRing.UniqueID == item.UniqueID)`
- 钓鱼 reel：`if (reel == null || !FishingAutocast || reel.CurrentDura == 0)`

**其余 P2**：
- Drop：`if (!DropItem(item)) continue;`（单件失败不丢后续掉落）
- 钓鱼掉落变量：`CreateDropItem(drop.Item)` → `CreateDropItem(dropitems)`
- 钓鱼 Random.Next：插入 `lo=Math.Min(...)/hi=Math.Max(...)` 排序后两处 Next 改用 lo/hi
- SplitItem：`temp = originalItem.Clone(); temp.UniqueID = ++Envir.NextUserItemID; temp.Count = count;`（复用仓库权威 UserItem.Clone()，已深拷 AddedStats）
- 组队余数：`share=gold/count; remainder=gold%count;` 前 remainder 名符合条件队员各补 1，总额守恒
- GameshopBuy：`if (Product.Info.StackSize == 0) return;` + `long totalQuantity=(long)Quantity*Product.Count; if (totalQuantity>ushort.MaxValue) return; ushort quantity=(ushort)totalQuantity;`
