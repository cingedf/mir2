# 20261118修复内存泄漏批

## 现象

子代理内存审计回报 Top12 泄漏点，主会话逐项核查引用链后，确认 4 项为真实缺陷并修复；2 项经核查为误报，强行修复会造成玩家资产损失或改动无效，登记不修。

## 排查过程（逐项核查引用链）

### 真实缺陷（4 项，已修）
1. **ErrorThrottle 逐 ObjectID 键永不清**：`ErrorThrottle.Notify` 的 `LastNotify`（ConcurrentDictionary）以 `"ProcessError:"+ObjectID` 为键（写入点 MapObject.cs:423 HandleProcessError），ObjectID 单调自增永不复用 → 字典随每个处理过的对象无限增长。
2. **BigMapDialog.MakeButtons 重复累积**（:512，调用点 :273 + GameScene.cs:1465/2295 收包）：每次 setup 反复 `new MirButton` + 3 个捕获 icon 的委托 + `ButtonList.Add`，无 Clear/Dispose → 重复打开大地图时按钮/事件累积。
3. **GameScene.GameShopUpdate 全量膨胀**（:7060-7065）：服务端可下发多个同名商品条目，无条件 `GameShopInfoList.Add(p.Item)` 不查重 → 重复 update 使列表无限膨胀。
4. **MainDialogs.FullHistory 无上限**（:888）：仅一处 Add 无上限，Update（:895-936）每次 `new List` 全量遍历重建 + Dispose 全部 → 线性增长 + O(n²) 卡顿。

### 误报否决（2 项，不修）
- **ProcessAuction 摘除（子代理 #1，否决）**：核查全仓引用链——`Auctions` 移除点仅 4 处（MarketDelist/MarketGetBack×2/LoadDB 重建），ProcessAuction 只打 Expired/Sold 标记**从不移除是设计意图**：成交分支只把物品邮给买家（:1112），金币要卖家后续 MarketGetBack 才发（PlayerObject.cs:9215 GainGold 扣手续费）；过期物品留 info.Item 等卖家取回（:9198 GainItem）。条目持有的是**待领取资产**，若在 ProcessAuction 直接摘除会导致卖家钱/物永久丢失（P0）。若要限时返还属经济系统行为变更，风险大且用户未要求。
- **MapObject.Remove 清 Effects（子代理 #4，否决）**：实测 MapObject.cs 无 Effects 集合字段（全仓 grep 无匹配，子代理所报 :155-179 实为字段声明区），Remove(HumanObject)/Remove(MonsterObject) 均无特效引用；真正销毁在 Despawn()（Broadcast + Envir.Objects.Remove + ActionList.Clear），特效靠自身 Remove() 退出静态表。无泄漏可清。

## 修复内容

1. **Envir.cs**（ErrorThrottle.Notify）：`long now = Envir.Main.Time;` 后加惰性清理——`if (LastNotify.Count > 512) { long cutoff = now - Math.Max(windowMs, 60000); foreach (var pair in LastNotify) if (pair.Value < cutoff) LastNotify.TryRemove(pair.Key, out _); }`。阈值触发才扫描，清理超过节流窗口的陈旧键，节流语义不变。
2. **BigMapDialog.cs**（MakeButtons:512）：方法开头 `foreach (MirButton old in ButtonList) old.Dispose(); ButtonList.Clear();`。
3. **GameScene.cs**（GameShopUpdate:7065）：Add 前 `GameShopInfoList.RemoveAll(x => x.GIndex == p.Item.GIndex);`（`p` 是 S.GameShopInfo 无 GIndex，其字段 `p.Item` 才是含 GIndex 的 GameShopItem——踩坑 CS1061 后修正）。
4. **MainDialogs.cs**（FullHistory:888 后）：`while (FullHistory.Count > 500) FullHistory.RemoveAt(0); if (StartIndex >= FullHistory.Count) StartIndex = FullHistory.Count - 1;`（保留最近 500 条，同步修正索引越界）。
