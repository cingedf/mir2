# 20261112修复F12设置面板标签页化（内挂区块出界）

## 现象

- F12 设置面板底部「内挂功能（开发中）」橙色标题 + 3 个复选框**超出原背景图范围突出到面板外**（用户截图确认）。
- 原因：背景图 Title[411] 高 356px，内挂区块原布局画到 y=336+72=408 出界（此前的压缩布局已无法再腾出约 110px 空间）。

## 排查过程

1. **素材实测**（PowerShell 二进制探针读 .Lib v3 结构）：Title[411]=260×356，顶部 y=0-40 为空白区可放页签；Prguse[2086/2087]=勾选框 16×13/16×12；Prguse2[450-467]=36×17 开关图。无现成第二页背景图（Title[466/467] 是聊天设置专用 224×180，尺寸不匹配）。
2. **先例精读**：ChatOptionDialog.cs（同对话框体系）的分页模式 = 页签按钮 + SwitchTab(int) 逐控件切 Visible（tab0 显示 Filters 组隐藏 Transparency 组）；MirControl.Visible getter 级联 Parent、false 时不参与鼠标路由（IsMouseOver 判 Visible），逐控件切换安全无需容器面板；MirLabel 支持 Click 事件（MirControl.OnMouseClick，InventoryDialog GoldLabel.Click 先例）。
3. **方案定稿**：文字页签（MirLabel）而非图片按钮——Title[470-475] 等 60×25 素材的选中/悬停/按下配对关系无法从尺寸推断，零素材依赖的文字页签更稳，且与 ChatOptionDialog 精神一致。

## 修复内容（仅 Client\MirScenes\Dialogs\MainDialogs.cs，服务端零改动）

1. **页签控件**：顶部空白区新增两个 MirLabel 文字页签——「基本设置」(15,10)、「内挂」(85,10)，Sound=ButtonA，Click 调 SwitchTab；当前页 ForeColour=Orange，非当前页 White。
2. **SwitchTab(int tab)** 方法：tab0（基本页）=8 组 On/Off 开关 + 2 组音量条（SoundBar/VolumeBar/MusicSoundBar/MusicVolumeBar）+ Observe/NewMove 共 22 个控件 Visible=true，内挂区块（AssistantTitleLabel + AssistantOptions[3]）Visible=false；tab1（内挂页）反之。新字段 BasicTabLabel/AssistantTabLabel/CurrentTab。
3. **内挂区块上移**：AssistantTitleLabel (10,315)→(10,60)、AssistantOptions (12,336+i*24)→(12,80+i*24)，全部初始 Visible=false；构造尾部默认调 SwitchTab(0)（打开面板即基本页，与原有布局兼容）。
4. 音量条 4 处硬编码 y（206/232）与 OptionPanel_BeforeDraw 刷 Index 逻辑均未动（本页内坐标不变）。
