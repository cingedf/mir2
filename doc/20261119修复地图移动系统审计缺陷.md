# 20261119修复地图移动系统审计缺陷

## 现象

地图/移动/传送维度深度审计回报 6 项缺陷，其中 1 项 P1 可被构造包实现远程瞬移/穿墙（绕过施法距离校验），5 项 P2 为边界配置下的空引用/越界/状态标志不同步：

1. **P1 传送技能可绕过距离校验**（HumanObject.cs）：技能入口对 `location.X/Y != 0` 的判断使客户端传 `X=0` 或 `Y=0` 的目标点时跳过 InRange 校验，配合额外两处遗漏，可实现远程瞬移/穿墙。
2. **P2 MagicTeleport 空地图**（PlayerObject.cs）：绑定地图索引无效时 `GetMap` 返回 null，直接解引用 NRE。
3. **P2 ForceLeaveGroupRequiredMap 空地图**（PlayerObject.cs）：目标地图为 null 时分支内仍解引用 `targetMap.Width` NRE。
4. **P2 SetBind 安全区列表为空**（PlayerObject.cs）：全部地图加载失败时 `Random.Next(0)` 后索引 `[0]` 越界。
5. **P2 怪物 Teleport 不刷新安全区标志**（MonsterObject.cs）：怪物换图后 `InSafeZone` 沿用旧值，导致安全区内外攻击裁决错误。

## 排查过程

1. **传送距离漏洞**：`HumanObject.cs` 传送技能入口原用 `location.X != 0 && location.Y != 0` 作为「有有效目标点」判据；客户端包 `p.Location` 由玩家提供（`MirConnection.cs:2842-2866`），当目标点 X 或 Y 为 0 时该判据为 false → 跳过 InRange 校验 → 可传送到地图任意位置。同文件 StormEscape/StormEscapeRare 两处直接 Teleport 前无独立 InRange 校验（Blink 已有先例 :7132）。实测当前 2022 地图集中 x=0 列 26 张可走、y=0 行 25 张可走，故该漏洞真实可利用。
2. **MagicTeleport**：`Map temp = Envir.GetMap(BindMapIndex)` 未判空即后续使用。
3. **ForceLeaveGroupRequiredMap**：`if (targetMap == null || !targetMap.ValidPoint(targetLocation)) targetLocation = new Point(targetMap.Width/2, targetMap.Height/2);` —— 条件包含 null 但分支内仍解引用 targetMap（SetBind 重取后地图可能已删）。
4. **SetBind**：`Envir.StartPoints[Envir.Random.Next(Envir.StartPoints.Count)]` —— Count=0 时 Random.Next(0)=0，索引空列表越界。
5. **怪物 Teleport**：玩家版 Teleport 换图后会重算 `InSafeZone = CurrentMap.GetSafeZone(CurrentLocation) != null`，怪物版漏掉该步（Spawned:387 已用同款写法）。

## 修复内容

**改 Server\MirObjects\HumanObject.cs：**
1. P1：传送技能入口 `location.X != 0 && location.Y != 0` 改为 `location != Point.Empty`（配合 `magic.Info.Range != 0 && !Functions.InRange(...)` 判距）；StormEscape、StormEscapeRare 两处 Teleport 前各补独立 `if (Functions.InRange(CurrentLocation, location, magic.Info.Range) == false) return;`（对齐 Blink 先例）。

**改 Server\MirObjects\PlayerObject.cs：**
2. P2 MagicTeleport：`GetMap` 后加 `if (temp == null) return false;`。
3. P2 ForceLeaveGroupRequiredMap：加前置 `if (targetMap == null) return;`，保留后续 ValidPoint 分支。
4. P2 SetBind：`if (Envir.StartPoints.Count == 0) return;` 前置防越界。

**改 Server\MirObjects\MonsterObject.cs：**
5. P2 怪物 Teleport：换图后补 `InSafeZone = CurrentMap.GetSafeZone(CurrentLocation) != null;`（对齐玩家版）。

**不修（记录在案）：**
- P2 换图双轨制 CompleteMapMovement（PlayerObject.cs:4849-4953）：踩传送点走独立路径，绕过 Teleport 管线的 Valor.CanEnter/OnMapChanged/MapLeave/TradeCancel/Fishing=false 等守卫；但改动面大、行为等价风险高，属设计层改造，暂不修改。
- P2 GetRandomPoint Random.Next 负数（MapObject.cs:1004-1029）：当前 2022 地图配置下不触发，低优先。

（地图路其余维度经核查无缺陷：Walk/Run 逐格校验、传送基类判空、回城卷限制、召回双方同意、安全区判定、地图加载容错、GetRandomPoint(0,0) 有 StartGame ValidPoint 兜底、Opendoor 已修。）

## 验证证据

- `dotnet build Server.MirForms\Server.csproj -c Release`：**0 警告 0 错误**；
- 行为复核：正常传送（目标点非原点、在射程内）行为不变；仅拦截 X/Y=0 绕过与超距瞬移；边界配置下不再 NRE/越界；怪物换图安全区标志正确重算；
- 待实测：玩家传送技能无法远程瞬移/穿墙；安全区内外怪物攻击裁决正确。
