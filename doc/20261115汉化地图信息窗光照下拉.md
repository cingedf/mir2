# 20261115汉化地图信息窗光照下拉

> H 汉化线收尾项（H12）：地图信息窗光照下拉（LightsComboBox）显示 LightSetting 英文枚举（Normal/Dawn/Day/Evening/Night），改显示映射为中文（json Enum 段已有 5 键映射，b1b01a3）。

## 现象

- server.exe「地图信息」窗光照下拉显示英文：Normal/Dawn/Day/Evening/Night；其他下拉（天气 lstParticles 等）已中文，光照是最后一个漏网。

## 排查过程

- 现场（Server.MirForms\Database\MapInfoForm.cs）：构造 :28 原 `LightsComboBox.Items.AddRange(Enum.GetValues(typeof(LightSetting)))` Items 填充模式（无显示映射）；消费点 5 处——多选清空（:117，相邻 MineComboBox/MusicTextBox/lstParticles 三行）、单选回显（:163 SelectedItem=mi.Light）、多选比对（:231 强转比对）、写回（LightsComboBox_SelectedIndexChanged :768 `(LightSetting)SelectedItem`，ActiveControl!=sender 保护）。
- 危险点核查：DataTable 绑定后 SelectedItem 是 DataRowView 而非枚举值，所有强转/比对点必须同步改走 SelectedValue；地图 txt 协议写盘（MapForm.cs 171-190 写枚举）与 SaveDB 链不动。
- 参照模式：ItemInfoFormNew.cs / MonsterInfoFormNew.cs 的 Enum2DataTable（Value 列保类型 + Display=ToLocalizedServerString）。

## 修复内容（Server.MirForms\Database\MapInfoForm.cs）

1. 文件头加 `using System.Data;`。
2. 构造 :28：改 `DataSource=BuildLightTable(); DisplayMember="Display"; ValueMember="Value"`（注释「20261115 汉化（H12）」）。
3. 新增 `BuildLightTable()`（Value 列 typeof(LightSetting) 保强转 + Display=setting.ToLocalizedServerString()）与 `GetSelectedLight()` 辅助（SelectedItem==null 返回 null，否则 `(LightSetting)SelectedValue`）。
4. 四处消费点同步改造：多选清空 :117 `if (GetSelectedLight() == null) ...`；单选回显 :163 `SelectedValue = mi.Light`；多选比对 :231 `if (GetSelectedLight() == null || GetSelectedLight() != mi.Light) ...`；写回 :768 `_selectedMapInfos[i].Light = (LightSetting)LightsComboBox.SelectedValue`。
- 排查插曲：编辑过程曾误删多选清空点相邻三行（MineComboBox/MusicTextBox/lstParticles 清空逻辑），已核对恢复（@917@）。
