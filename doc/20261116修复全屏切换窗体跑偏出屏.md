# 20261116修复全屏切换窗体跑偏出屏

## 现象

用户反馈：游戏内设置任意分辨率并点选全屏后，点击开始弹出的登录窗口**没铺满屏幕，跑到屏幕右下角脱离屏幕显示，屏幕左上角露出桌面**。

## 排查过程

1. 全屏拉伸改造（本日早前提交 2ee1320）后，切全屏时 `ClientSize` 从逻辑尺寸（如 1366×768）放大到物理屏尺寸（如 1920×1080），但**窗体 Location 保持原值**。
2. 窗口模式下窗体是 `CenterToScreen()` 居中的（Location 约为 (278, 54)）——切全屏后窗体以该左上角为锚点向右下长大，右侧与底部超出物理屏，左上角自然露出桌面。与用户描述逐字吻合。
3. 影响点排查：`ToggleFullScreen`（Alt+Enter / WM_SYSCOMMAND）、`SetResolution`（进游戏切分辨率）、`CMain_Load`（全屏启动）三处都会把窗体切到全屏尺寸，均未重置 Location。

## 修复内容

`Client\Forms\CMain.cs` 三处，全屏态一律把窗体 Location 归零：

1. `ToggleFullScreen`：ClientSize 切换后加 `if (Settings.FullScreen) Program.Form.Location = new Point(0, 0);`；
2. `SetResolution`：同样加 Location 归零（全屏分支）；
3. `CMain_Load`：全屏启动时 `StartPosition = FormStartPosition.Manual; Location = new Point(0, 0);`（防止系统默认启动位置干扰）。

窗口模式路径未动（已有 CenterToScreen 居中）。全屏拉伸机制本身（D3D 恒窗口化+后缓冲拉伸）不变。

## 验证证据

- `dotnet build Client\Client.csproj -c Release`：0 错误（1 存量 MSB3277 警告）；
- 逻辑复核：三处全屏入口均 Location=(0,0)，窗体严格铺满物理屏左上角对齐；
- 待用户实测：任意分辨率+全屏，登录窗与游戏画面应铺满整屏、无右下角跑偏、无桌面露出。
