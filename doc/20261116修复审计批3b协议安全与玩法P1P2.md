# 20261116修复审计批3b协议安全与玩法P1P2

## 现象

四路深度审计（协议与安全 + 玩法系统路线）回报的 P1/P2 网络面与经济面缺陷，均可被伪造协议包触发：撞库锁号、无限重掷刷幸运、隔空开全图门、宠物隔空拾取、超大 count 反序列化 OOM 等。

## 排查过程（关键现场）

1. **登录撞库**：Envir.Login 错密 5 次封的是**账号**（WrongPasswordCount 在 account 上）→ 攻击者 5 包锁任意账号 2 分钟；换账号可无限试（IP 无记录）。
2. **GetStuntlucky 无冷却**：MirConnection 包处理直接调，无消耗 → 客户端无限重掷直到摇出奇数=必得幸运模式（下次抽奖 chance 减半）。
3. **Opendoor 无距离**：PlayerObject.Opendoor 直接 CurrentMap.OpenDoor(Doorindex)，Map.OpenDoor 仅按 index 开门 → 任意 doorIndex 远程开全图门。
4. **灵宠拾取无坐标校验**：IntelligentCreaturePickup 包的 Location 直读任意值 → pet.ManualPickup(mousemode, atLocation) → FillTargetList 以该点为中心环形扫描 → 隔空拾取（归属检查有但位置无限制）。
5. **反序列化先分配后读**：全仓 `ReadBytes(reader.ReadInt32())` 网络面 4 处（VersionHash/ReportIssue.Image）+ count 循环 3 处（Craft.Slots `new int[ReadInt32()]`/EditGuildNotice.LineCount/Chat.LinkedItems）→ 恶意 count=20 亿 OOM/循环膨胀。AccountInfo.cs Salt 两处为本地存档非攻击面。
6. **ChangePMode 无枚举域校验**：`ChangePMode.Mode` 实为 PetMode（ClientPackets.cs:776 `(PetMode)reader.ReadByte()`），恶意值越域注入非法状态。
7. **CollectMail 金币截断**：`gold = uint.MaxValue - Account.Gold` 静默截断（寄件方已全额扣款=金币蒸发）；且物品领取在前，若在金币处 return 会重复领物品。
8. **NPC Buy 污染共享模板**：NPCScript.Craft 邻近的 Buy 路径 `else goods.Count = count` 直接改写 NPC 共享 Goods 模板 → 多玩家堆叠数显示污染。
9. **TestServer 跳 GM 校验**：34 处 `if (!IsGM && !Settings.TestServer)` ——系测试模式设计意图，生产 deploy 已 TestServer=False，**不改码**（doc 记录：勿在生产开启）。
10. **PBKDF2 迭代 50 过弱**：升级迭代数会使全部账号密码失效（存档只存 hash+salt），需停机迁移，**暂不改码**（doc 记录）。

## 修复内容

**P1 五项（改码）：**
1. **登录 IP 拉黑**（Envir.cs 错密分支）：错密 5 次封账号同时 `UpdateIPBlock(c.IPAddress, TimeSpan.FromSeconds(Settings.IPBlockSeconds))`（默认 5s，ini [Network] 可调）——防换号撞库。
2. **反序列化 count 钳制**（Shared\ClientPackets.cs 5 处，钳制为 0 比 throw 安全不断线）：VersionHash>64→0、Chat.LinkedItems>10→0、Craft.Slots>256→0、EditGuildNotice.LineCount>200→0、ReportIssue.Image>131072→0。
3. **Stuntlucky 冷却**（PlayerObject.cs）：`NextStuntluckyTime` 字段+入口 `Envir.Time < NextStuntluckyTime` return（60s 冷却）。
4. **灵宠拾取范围**（IntelligentCreatureObject.cs ManualPickup）：MousePickup 分支包 `Functions.InRange(atLocation, CurrentLocation, CreatureRules.SemiAutoPickupRange)`——只能捡宠物身边的。
5. **Opendoor 距离**（Map.cs 新增 GetDoor + PlayerObject.Opendoor）：door==null return + `Functions.InRange(door.Location, CurrentLocation, Globals.DataRange)`（16 格视野）。

**P2 七项（改码）：**
6. ChangePMode 枚举域：`Enum.IsDefined(typeof(PetMode), p.Mode)`（对齐 ChangeAMode 先例）。
7. NPCConfirmInput 截断 100 字符（MirConnection.cs:3568）。
8. ChatItemRegexCache 上限：>200 清空（PlayerObject.cs，缓存键=玩家可控 Title 防膨胀）。
9. DropGold 0 堆（MonsterObject.cs:1311）：`count = gold/Max + (gold%Max==0 ? 0u : 1u)`，末堆金额=整倍数时 Max 而非 0。
10. SpellObject 三处防御：Process cell 判空前置+Objects.ToArray() 快照遍历；Caster 非 HumanObject 直接 Despawn；ProcessSpell 入口 `Caster as HumanObject` 判空（治疗/地图法术豁免）替代六处硬强转；Reincarnation Caster==null 消散防 NRE。
11. NPC Buy 不回写共享模板：`purchaseCount` 局部变量，`item.Count = (isBuyBack||isUsed) ? goods.Count : (ushort)purchaseCount`。
12. CollectMail 溢出前置：金币超携带上限时 ReceiveChat 提示并整单拒绝（在任何物品/金币变更前），不再静默截断。

**不改码（记录在案）：** TestServer 语义保留（生产勿开）；PBKDF2 迭代升级需停机迁移（后续运维窗口处理）。

## 验证证据

- `dotnet build Server.MirForms\Server.csproj -c Release`：**0 警告 0 错误**（修复 PKMode→PetMode、int→ushort 两处编译错后）；
- 行为复核：合法登录/抽奖/开门/宠物拾取/购买/收邮件路径不变；所有钳制只影响越界恶意输入；
- 待实测：正常游戏全流程无回归；错密 5 次 IP 被短暂拉黑；同图门外 16 格外无法开门。
