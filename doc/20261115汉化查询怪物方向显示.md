# 20261115汉化查询怪物方向显示

> H 汉化线第 9 项（H13，收官项）：GM 命令 `@查询怪物` 的返回信息中朝向字段显示英文枚举名（Up/DownRight 等），改为中文方位。

## 现象

- `@查询怪物` 返回第三行「等级/坐标/朝向」，朝向显示英文（Up、DownRight、UpLeft 等），玩家不可读。

## 排查过程

- 现场：PlayerObject.cs `@查询怪物` 分支 :4049 `GetLocalization(ServerTextKeys.MonsterInfo2, monOb.Level, X, Y, monOb.Direction)`——MirDirection 枚举（Shared\Enums.cs:959-969，Up=0..UpLeft=7）直接进 string.Format 输出 ToString()。
- 本地化基础设施评估：MirDirection 不在 localizationEnumTypes 内且方向词属通用词汇，8 成员一次性 switch 更直观，不扩 json（避免为 8 个词加载段）；客户端无需改动（纯服务端文本）。

## 修复内容（Server\MirObjects\PlayerObject.cs :4048-4058）

- 新增 switch 表达式：Up=上 / UpRight=右上 / Right=右 / DownRight=右下 / Down=下 / DownLeft=左下 / Left=左 / UpLeft=左上，default 回退 ToString；MonsterInfo2 的第 4 参由 `monOb.Direction` 改为 `dirText`。
- 注释「20261115 汉化（H13）」；等级/坐标格式串（MonsterInfo2 本地化文案）零改动。

## 验证证据

- `dotnet build Server\Server.Library.csproj -c Release`：**0 警告 0 错误**（6.83s）。
- 上线验证：GM 聊天框 `@查询怪物 <怪物名>` → 第三行朝向显示中文方位。
