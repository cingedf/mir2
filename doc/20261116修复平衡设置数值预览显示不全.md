# 20261116修复平衡设置数值预览显示不全

## 现象

平衡设置窗：切到职业页（tab1）右侧数值预览只能显示到 49 级，英雄页（tab2）只能显示到 47 级，最后一两行被窗体底边截断；英雄页比职业页更靠下（更低）。

## 排查过程

1. 预览 Label 是**窗体级控件**（不在 tabPage 内，悬在 tabControl 右侧空白条）：`lblClassStatExample` Location=(836,41)、`lblHeroStatExample` Location=(838,77)，AutoSize=true；窗体 ClientSize=(981,962)。
2. 预览内容 52 行（标题+空行+Level 1..50），AutoSize Label 默认字体行高 18px/行。
3. 反推与用户观察完全吻合：职业页 41+52×18=977 > 962 → 底部截断，显示到 49 级；英雄页 77+52×18=1013 > 962 → 截断更多，显示到 47 级。
4. 两侧 panel（Dock.Right 233 宽）右缘到 820，Label x=836/838 位于空白条上，x 无需动。

## 修复内容

`Server.MirForms\BalanceConfigForm.Designer.cs` 两处坐标（含 20261116 注释）：

- `lblClassStatExample`：y 41 → 8
- `lblHeroStatExample`：y 77 → 8

y=8 时 8+52×18=944 < 962，52 行完整显示。两 Label 分属职业/英雄两页互斥显示（`tabControl1_SelectedIndexChanged` 控制可见性），不同屏冲突，可共用同一 y。

## 验证证据

- `dotnet build Server.MirForms\Server.csproj -c Release`：0 警告 0 错误。
- 数学复核：y=8 + 936px 内容高度 = 944 < ClientSize 高 962，含描边余量完整显示。
- 观察吻合性复核：旧 y=41/77 反推截断位置（49 级/47 级）与用户反馈逐字一致，确认根因唯一。
