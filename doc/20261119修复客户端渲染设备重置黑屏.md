# 20261119修复客户端渲染设备重置黑屏

## 现象

客户端渲染与资源释放深度审计回报 2 项真实缺陷：

1. **P1 设备重置失败后永久黑屏**：Direct3D 设备丢失后重置失败，设备恢复后 Sprite/Line 未重建，下一帧 `Sprite.Begin()` 抛 NullReferenceException，渲染循环反复进入 catch，画面永久黑屏。
2. **P2 OutputLines 释放条件写反**：`if (OutputLines[i] != null && OutputLines[i].IsDisposed) Dispose()` 条件反转，存活的输出行控件永不释放（MirControl.Dispose 幂等，对已释放控件调用会直接 return）。

## 排查过程

1. **P1 设备重置黑屏**：
   - `CMain.RenderEnvironment`（CMain.cs:431-460）：`if (DXManager.DeviceLost) { AttemptReset(); Sleep(1); return; }`，否则 `:440 DXManager.Sprite.Begin(...)`。
   - `DXManager.ResetDevice`（DXManager.cs:291-318）：`:293 CleanUp()` 销毁 Sprite/Line 置 null → `:310 Device.Reset` 抛 Direct3D9Exception → `:312-315 catch return` **跳过 `:317 LoadTextures()`** → Sprite 保持 null、DeviceLost=true。
   - `DXManager.AttemptReset`（:268-288）：设备恢复后 `TestCooperativeLevel()` 返回 Success 时，`:284 DeviceLost=false` 后**未重建 Sprite**（DeviceNotReset 分支会调 ResetDevice 间接重建，但 Success 分支不经过）。
   - 结果：设备恢复走 Success 分支时 DeviceLost 被清 false，RenderEnvironment 下一帧直接进 `:440 Sprite.Begin()`，Sprite==null → NRE（非 Direct3D9Exception）→ `:455 catch` → AttemptRecovery 只恢复 MainSurface 不重建 Sprite → 循环黑屏。
   - `LoadTextures`（:129-159）：`:131 Sprite = new Sprite(Device)`、`:132 Line = new Line(Device)` 确认可重建。
2. **P2 OutputLines**：GameScene.Dispose（:10965-10967）条件 `IsDisposed` 才 Dispose，与"释放存活控件"意图相反；MirControl.Dispose 对 IsDisposed=true 直接 return（幂等），故该循环实际从不清任何控件。

## 修复内容

1. **P1**（Client\MirGraphics\DXManager.cs AttemptReset :284）：`DeviceLost=false` 后补
   ```csharp
   if (DXManager.Sprite == null || DXManager.Line == null)
       DXManager.LoadTextures();
   ```
   设备恢复后立即重建缺失的 Sprite/Line，避免下一帧 Sprite.Begin() NRE 永久黑屏。LoadTextures 重建 Sprite/Line + 回后缓冲 + 灯光，行为与正常建设备一致。
2. **P2**（Client\MirScenes\GameScene.cs :10966）：`OutputLines[i].IsDisposed` → `!OutputLines[i].IsDisposed`，真正释放存活的输出行控件（即使 base.Dispose 递归释放也无害，幂等）。

**不修（登记利弊）：** CMain_Deactivate 未重置 GameScene.CanRun 与控件 Moving——属输入状态机维度而非渲染，改动涉及 GameScene/MirControl 多处状态机，与本批渲染资源释放无关，单独登记。

## 验证证据

- `dotnet build Client\Client.csproj -c Release -p:ApplicationIcon=`：**0 错误**（1 存量警告；-p:ApplicationIcon= 规避并行会话持有的损坏 MIR2.ICO）；
- 行为复核：正常设备创建/重置路径不受影响（Sprite != null 时不调 LoadTextures）；仅设备恢复后 Sprite 缺失才重建；
- 待实测：切换分辨率/全屏导致设备重置后不再黑屏。
