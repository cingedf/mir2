# 20261115实装移除仓库密码客户端入口

> 死接线审计仅记录项（5483fd4 台账第 2 条）正式接线：`C.RemoveStoragePassword` 服务端处理完整但客户端零发送，玩家无法通过 UI 移除仓库密码。本 commit 补齐客户端发送入口，形成完整闭环。

## 现象

- 玩家设置仓库密码后只能「改密码」或「解锁」，无「移除密码」入口；服务端 `RemoveStoragePassword` 处理（MirConnection.cs:1976-2053：需仓库 NPC 旁 + 原密码校验 + Result 0/1/2/4/5）完整实现却永远收不到包。

## 排查过程

- 取证确认服务端回包消费链完备：GameScene.cs 分发 → NPCDialogs.cs:3063 `HandleStoragePasswordResult`——**Result 4 + Removing=true 分支已存在**（:3088-3098：置 `StoragePasswordRemoveSuccess` 提示、复位 `_pendingOpenAfterPasswordSet/_forcingPasswordSetup`、`_storageUnlocked=false`、`Hide()`），客户端只缺发送侧。
- `MirMessageBoxButtons` 枚举原生支持 `YesNoCancel`（MirMessageBox.cs:5）；该模式下创建 YesButton(160,157)/NoButton(260,157)/CancelButton(360,157) 三键，**OKButton 为 null**（:98-122）——挂 OKButton 会 NullReferenceException（实施中第一版曾踩，已修正挂 NoButton）。
- 文案键全部已预置：`StoragePasswordManagePrompt`（更改或移除存储密码？）、`StoragePasswordRemovePrompt`、`StoragePasswordRemoveSuccess`（存储密码已移除。）在 Shared\Language.cs:2703/2714/2706 与客户端 Chinese.json 均有中文译文（客户端 Text 1094 键实测齐全）。
- 现有输入流程复用：`PromptStoragePassword(prompt, onSubmit, onCancel)`（NPCDialogs.cs:3242 起）带密码遮蔽输入框+长度规则提示（MinPasswordLength/MaxPasswordLength），与解锁/改密码同款交互。

## 修复内容（`Client\MirScenes\Dialogs\NPCDialogs.cs` 一处）

1. `ManageStoragePassword()` 确认框 `OKCancel` → `YesNoCancel`：
   - **Yes** = `BeginRemoveStoragePassword()`（移除密码）；
   - **No** = `BeginChangeStoragePassword()`（改密码，原 OK 行为不变）；
   - **Cancel** = 关闭（默认 Dispose）。
2. 新增 `BeginRemoveStoragePassword()`：`PromptStoragePassword(StoragePasswordCurrentPrompt)` 输入旧密码 → 非空校验 → `Network.Enqueue(new C.RemoveStoragePassword { CurrentPassword = currentPassword })`。
3. 交互语义：Yes=是（移除）/No=否但继续改密码/Cancel=取消——移除成功后由服务端回包驱动 `StoragePasswordRemoveSuccess` 提示并关仓库窗。
