# 20261119修复社交权限校验

## 现象

第五轮新维度审计（社交系统权限校验路线）回报 4 项 P2 缺陷，均可被伪造协议包或异常时序触发越权/错乱：

1. **物品租赁单方强制成交**（PlayerObject.cs ConfirmItemRental）：成交校验用 `&&`，任一方未锁定也能完成交易，单方篡改客户端即可强制成交。
2. **结婚/离婚接受端缺现场复核**（MarriageReply/DivorceReply）：发起端校验了面对面/同图/距离，接受端没有——求婚后对方跑远、换图甚至下线，仍可远程确认。
3. **行会 rank 改名越权**（GuildObject.cs ChangeRankName）：`SelfRankIndex > RankIndex` 判定宽松，未找到自身 rank（=-1）时可改任意 rank 名（含会长 rank0）；相等时还能改自身 rank 名。
4. **交易物品显示滞后**（PlayerObject.cs TradeItem）：`S.TradeItem { TradeItems = Info.Trade }` 直接把数组引用入队，包延迟序列化时数组已被后续增删物品改写，对方看到错乱的交易栏。

## 排查过程

- **缺陷1**：读 ItemRentalLockFee(:14890)/LockItem(:14911) 确认成交条件是"本方锁物品 + 对方锁租金"（:14924 `ItemRentalItemLocked && ItemRentalPartner.ItemRentalFeeLocked` → 下发 `CanConfirmItemRental`）；而 ConfirmItemRental :14986 却写 `!本方ItemLocked && !对方FeeLocked` 才拒绝——`&&` 使得"本方未锁但对方锁了"也放行，与下发条件矛盾。成交后 :15031 `ItemRentalPartner.GainItem(item)` + :15035 `GainGold(费用)` 真实转移资产，故属经济风险。
- **缺陷2**：读 MarriageRequest(:13750-13783) 确认发起端有距离/同图(:13770)校验且要求面对面(:13785)，DivorceRequest(:13852-13922) 同样有 FacingEachOther(:13885)+距离(:13909)；而两个 Reply 的 accept 分支只校验 null/已婚状态/冷却，无任何在线/位置复核。`Functions.InRange(point,point,range)` 与 `Globals.DataRange` 均为既有先例（同文件多处）。`Node == null` 为对象下线判定（MapObject.Despawn 置 null）。
- **缺陷3**：读 ChangeRank(:264) 见会长豁免语义 `(MemberRank.Index >= self.MyGuildRank.Index) && (self.MyGuildRank.Index != 0)`，ChangeRankOption(:361) 用 `Self.MyGuildRank.Index >= RankIndex`；ChangeRankName(:383-394) 用遍历求 SelfRankIndex，若未找到保持 -1，而 `-1 > RankIndex` 恒 false → 越权放行。
- **缺陷4**：TradeItem(:11270-11286) 先 TradeUnlock + CheckItem 再入队，但 `Info.Trade` 数组引用直接进包对象；Enqueue 后到实际网络序列化间若有其它 Trade 变更（增删物品会改写同一数组），对方收到的是被改写后的内容。

## 修复内容

1. **ConfirmItemRental**（PlayerObject.cs :14986）：`&&` → `||`，即 `if (!ItemRentalItemLocked || !ItemRentalPartner.ItemRentalFeeLocked) return;`——双方都必须锁定才成交，对齐 ItemRentalLockItem 的成对语义。
2. **MarriageReply**（:13806 后）/ **DivorceReply**（:13939 后）：accept 分支补 `if (Proposal.Node == null || Proposal.CurrentMap != CurrentMap || !Functions.InRange(Proposal.CurrentLocation, CurrentLocation, Globals.DataRange)) { ReceiveChat(中文提示); Proposal = null; return; }`（中文提示文案，符合项目汉化规范）。
3. **ChangeRankName**（GuildObject.cs :396）：改为 `if (SelfRankIndex < 0 || (SelfRankIndex >= RankIndex && SelfRankIndex != 0))`——未找到自身拒绝；非会长仅可改比自己低的 rank；保留会长（index 0）改名任意 rank（含 rank0）的能力，对齐 ChangeRank 的会长豁免。
4. **TradeItem**（PlayerObject.cs :11285）：`TradeItems = (UserItem[])Info.Trade.Clone()`——入队时克隆数组快照（浅拷贝，元素引用共享），成交校验仍走实时数组，行为等价。
