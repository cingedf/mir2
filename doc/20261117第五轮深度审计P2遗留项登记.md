## 现象

第五轮开辟了前四轮未覆盖的五个新维度（存档/数据库层、网络底层、NPC 脚本引擎+配置加载、社交系统、客户端非渲染）进行深度审计。五个维度的 **P0/P1 缺陷已全部修复闭环**（见下方闭环清单），剩余 **P2 项统一登记在案，本批不改码**。

P2 项共同特征：低概率竞态、纯性能 churn、需停机迁移、或改动会改变既有行为语义，修复收益与引入回归的风险不成比例，故按项目规则暂缓并记录触发条件。

## 修复内容（本批）

本批**不修改任何代码**，仅登记 P2 遗留项。以下为完整清单及决策：

### 网络底层 P2（6 项，暂缓）
1. **心跳保活失效**：`_keepAlivePending` 标志置位后不再发新心跳且永不复位；任意收包刷新 TimeOutTime 与心跳解耦。触发条件：需改造心跳状态机，涉及断线判定语义，暂缓。
2. **IPBlocks 字典只增不减**：`Envir.IPBlocks`/`ConnectionLogs` 仅手动 Clear，长期运行内存增长。触发条件：加 WorkLoop 5 分钟周期清理 banDate<Now 项（低风险，可在后续运维窗口顺带做）。
3. **状态端口满员 while 未查 Running**：`Envir.cs:2343` 关服线程滞留。触发条件：改 `while(Running && ...)`（一行改动，下次顺带）。
4. **SendDisconnect 绕过发送队列计数**：`MirConnection.cs:1653` 直 `_sendList.Enqueue` 未计数/查上限。触发条件：纳入统一队列计数。
5. **跨线程统计字段 long 无锁**：`_receiveCount` 等写读无 volatile/Interlocked；`_sendQueueCount` 增减双锁偏差。触发条件：仅作健康统计，不影响玩法，暂缓。
6. **观察者扇出递归无环检测**：管理员令 A 观察 B/B 观察 A 时栈溢出崩进程（普通玩家不可用）。触发条件：加 HashSet 去重+AddObserver 拒绝反向观察（低优先级，管理员操作场景）。

### 客户端 P2（8 项，暂缓）
1. **Tab 双绑定**：`KeyBindSettings.cs` Tab 同时绑 Pickup 与 DropView，`GameScene.cs` foreach 无 break→按一次双触发。
2. **设置写错参数**：`Client/Settings.cs:375` `Reader.Write("Game","ExpandedHeroBuffWindow", ExpandedBuffWindow)` 参数应为 `ExpandedHeroBuffWindow` 变量本身→设置无法持久化。
3. **IniReader Split('=') 截断**：`Shared/Functions/IniReader.cs` 按所有 `=` 拆只取 parts[1]→值含 `=`（密码/URL）被截断。触发条件：改 `Split(new[]{'='},2)`（低风险，下次顺带）。
4. **补丁器 try+Sleep 忙等**：`Program.cs` MainModule.FileName 无局部 try+3 秒忙等无 Sleep→静默失败/CPU 占用。
5. **LoginScene 版本异常不提示**：`SendVersion` 异常只记日志不提示不重试+`ClientVersion` switch 无 default→登录卡在 Sending client version。
6. **多 handler 解引用缺判空**：`LoginScene.cs`/`SelectScene.cs`/`GameScene.cs` 多处 User/对话框在包赋值前解引用。
7. **Network.Process 逐包无 try**：`Network.cs:1100` 单包异常中断整帧。
8. **补丁并发 P_Concurrency 无效**：`AMain.cs` 串行 DownloadFile+task.Result 递归清空队列。

### NPC 脚本引擎 P2（8 项，暂缓）
