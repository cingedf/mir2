# 20261115汉化商城窗职业下拉

> 用户十问第 6 问：游戏商城窗编辑区「职业」下拉显示英文（All/Warrior/Assassin/Taoist/Wizard/Archer）。改 DataSource 表绑定：显示中文、存盘英文原值，数据链零回归。

## 现象

- server.exe「游戏商城」窗选中物品后，编辑区「职业」下拉显示英文职业名（Warrior 等）；选中职业写回 GameShopInfo.Class（string 存盘）。

## 排查过程

- **根因**：`GameShop.designer.cs:356` 硬编码 `Items.AddRange(new object[] { "All", "Warrior", "Assassin", "Taoist", "Wizard", "Archer" })`——不走枚举不走本地化（MirClass 枚举本身已是中文，但此下拉用不上）。
- **数据链约束**（关键）：`GameShopInfo.Class` 是 string 字段存盘（GameShop.cs 默认 "None"），四处按字符串消费——写回（Class_combo_SelectedIndexChanged 把文本写回 item.Class）、筛选（UpdateGameShopList 按 `item.Class == ClassFilter_lb.Text`）、回显（SelectedItems[0].Class → Text）、序列化（SaveGameShop）。**直接把数组改中文会断链**（选中「战士」存盘成中文串，与既有英文数据失配）。
- **修法拍板**：DataSource 表绑定（Value 列=英文原值保数据链 + Display 列=中文显示），写回改 SelectedValue——显示/存盘分离，与既有英文数据完全兼容。

## 修复内容

1. **`Server.MirForms\Database\GameShop.designer.cs`**（Class_combo 配置段）：硬编码 Items.AddRange → DataSource 表绑定（Value/Display 两列：All=全部/Warrior=战士/Assassin=刺客/Taoist=道士/Wizard=法师/Archer=弓箭手）+ DisplayMember/ValueMember（注释「20261115 汉化（十问⑥）」）。
2. **`Server.MirForms\Database\GameShop.cs`** 三处：
   - 写回 Class_combo_SelectedIndexChanged：`ActiveControl.Text` → `Class_combo.SelectedValue as string`（存盘英文原值）。
   - 清空态 :97：`Class_combo.Text = "全部"` → `Class_combo.SelectedValue = "All"`。
   - 回显 :121：`Class_combo.Text = SelectedItems[0].Class` → `SelectedValue = SelectedItems[0].Class`，**未命中时回退 SelectedIndex=0（"全部"）**——兼容既有存盘值 None 等不在六项内的串（只影响显示，不误写回：写回仅由用户改选触发）。

## 验证证据

- `dotnet build Server.MirForms\Server.csproj -c Release`：**0 警告 0 错误**（14.61s）。
- 数据链复核：写盘值仍是英文（SelectedValue）；筛选链（ClassFilter_lb 动态收集 item.Class）不受本改动影响；回显对旧数据（None）回退"全部"显示，改选后才写新值。
- 上线验证：商城窗职业下拉显示 全部/战士/刺客/道士/法师/弓箭手；选中物品职业正确回显；改选职业后保存，GameShopList 存盘值仍为英文。
