# 20261116 删除SMain四个死代码菜单事件

## 现象

用户问：`SMain` 里 4 个 `_Click_1` 函数（itemInfo/monsterInfo/nPCInfo/questInfo `ToolStripMenuItem_Click_1`）是什么意图、后期有没有用。

## 排查过程

1. 定位：`Server.MirForms\SMain.cs:282/289/296/303` 四个方法，内容都是 `new XxxInfoForm().ShowDialog()`，与不带 `_1` 的同名版本（:246-280 一带）**功能完全相同**。
2. 挂线核查：`SMain.Designer.cs` 中 Designer 实际挂线的是**不带 `_1`** 的版本（:629/637/658/665 `new EventHandler` 指向 `xxxToolStripMenuItem_Click`）；全仓 grep `_Click_1` 零引用——四个方法**永远不会被调用**。
3. 结论：属 VS 设计器历史残留（早期手动挂线后改名/重新生成事件导致旧方法遗留在 .cs 中）。后期无用。

## 修复内容

删除 `Server.MirForms\SMain.cs` 中四个死方法：
- `itemInfoToolStripMenuItem_Click_1`
- `monsterInfoToolStripMenuItem_Click_1`
- `nPCInfoToolStripMenuItem_Click_1`
- `questInfoToolStripMenuItem_Click_1`

不动 Designer（其挂线本就不指向它们）。

## 验证证据

- `dotnet build Server.MirForms\Server.csproj -c Release`：**0 警告 0 错误**；
- 删除后 `SMain.Designer.cs` 中 `Click_1` 零匹配（挂线无悬空）。
