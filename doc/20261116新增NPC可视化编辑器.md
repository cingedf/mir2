# 20261116 新增 NPC 可视化编辑器

## 现象 / 需求

经静态逆向原版 `NPC可视化编辑器.exe`（UPX 壳 Delphi 7 程序，2015 年，纯离线传奇 NPC 编辑工具），需复刻一个功能一致的编辑器，对接 Crystal（C#/.NET 8）血统 Mir2 部署区。原版注册机制（CPUID 硬件码 + reg.dat 明文注册码）不实现；UI 全中文。

## 排查过程（设计依据）

1. 逆向原版脱壳文件，提取 17/17 个 TPF0 窗体布局（产物 `forms_dump.txt` 等）：启动器 + 主编辑器（世界/生态环境/关于三页）+ NPC 属性 + 对话编辑 + 保存确认等。
2. 核查 Crystal 部署区数据源：经典 Mir200 文本文件均不存在，全部数据在二进制 `Server.MirDB`；NPC 脚本在 `Envir\NPCs\` 下 UTF-8 无 BOM 文本；商人 = 脚本含 `[TRADE]`。
3. 核查引擎源码：`Envir.Main/Edit` 双实例、`Envir.LoadDB/SaveDB` 全块序列、`NPCInfo/MapInfo/SafeZoneInfo` 布局、`Settings.*` 相对工作目录路径体系、`NPCScript.LoadInfo` 以 `FileName + ".txt"` 定位脚本、`Previews\NPC\{Image}.bmp` 预览命名。

## 实现内容

新建 `tools\NpcVisualEditor\`（net8.0-windows7.0 WinForms，ProjectReference `Server\Server.Library.csproj`）：

- `Program.cs`：入口 + `--smoke <服务端目录>` 无头自检（带缺库保护，避免引擎缺库自动生成空库）。
- `LauncherForm.cs`：启动器（服务端/客户端目录、历史记录、加载 MirDB）。
- `MainForm.cs`：三页签主界面——世界（地图列表/GO、画布、商人/固定 NPC、安全区）、生态环境（物品/怪物检索）、关于；新建/编辑/删除 NPC、命令说明、Ctrl+S 保存。
- `MapCanvas.cs`：GDI+ 画布（小地图底图 + NPC 标记 + 安全区绘制，拖动改坐标、双击编辑、右键菜单）。
- `NpcEditForm.cs`：NPC 属性（脚本名/显示名/地图/X/Y/外观+预览/间隔/大地图/传送）+ 脚本编辑入口。
- `ConversationForm.cs`：脚本编辑（UTF-8 无 BOM 保存，符合引擎约定）。
- `SaveForm.cs`：保存确认（可选备份；引擎 SaveDB 自身另有备份机制）。

数据层完全复用引擎原生序列化（`Envir.Edit.LoadDB/SaveDB`），保证 MirDB 字节级兼容；工作目录切换到所选服务端目录后使用引擎全部相对路径常量。

## 扩展：全维度可视化编辑套件（同日追加）

用户目标升级为“全力打造多维度可视化编辑工具”，以本编辑器为基座分三批扩展，每批 `dotnet build` 均 0 警告 0 错误：

### P0 空间可视化（刷怪点 / 安全区 / 传送门）
- `MapCanvas.cs` 新增 `CanvasMode{Select,Npc,Respawn,SafeZone,Movement}` 工具模式栏；绘制青色传送连线、绿色安全区、红色菱形刷怪点（含怪物名×数量）、橙色 NPC。
- 框选生成 `RespawnInfo`（中心/范围）、`SafeZoneInfo`；两次点击生成 `MovementInfo`；右键编辑/删除各类对象。
- `SpatialObjectEditForms.cs`：`RespawnEditForm` / `SafeZoneEditForm` / `MovementEditForm`；对象挂 `_currentMap.*` 列表，走原子保存。

### P1 工具中心 + 坐标校准
- `ToolHubForm.cs`：复用入口中心，列出 10 个现成工具（客户端/源码地图编辑器、LibraryEditor、DropEditor、Server.exe 内置编辑器、GameShopMigrate、各 Seed/Fix 工具），一键启动。避免重复造车。
- `MinimapCatalog.cs`：读 `Client\Map\MiniMaps_Export\对照表.csv`（地图文件名,宽度,高度,小地图文件）。地图内对象坐标是**格坐标**（0~700），小地图 PNG 像素非等比（如 0.map 逻辑 700x700 但 PNG 1050x700），`MapCanvas` 改用逻辑宽高归一化（`_scaleX/_scaleY` 取代单一 `_scale`）。

### P2 创作层（自研补缺）
- `DialogueFlowForm.cs`：NPC 对话流程图。正则解析 `<文字/@段名>` 与 `<<文字/@段名/颜色>>` 跳转，GDI+ 贝塞尔连线，节点拖动/新建/删除/自动布局/保存脚本。已接入 `ConversationForm` 底部“对话流程图”按钮。
- `TemplateForm.cs`：8 个玩法模板（物品兑换/传送 NPC/答题/签到/BOSS 召唤/装备升级/增益 BUFF/等级奖励），参数面板 + 脚本预览 + 保存。
- `CreatorTools.cs`：`CommandWizardForm`（解析 `NPC命令说明.txt` 分类树 + 过滤 + 复制）、`EffectBuffForm`（SetBuffs.txt 可视化增删改 + 生成 GIVEBUFF 脚本）、`QuestFlowForm`（QuestInfo 按 RequiredQuest 串链）。
- `ImagePickerForm.cs`：图库 ID 选择器，扫描 `Previews\{NPC|Monsters|Items|Minimaps}\*.bmp`（实测 312/617/2863/473 张），缩略图网格 + ID 过滤 + 双击返回。已挂到 `NpcEditForm` 外观字段。
- `ItemMonsterBrowser.cs`：物品/怪物可视化图鉴（列表 + PropertyGrid 属性 + 外观图联动），接入生态环境页与创作菜单。
