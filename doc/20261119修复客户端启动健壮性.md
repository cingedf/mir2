# 20261119修复客户端启动健壮性

## 现象

新一轮「未触碰维度」深度审计（客户端非渲染系统路线）回报的启动期/网络交互期健壮性缺陷，可导致补丁器栈溢出、后台线程未处理异常杀进程、损坏资源致黑屏、重复登录/发包状态错乱：

1. **P1-1 补丁器无界递归栈溢出**：补丁下载靠 BeginDownload↔DownloadFile 相互递归推进，递归深度=待下载文件数（数百~数千）→栈溢出；且 `task.Result` 同步阻塞使 P_Concurrency 并发配置从未生效。
2. **P1-2 资源库损坏后台线程崩进程**：资源库后台加载线程无顶层 try/catch，任一 .Lib 损坏/异常计数致 OOM→未处理异常终止进程（.NET 任意线程未处理异常杀进程）。
3. **P1-3 损坏鼠标指针致黑屏**：鼠标指针加载与 D3D/Sound 初始化在同一 try，损坏的 .cur 抛异常→中断 D3D/Sound 初始化→黑屏全渲染失效。
4. **P2-1 重复 LoginSuccess 重入**：Enabled=false 不阻止收包，每个 LoginSuccess 注册一个切场景回调→多 SelectScene/重复 Dispose。
5. **P2-2 多入口重复发 StartGame**：开始游戏按钮/角色双击/回车/AfterDraw 四个入口可重复触发 StartGame。
6. **P2-3 CleanUp GetFiles 未保护**：补丁清理的 Directory.GetFiles 在逐文件 try 之外，后台线程无顶层 catch→进程崩。
7. **P2-5 无数字文件名 .Lib 致黑屏**：资源库目录扫描用 int.Parse 解析文件名数字，无数字文件名→FormatException→静态构造失败→ActiveScene null 黑屏。

## 排查过程

- P1-1：AMain.cs :84 启动 P_Concurrency 个 BeginDownload，BeginDownload(:104-118) 调 DownloadFile，DownloadFile 尾部(:338)又调 BeginDownload→递归链；:248/:251 用 task.Result 同步等待。
- P1-2：MLibrary.cs :205 `new Thread(LoadGameLibraries){IsBackground=true}.Start()` 无 try；LoadGameLibraries(:258-522) 写死数百 X.Initialize()+Progress++，末尾 :521 Loaded=true 为进场门槛；Initialize(:600-604) `catch{_initialized=false;throw;}` 异常冒泡到线程顶层无 catch。
- P1-3：CMain.cs CMain_Load try :98 LoadMouseCursors+SetMouseCursor 与 :103 DXManager.Create()/:104 SoundManager.Create() 同一 try（catch :108 只 SaveError）；LoadMouseCursors(:807-840) 逐文件无 try，LoadCustomCursor(:842-851) :845 hCurs==0 抛 Win32Exception。
- P2-1：LoginScene.cs :329 Login(S.LoginSuccess)，:331 Enabled=false 不影响 ProcessPacket，:337 AfterAnimation+= 回调切场景。
- P2-2：SelectScene.cs StartGame() :264 四入口（按钮 Click :79/双击 :232/回车 :455/AfterDraw :284）无闸门。
- P2-3：AMain.cs CleanUp(:122) :126 Directory.GetFiles 在 for(try :134-139) 之外。
- P2-5：MLibrary.cs :217 OrderBy key 与 :221 count 两处 int.Parse(Regex.Match(x,@"\d+").Value)，无数字文件名返空串→FormatException。

## 修复内容（均附 20261119 注释）

1. **P1-1**（Client\Forms\AMain.cs 3 处）：:84 多 BeginDownload→单次；BeginDownload 方法体改 `while(DownloadList.Count>0){var d=new Download();d.Info=DownloadList.Dequeue();DownloadFile(d);} Completed=true; CleanUp();`；DownloadFile :338 尾部删递归调用。语义等价（原递归下载完所有后末次 BeginDownload 调 Completed+CleanUp）。
2. **P2-1**（Client\MirScenes\LoginScene.cs）：加字段 `private bool _loggedIn;`，Login() 入口 `if(_loggedIn)return; _loggedIn=true;`。
3. **P2-2**（Client\MirScenes\SelectScene.cs）：StartGame() 开头 `if(_starting)return; _starting=true; StartGameButton.Enabled=false;`；AfterDraw 回调改调 SendStartGame()；发包逻辑抽 private SendStartGame()（四入口共用，闸门只进一次）。
4. **P1-2**（Client\MirGraphics\MLibrary.cs）：线程启动改 new Thread(LoadGameLibrariesSafe)；新增 `LoadGameLibrariesSafe(){try{LoadGameLibraries();}catch(Exception ex){CMain.SaveError(ex.ToString());Loaded=true;}}`（Loaded=true 防卡进场；CheckImage 对 _images==null 返回 false 降级）。
5. **P2-5**（Client\MirGraphics\MLibrary.cs）：:217/:221 两处 int.Parse → int.TryParse(...,out int n)?n:0。
6. **P1-3**（Client\Forms\CMain.cs）：LoadMouseCursors 7 处 LoadCustomCursor→TryLoadCustomCursor；新增 `TryLoadCustomCursor(path){try{return LoadCustomCursor(path);}catch(Exception ex){SaveError(...);return Program.Form.Cursor;}}`，Win32Exception 不再冒泡中断 D3D/Sound 初始化。
7. **P2-3**（Client\Forms\AMain.cs CleanUp:122）：方法体整体包 try{...}catch(Exception ex){try{CMain.SaveError(ex.ToString());}catch{}}。

**不修（记录在案）：**
- P2-4 多开配置写回覆盖（Settings.cs Save 整文件写，多进程过期快照后写者覆盖）：需重构 Save 语义为按改动键写回，属设计层改造，风险/收益不成比例。
- P2-6 MessageBox 硬类型转换（MirMessageBox.cs:246-251 `(TextBox)Program.Form.Controls[i]`）：当前 CMain.Controls 仅 MirTextBox 挂的原生 TextBox，不可触发，纯未来防御。
- ActiveDownloads List 工作线程 Add / UI Timer RemoveAt 无锁共享：低优先，改动需读现场重构，暂登记。
