# 20261115汉化NPC任务数据导出表头

> H 汉化线第 8 项（H11）：NPC 数据 / 任务数据两个导出 CSV 的表头是英文（Index,FileName,...），用户用 Excel 打开导出件不直观；汉化表头（导入按列序解析不读表头，零回归）。

## 现象

- server.exe「NPC 信息」「任务信息」窗导出的 CSV（Exports\4_NPC数据.csv / 5_任务数据.csv）首行表头全英文，用户核对数据不便。

## 排查过程

- 导出链：NPCInfoForm.cs :332 写死英文表头 + NPCs[j].ToText() 数据行；QuestInfoForm.cs :259 同构。
- 导入链安全性核查（关键）：NPCInfoForm ImportButton `File.ReadLines().Skip(1)` 后 ParseNPCFromCSV 按列序切分（354-359）；QuestInfoForm 导入 `File.ReadAllLines().Skip(1)` 后 QuestInfo.FromText 按列序解析（281-282）——**两处导入均不读表头**，表头纯给人看，可自由汉化（H 清单 @b56@ 已预判）。
- 旧导出件回灌兼容：旧英文表头 CSV 导入同样 Skip(1) 跳过，不受影响。

## 修复内容

1. **Server.MirForms\Database\NPCInfoForm.cs** :332 表头汉化：`编号,文件名,地图文件名,坐标X,坐标Y,名称,形象,出现率,大地图显示,大地图图标,可传送,攻城可见,最低等级,最高等级,定时显示,开始小时,开始分钟,结束小时,结束分钟`（19 列与原一一对应）。
2. **Server.MirForms\Database\QuestInfoForm.cs** :259 表头汉化：`编号,名称,分组,类型,脚本文件,传送提示,击杀提示,物品提示,标记提示,最低等级,最高等级,前置任务,职业限制`（13 列对应原 Index..RequiredClass）。
- 数据行（ToText）零改动；列数与列序完全不变。

## 验证证据

- `dotnet build Server.MirForms\Server.csproj -c Release`：**0 警告 0 错误**（9.43s）。
- 逻辑复核：导入侧 NPCInfoForm.cs:354-359 / QuestInfoForm.cs:281-282 均 Skip(1) 按列序解析，新表头旧表头均可导入；导出件用 Excel 打开首行即中文。
