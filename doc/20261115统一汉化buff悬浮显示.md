# 20261115统一汉化buff悬浮显示

> 用户实测反馈：华丽雨光 buff 悬浮只显示空洞文案「来自雨光的加成」不显示具体效果（对照：尊者封印会显示 生命值降低 25% / 法力值降低 25%）。授权统一排查此类问题（@604@），顺手汉化顺手修（AGENTS.md 协作决策规范）。

## 现象

1. 华丽雨光悬浮文案空洞（无效果说明）；
2. 12 个英文枚举怪物 buff（HornedArcherBuff/ColdArcherBuff/Mon409BShieldBuff 等）悬浮首行显示英文驼峰拆分（如 `Mon 409 BShield Buff`）；
3. buff 属性行中英文 Stat 键（MinAC/MaxAC/HP/MP）显示英文。

## 排查过程

- **显示机制**（Client\MirScenes\Dialogs\BuffDialog.cs）：`BuffString(ClientBuff)`（286 起）首行 = `RegexFunctions.SeperateCamelCase(buff.Type.ToString())`——中文枚举名拆分后即中文（华丽雨光/尊者封印天然正常），英文枚举原样显示英文；tooltip 靠 switch case 逐个补写；stats 属性行（447）与 `CombinedBuffText`（491）同样用 `SeperateCamelCase(Stat键名)`。
- **本地化基础设施已存在但未接线**：`ToLocalizedString()`（Shared\Language.cs:4272-4280）查 `ClientTextMap.Enum["类型_成员名"]`，查不到回退枚举原 ToString——即改用它对中文枚举零风险；Enum 字典启动时预填充（4133-4143），`LoadClientLanguage`（4151-4181）用 json 的 Enum 段逐键覆盖。**但 angelk 仓库 `Client\Localization\Chinese.json` 只有 Text 段（1094 条）、无 Enum 段**（English.json 有完整 Enum 段 76 键），中文环境英文枚举全部漏网。
- **22 buff 效果取证**（explore 子代理 ses_e230f2f5dffekhuxrSgCOYnr5b）：12 个英文怪物 buff 的授予怪物/Stats 键值/时长/对象逐一核对（HornedArcher.cs:96、Mon409B.cs:104 空 Stats 免伤走 _Immune 标志、Mon579B/580B/615B 分段 AC 护盾等）；中文 debuff（惩戒真言/死亡印记/防御诅咒/烈火焚烧）已有 case 或已注册 Visible。

## 修复内容

1. **`Client\MirScenes\Dialogs\BuffDialog.cs` 三处接线 ToLocalizedString**：
   - BuffString 首行（286）：`SeperateCamelCase(buff.Type.ToString())` → `buff.Type.ToLocalizedString()`（中文枚举无映射回退原名显示不变，英文枚举经 json 映射显示中文）；
   - stats 循环（原 447）与 CombinedBuffText（原 491）：`SeperateCamelCase(key)` → `val.Key.ToLocalizedString()`——英文 Stat 键（MinAC 等）显示中文。
2. **12 个英文怪物 buff tooltip case**（插在 Mon564NSealing case 后，文案按取证效果）：HornedArcherBuff=弓手战吼：攻击与魔法提升 / ColdArcherBuff=冰弓庇佑：双防提升 / HornedColdArcherBuff=魔弓庇佑：魔御与攻击提升 / GeneralMeowMeowShield=护体结界：防御大增 / HornedWarriorShield=石肤护盾：防御激增 / Mon409BShieldBuff=无敌护盾：免疫伤害（overridestats=true）/ ChieftainSwordBuff=狂怒之刃：攻击大增 / ReaperPriestBuff=亡者祝福：攻击提升 / RiklebitesShield=能量护盾：防御大增 / Mon579BShield+Mon580BShield+Mon615BShield 三合一=护体罡气：防御提升（overridestats=true，分段 AC 动态）。
3. **华丽雨光 tooltip 充实**（用户主诉）：`来自雨光的加成` → `华丽雨光：光效加身（纯外观光环，无属性加成）`。
4. **`Client\Localization\Chinese.json` 新增 Enum 段**（Text 段 1094 条原样保留）：26 键=BuffType 13 个英文怪 buff 中文对照（弓手战吼/冰弓庇佑/魔弓庇佑/护体结界/石肤护盾/无敌护盾/狂怒之刃/亡者祝福/能量护盾/冰晶护盾/寒潭护盾/护体罡气/尊者封印）+ Stat 13 个英文键（MinAC=下限防御/MaxAC=上限防御/MinMAC=下限魔御/MaxMAC=上限魔御/MinDC=下限攻击/MaxDC=上限攻击/MinMC=下限魔法/MaxMC=上限魔法/MinSC=下限道术/MaxSC=上限道术/HP=生命值/MP=魔法值）。
5. **deploy 同步**：Chinese.json → `C:\1.40\mir2-deploy\Client\Localization\`（74592B）；Client.exe/dll/pdb → deploy\Client\（10:23:20，旧件已备份 `_backup-exe-20261115\Client\`）。
